# 遺產收集者｜遊戲企劃網站

《遺產收集者》的遊戲企劃資料庫與未來原型實驗室。

目前是無建置步驟的靜態網站：直接在瀏覽器開啟 `index.html`，或使用任何靜態網站服務即可預覽。完整企劃資料是 `docs/` 內的繁體中文 Markdown 文件；網站的「企劃文件」導覽會連至它們。

## 專案原則

- 所有企劃內容以繁體中文撰寫。
- 先建立可維護的設計資料與頁面框架，再逐步加入互動原型。
- 每一項原型獨立實作與驗證，不把網站骨架與遊戲實作綁死。

## 初始內容

- 總覽與核心遊戲循環
- 角色、職業、遺物、戰鬥、時間軸、遠征、報告系統
- 五大區域與事件系統
- 原型實作路線圖

## 企劃資料庫

- `docs/overview/`：遊戲概念與遊戲循環
- `docs/systems/`：角色、職業、戰鬥、時間軸、遺產、關係、敵人與遠征報告
- `docs/world/`：遠征結構、世界觀與擴充邊界
- `docs/development/`：原型實作路線圖

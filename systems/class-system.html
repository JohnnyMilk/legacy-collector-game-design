Prototype 規則

  • Tier 0～3 維持同心圓；角色記憶不新增 Tier 4。
  • Tier 1 → Tier 2 使用一般晉升連線。
  • 同 Tier 只顯示相鄰節點的轉換關係。
  • Tier 3 Inspiration Links 只代表解鎖與繼承來源，不是一般可逆轉職線。
  • 四個角色記憶只在職業樹外顯示與四大職業系的結構對應。
  • 職業定位、一般攻擊、主動、被動、Charge 與 Mastery 不在本頁重複。

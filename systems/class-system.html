Prototype 規則

  • Tier 0 村民只存在首次序章／教學，不參與 Mastery，也不是正式 Run 的可選起始職業。
  • 正式 Run 預設四名主角分別為戰士、斥候、法師、侍祭；玩家可改成任何已解鎖職業，也可四人選同一職業。
  • 每名主角在遠征準備時同時配置一件飾品遺產。
  • 已解鎖職業可直接作為新 Run 起始職業，不必重新從低 Tier 走起。
  • 遠征中的正式轉職只在 Region 之間固定休整點進行；戰鬥後只更新 Mastery 與解鎖。
  • Tier 1 → Tier 2 的一般晉升以 ±45° 為範圍；同 Tier 只能移動到左右相鄰職業。
  • 點擊 Tier 3 時，與左右相鄰 Tier 3 的實線代表可轉職路徑；連向 Tier 2 的紫色虛線只代表 Inspiration 前置關聯，不能沿線轉回 Tier 2。

Prototype 規則

  • Tier 0～3 維持同心圓；角色記憶不新增 Tier 4。
  • Tier 1 自身主動技能統一 9 Charge；Tier 2 統一 6 Charge；Tier 3 自身主動統一 3 Charge。
  • Tier 3 完整繼承 Inspiration Links 對應 Tier 2 與祖先技能，再取得自身 1 個 Charge 3 主動技能與 1 個 Tier 3 專屬被動技能。
  • Tier 3 Mastery 只圍繞自身專屬主動與被動，不加入戰鬥場次、擊殺數或 Elite / Boss 共通任務。
  • Tier 3 最外圈目前保留 16 個概念節點；軍團守衛已確認，其餘逐職業調整。
  • 四名主角分別有戰士、敏捷、魔法、支援系的原始歸屬，但 Tier 1～3 可自由跨系發展。
  • 「XXX 的記憶」只允許對應角色本人使用；需完成原始職業系全部 Tier 3 Mastery，並在 Region 4 的可選記憶神殿首次覺醒。
  • 神殿不是必經路線；同一 Run 可以覺醒多名角色記憶。
  • 記憶首次覺醒後永久解鎖，後續 Run 可直接作為該角色起始形態。
  • 角色記憶的正式名稱、稱號、技能與繼承方式尚待個別設計。

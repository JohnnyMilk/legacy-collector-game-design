Prototype 規則

  • Tier 0～3 保持原同心圓；特殊職業不新增第四圈。
  • 四個特殊職業分別代表戰士、敏捷、魔法、支援系，屬於最終職業。
  • 特殊職業解鎖採 AND：完成該職業系要求的全部 Tier 3 Mastery，且取得對應特殊遺產。
  • Tier 3 Mastery 取消 3 共通 + 3 專屬模板，改為完全職業特色化。
  • 同一隊伍不可重複同一特殊職業；不同特殊職業可同時存在。
  • 特殊職業技能繼承方式尚未定義，不先假設等同 Tier 3。

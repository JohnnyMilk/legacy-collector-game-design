Prototype 規則

  • 此頁專注職業關係與轉職邏輯，不展開個別主動技能、被動技能或 Mastery。
  • 每個職業只保留「定位」與「職業特性」兩種文字說明；舊有「職業描述」欄位已刪除。
  • Prototype 會直接顯示 Tier 3；正式遊戲第一次解鎖 Tier 3 前，連外圈、標籤、問號節點與 Inspiration Links 都不會出現。
  • Tier 0 村民只存在首次序章／教學，不參與 Mastery，也不是正式 Run 的可選起始職業。
  • Tier 2 完整繼承正式連線 Tier 1 的技能；Tier 3 完整繼承 Inspiration Links 對應 Tier 2 與其祖先技能，同一來源不重複。
  • 每個 Region 固定只有一個轉職點，原則上位於路程中段；完成轉職後，新 Build 所有可用主動技能 Charge 補滿。
  • Final Region / Final Boss 不硬性鎖 Tier 3，但正常完整通關難度預期隊伍已取得部分 Tier 3。

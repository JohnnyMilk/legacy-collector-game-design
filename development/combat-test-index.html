戰鬥測試索引

Combat Test 依故事階段與 Region 分類。每個 Region 固定保留兩個一般敵人 Demo；Boss 則固定使用 A / B：A＝Mini Boss，B＝Region Boss。若同一 Boss 需要不同玩家 Tier 做對照，使用 A-1 / B-1 這類子測試名稱。

紅色＝實作中綠色＝完成一般文字＝未開始、不可點

命名規則

序章：Demo 0。
Region 一般敵人：Demo R-1 / Demo R-2，例如 Region 1＝Demo 1-1、Demo 1-2。
Region Boss：Boss A＝Mini Boss；Boss B＝Region Boss。A-1 / B-1 為同一 Boss 的額外對照子測試，不代表第三個 Boss。

共用 Combat Runtime

所有測試共用同一套 Combat Model／Combat UI Runtime。各測試頁只提供 Scenario Configuration；核心戰鬥規則、公式、HUD 與互動邏輯不複製。正式戰場基準為 8×8。

序章｜Prologue

序章只保留劇情殺與核心戰鬥操作驗證，不套用每個 Region 的雙 Demo 規則。

完成。驗證劇情殺、首次 Party Wipe、共用 Combat Runtime、HUD、主動技能入口與雙向行動順序。

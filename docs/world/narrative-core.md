# LEGACY COLLECTOR｜故事核心與創作精神

## 頁面用途

本頁記錄《LEGACY COLLECTOR》的核心敘事方向與作品想表達的精神。此頁優先保存「為什麼這趟旅程存在」；角色姓名、昔日稱號、最終敵人、神祇身分與最後一句 Legacy 的正式文字，後續再個別定義。

## 核心命題

《LEGACY COLLECTOR》不是一個以取得最終獎勵為終點價值的故事。

四名主角一路追逐失去的記憶、力量與原本的身份，玩家也一路追逐職業解鎖、Mastery、Tier 3、角色記憶與 Final Boss。最後真正想留下的問題不是「你拿到了什麼」，而是：

**你是否享受了走到這裡的過程？**

Final Legacy 最終可以是一句話，而不是裝備、能力或收藏品。它代表的不是另一個獎勵系統，而是對整段旅程的回看。

## 四名主角的過去

四名主角在故事開始以前，曾經分別站在戰士、敏捷、魔法、支援四個職業系的頂點。

他們可能曾是英雄、王、神祇級人物，或其他足以代表該職業系最高境界的存在；正式身份與稱號尚未定義。

他們當時擁有極強的力量，也因此逐漸自負，只看重「自己已經站在頂點」的結果，而忘記一路走到頂點時曾經歷的學習、同伴、失敗與選擇。

## 被打回原形

某個比四人更高位的存在介入了他們的人生。這個存在可能是女神、世界意志、守護者或其他角色，目前不先定義。

四名主角因此失去原本的力量與記憶，回到最初的狀態，並以 Tier 0「村民」重新開始。

這不是單純的懲罰，而是一場讓他們重新經歷成長、重新理解自己、重新找回初心的旅程。

## 輪迴與職業系統

Roguelike 的 Run 不只是遊戲機制，而可以直接存在於世界觀中。

每一次失敗、重來與重新選擇職業，都代表四名主角再次走過一段尋回自己的道路。

Tier 1～3 並不是他們只能走的命定路線。四名主角都可以自由學習不同職業系，體驗彼此不同的道路；職業轉換本身就是他們重新理解力量、合作與選擇的過程。

跨 Run 保留的 Mastery、職業解鎖與記憶進度，可以被理解成：即使明確記憶再次模糊，某些經驗仍留在靈魂、本能或世界的痕跡裡。

## 「XXX 的記憶」

四名主角各自有一個真正屬於自己的最終身份，暫以「XXX 的記憶」表示。

這不是一般 Tier，也不是任何人都能學會的職業，而是該角色找回自己曾經是誰之後恢復的專屬形態。

- 每名角色固定對應戰士、敏捷、魔法、支援其中一個職業系。
- 角色平時仍可自由使用其他職業系。
- 對應職業系全部 Tier 3 Mastery 完成後，才具備覺醒自己記憶的資格。
- 記憶神殿只會出現在 Region 4，且不是必經路線；玩家可以選擇其他分支而不進入神殿。
- 同一 Run 可以覺醒多名角色的記憶，只要各自條件成立並實際走到對應神殿機會。
- 「XXX 的記憶」只能由該角色本人使用。
- 首次覺醒後永久解鎖；後續 Run 可直接以已解鎖的「XXX 的記憶」作為起始職業／形態。

角色姓名、昔日身份、英雄／王／神祇級稱號、技能與完整規則另頁定義。

## Final Boss 與最終 Legacy

玩家最終仍會穿越各個 Region、進入 Final Region 並擊敗 Final Boss。

Final Boss 的身分、與四名主角過去的關係，以及更高位存在是否與 Final Boss 為同一角色，目前都不預先決定。

擊敗 Final Boss 後取得的「最後 Legacy」不是裝備系統的回歸。它更可能是一句話、一個答案或一個終於被理解的真相。

正式句子現在不先寫死，但它必須承載同一個精神：

**終點會到來；真正有價值的是你如何走到那裡。**

## 創作精神

這個命題同時適用於遊戲內角色、玩家，以及遊戲本身的創作過程。

四名主角花整個遊戲追尋自己；玩家花整個遊戲走到 Final Boss；而作品的製作也有它自己的終點。

因此《LEGACY COLLECTOR》希望留下的不是「完成」本身，而是對過程的重視：設計、嘗試、改變、失敗、重新選擇與逐步成形，本身就是作品的一部分。

當遊戲真的抵達結尾時，Final Legacy 應該讓玩家回頭想到自己一路玩過來的經驗，而不是只把注意力放在最後一個獎勵上。

# LEGACY COLLECTOR｜故事核心與創作精神

## 頁面用途

本頁記錄《LEGACY COLLECTOR》的核心敘事方向與作品想表達的精神。此頁優先保存「為什麼這趟旅程存在」與整體故事起點；各 Region 的事件、戰鬥、角色細節與場景演出則由獨立的敘事／事件設計頁承載。

## 核心命題

《LEGACY COLLECTOR》不是一個以取得最終獎勵為終點價值的故事。

四名主角一路追逐失去的記憶、力量與原本的身份，玩家也一路追逐職業解鎖、Mastery、Tier 3、角色記憶與 Final Boss。最後真正想留下的問題不是「你拿到了什麼」，而是：

**你是否真正走過、理解並記住了這一路的經歷？**

本作對「Legacy／遺產」的核心理解不是物品、稱號、數值或單純被找回的過去，而是角色與玩家一路實際經歷、承受、選擇、理解、失去與留下的過程。

**真正的遺產，是走過之後留在自己身上的經歷。**

收集這些遺產，並不是把過去拼回原樣，而是讓角色在經歷過新的旅程之後變得更完整。

## 四名主角

故事由四名固定主角組成：

- **蒼岳・玄武**：男性，戰士系起源。
- **朧月・幻姬**：女性，敏捷系起源。
- **阿斯特蕾雅・星賢**：女性，魔法系起源。
- **賽洛恩・聖主**：男性，支援系起源。

在故事開始以前，四人原本就已經彼此同行，並各自擁有與原始職業系相對應的高階力量與完整身份。

這些昔日身份並不是角色必須否定的錯誤，也不是造成失憶的懲罰理由。過去的自己只是角色的一部分；後來重新走過的旅程，會成為另一個同樣真實的部分。

## 故事起點：古代遺蹟

四人在故事正式開始以前，為了冒險、探索或某個尚未完全揭露的目的，共同前往一座**古代遺蹟**。

他們在遺蹟深處接觸並啟動了某種古老機制、力量或封存於其中的存在。

這次啟動事件造成了故事最初的斷裂：

- 四人失去大部分過去記憶。
- 四人失去原本已掌握的力量與職業能力。
- 當四人重新恢復行動能力時，只剩下最基礎的 Tier 0「村民」狀態。

遺蹟事件究竟是單純意外、預先設計好的結果、某種封印機制，或與更大的世界真相有關，目前刻意保留，作為主線謎團逐步揭露。

## Prologue：失去

首次遊戲從古代遺蹟事件後開始。

四名角色在失去記憶與力量的狀態下醒來，並以 Tier 0「村民」進行首次戰鬥。

這場村民戰鬥同時是**教學戰鬥**，主要用於教導：

- 9×9 戰場與基本站位。
- 移動。
- 一般攻擊。
- 行動順序與敵方回合。
- HP、受傷與死亡。
- 一回合中的基本行動概念。

Tier 0 村民只存在於首次序章／教學：

- 不參與 Mastery。
- 不屬於正式 Run 的正常起始職業。
- 不作為一般遠征中的可選職業。

序章的重點不是讓角色理解全部真相，而是讓四人確認一件事：

**他們失去了某些重要的東西，而古代遺蹟正是這一切發生的起點。**

完成序章後，四人決定離開起點，正式踏上尋找失去記憶的旅程。

## Region 1：尋找

Region 1 是第一次正式遠征的開始。

這時四名角色已經知道：

- 自己失去了過去。
- 自己曾經擁有遠超村民狀態的能力。
- 古代遺蹟與失憶事件存在直接關聯。
- 如果想知道自己究竟是誰，就必須主動前進並追查留下來的線索。

因此 Region 1 的敘事功能不是「再次醒來」，而是**第一次主動出發尋找記憶**。

從這裡開始，角色會重新取得 Tier 1 職業、學習新的能力，並在不同 Region、戰鬥、事件與選擇中累積新的經歷。

## 旅程的六個階段

目前故事可以用以下六個階段理解：

1. **Prologue｜失去**
2. **Region 1｜尋找**
3. **Region 2｜選擇**
4. **Region 3｜代價**
5. **Region 4｜記憶**
6. **Final Region｜繼承**

這些不是單純的關卡標題，而是一條完整的角色經歷軸：

**失去 → 尋找 → 選擇 → 代價 → 記憶 → 繼承**

真正的「Legacy」不是其中任何一個單獨答案，而是角色與玩家把這整條路實際走過。

## 輪迴與職業系統

Roguelike 的 Run 不只是遊戲機制，也可以存在於世界觀中。

每一次失敗、重來與重新選擇職業，都代表四名主角再次走過一段尋找自己的道路。

Tier 1～3 並不是四人的命定職業路線。四名主角都可以自由學習不同職業系，體驗彼此不同的道路；職業轉換本身就是角色重新理解力量、合作與選擇的過程。

跨 Run 保留的 Mastery、職業解鎖與記憶進度，可以被理解成：即使一段遠征結束，真正經歷過的事情並沒有完全消失，而會以本能、理解、熟練或世界留下的痕跡持續存在。

這也是本作對「遺產」的機制表現之一：**經歷可以被留下來。**

## 四個完整記憶形態

四名主角各自有一個真正屬於自己的完整記憶形態：

- 蒼岳 → **玄武的記憶**。
- 朧月 → **幻姬的記憶**。
- 阿斯特蕾雅 → **星賢的記憶**。
- 賽洛恩 → **聖主的記憶**。

這些不是 Tier 4，也不是任何角色都能學會的通用職業，而是角色本人在重新經歷旅程後，重新理解並整合自身過去所得的專屬最終形態。

完整記憶並不代表「恢復成以前的自己就完成了」。

角色真正完成的是：

**理解自己曾經是誰，並把那個過去與這一路重新累積的經歷一起接受為現在的自己。**

首次取得完整記憶時，系統先檢查該角色所需的 3 個 Tier 3 Mastery；符合後，才可在 Region 4 唯一一座可選記憶神殿進入角色記憶問答。問答全部通過後，永久解鎖該角色的完整記憶形態。

完整技能繼承、一般攻擊、Party Composition 與記憶神殿的詳細系統規則，統一由「角色記憶覺醒系統」正式頁維護。

## 角色成長與 Legacy

四人的故事不應被理解成「失憶 → 找回舊人格 → 完成」。

他們會在旅途中重新經歷：

- 生存與共同前進。
- 面對沒有完美答案的選擇。
- 承受自己與他人選擇造成的代價。
- 重新面對過去的身份與記憶。
- 最後決定如何帶著所有經歷繼續成為現在的自己。

因此角色的完整，不是因為所有缺失都被補回，而是因為那些失去、得到、犯錯、理解、離開與留下的經歷，都成為了自己的一部分。

可以用一句話概括：

**我們繼承過去，但真正留下來的，是我們曾經走過的路。**

## Final Boss 與最終 Legacy

玩家最終仍會穿越各個 Region、進入 Final Region 並面對 Final Boss。

Final Boss 的身分、古代遺蹟真正的用途、當初的啟動事件為什麼會造成失憶，以及輪迴本身的起源，目前都不預先寫死。

這些問題應該在整段旅程中逐步揭露，而不是在序章一次說完。

擊敗 Final Boss 後的 Final Legacy 不是裝備系統的回歸，也不應只是最後一個強化獎勵。

它更適合是一句話、一個答案、一段回望，或一個終於能被理解的真相。

它必須承載同一個精神：

**終點會到來；真正有價值的是你如何走到那裡，以及那些經歷最後成為了誰的一部分。**

## 創作精神

這個命題同時適用於遊戲內角色、玩家，以及遊戲本身的創作過程。

四名主角花整個遊戲追尋自己；玩家花整個遊戲走過一次又一次遠征；而作品的製作也會經歷設計、嘗試、推翻、修正與重新選擇。

因此《LEGACY COLLECTOR》希望留下的不是「完成」本身，而是對過程的重視。

**設計、嘗試、改變、失敗、重新選擇與逐步成形，本身就是作品的一部分。**

當遊戲真的抵達結尾時，Final Legacy 應該讓玩家回頭想到自己一路玩過來的經驗，而不是只把注意力放在最後一個獎勵上。

## 目前刻意保留的未定內容

- 四人最初為什麼前往古代遺蹟的完整目的。
- 古代遺蹟的正式名稱、文明來源與真正功能。
- 遺蹟啟動事件究竟是意外、機制、封印或其他原因。
- 四名主角在失憶以前更完整的人生經歷與彼此關係。
- Final Boss 身分與其和古代遺蹟的關係。
- 輪迴的完整世界規則與起源。
- Final Legacy 最後一句話或最終呈現方式。

以上內容後續可逐步建立，但不得破壞本頁已確認的核心：

**四人因古代遺蹟事件失去記憶與力量，從村民重新開始；他們出發尋找過去，卻在一路新的經歷中變得比單純恢復過去更加完整。**

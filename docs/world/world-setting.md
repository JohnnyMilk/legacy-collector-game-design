# LEGACY COLLECTOR｜世界設定（World Setting）

## 核心概念

世界由一次次循環構成。四名主角曾經站在戰士、敏捷、魔法、支援四大職業系的最高點，卻因某個更高位存在或重大事件失去記憶、身份與力量，重新以普通村民開始。

他們每一次遠征都在穿越世界、重新學習職業、找回力量，也在逐步理解自己為什麼會不斷重來。

## 世界與輪迴

- Party Wipe 可視為本次循環失敗。
- 下一個 Run 是新的循環。
- 職業 Mastery、已解鎖職業與已真正找回的記憶可以跨循環保留。
- 這些永久進度不一定要被角色完整「記得」，也可以表現為本能、熟悉感或無法被抹除的記憶碎片。

## 四名主角

四人原本各自屬於一個主要職業系的頂點人物。他們過去可能是英雄、王、神選者或其他同等層級存在；正式身份與稱號尚未定義。

Tier 1～3 是他們在輪迴中重新理解不同戰鬥道路的過程。四人都能自由跨系發展，只有最終的「XXX 的記憶」與原始身份綁定。

## Legacy 的定位

現行世界觀不使用 Relic／遺產作為裝備、收藏或成長系統。

「Legacy」仍然可以是故事中的古老概念、遠古遺留、世界核心或最後真相。Final Boss 之後的最終 Legacy 不是戰利品式裝備，而是一句話／一個理解。

它要傳達的精神是：**終點不是旅程唯一的價值；真正重要的是追逐終點的過程是否值得、是否被享受。**

## 遠征目的

遊戲表層目標很單純：

`Region 1 → Region 2 → Region 3 → Region 4 → Final Region → Final Boss`

深層目標則是：四名角色在一次次循環、轉職、Mastery 與記憶覺醒中找回自己，並理解過去的自己為什麼會失去一切。

## Region 4

Region 4 存在可選的記憶神殿分支。它不是必經路線；完成對應職業系全部 Tier 3 Mastery 的角色，可在合法神殿首次覺醒自己的「XXX 的記憶」。

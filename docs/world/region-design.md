# LEGACY COLLECTOR｜Region 設計

## 基本架構

一次完整遠征由：

- Region 0（序章／村民前導）
- Region 1
- Region 2
- Region 3
- Region 4
- Final Region
- Final Boss

組成。

## Region 場景與敘事主題｜CONFIRMED

世界場景必須隨遠征推進，從封閉的古代遺跡逐步走向外界、舊文明遺址，再進入被記憶侵蝕的空間，最後抵達「遺忘之地」。

| 階段 | 場景主題 | 敘事核心 | 場景方向 |
| --- | --- | --- | --- |
| Region 0 | 遺跡內部 | 失去 | 村民前導。四名主角尚未進入正式職業體系，在遺跡內經歷序章與第一次 Party Wipe。 |
| Region 1 | 遺跡廢棄道路 | 尋找 | 從遺跡深處往外走的廢棄道路、守衛區與殘存設施；仍保有強烈古代遺跡與構裝機械感。 |
| Region 2 | 遺跡出口森林 | 選擇 | 離開遺跡後第一次真正踏入外界。森林包覆遺跡出口，古代構造逐漸被自然環境取代／吞沒。 |
| Region 3 | 沉沒舊城 | 代價 | 舊文明城市／聚落被河流、水域與自然侵蝕，部分道路與建築半沉沒。玩家開始直接看見過去文明留下的代價。 |
| Region 4 | 記憶裂境 | 記憶 | 真實世界開始被記憶侵蝕。神殿、石橋、荒原與遺跡出現重複、斷裂、漂浮或不合理拼接，逐步把玩家帶向記憶本身形成的空間。 |
| Final Region | 遺忘之地 | 繼承 | 世界與記憶的最深層。核心戰鬥是面對並擊敗四名主角各自的「覺醒記憶複製體」。 |

敘事主軸固定為：

**失去 → 尋找 → 選擇 → 代價 → 記憶 → 繼承**

其中 Region 0 對應「失去」，Region 1～4 依序對應「尋找／選擇／代價／記憶」，Final Region 對應「繼承」。

### Final Region｜遺忘之地

Final Region 的核心敵方不是一般 Region 敵人，而是四名主角「原本的覺醒記憶」所形成的複製體：

- 蒼岳・玄武／玄武的記憶
- 朧月・幻姬／幻姬的記憶
- 阿斯特蕾雅・星賢／星賢的記憶
- 賽洛恩・聖主／聖主的記憶

最終階段的核心命題是：玩家必須擊敗「原本的自己／被固定下來的記憶」，才能完成真正的繼承。

## Region 對敵方設計的約束｜CONFIRMED

後續設計一般敵人、Elite、Mini Boss、Region Boss 時，**必須優先根據該 Region 的場景主題與敘事功能設計**，不能只按 Tier 數值換皮。

敵方設計至少應同時考慮：

- **外觀來源**：角色的服裝、裝備、材質、機械／人形／自然／記憶異象特徵是否符合該 Region。
- **戰鬥功能**：技能與被動是否能反映場景，例如森林中的機動／伏擊、沉沒舊城中的地形與殘存文明機制、記憶裂境中的位移／複製／失序效果。
- **敵人組成**：同一 Region 可混合不同來源，但必須形成一致的世界觀。例如 Region 1 適合遺跡守衛、人形探索者、構裝機械；Region 2 應逐步增加森林與外界生態／探索勢力元素。
- **Boss 語言**：Mini Boss 與 Region Boss 應是該區主題的強化表現，而不是獨立於場景之外的敵人。
- **事件連動**：特殊敵人應能和該 Region 的事件、遺物、環境線索互相呼應。

因此未來進行 Enemy Stats／Boss Stats 設計時，應先確認其所屬 Region，再決定角色名稱、視覺概念、能力與技能。

## Region × Enemy Tier 強度基準｜CONFIRMED

Region 不綁定單一 Enemy Tier，而採用「主要 Tier + 過渡 Tier」結構。前段可保留較低 Tier 敵人，後段逐步混入下一階 Tier，讓玩家自然感受到轉職壓力，而不是跨 Region 突然跳級。

| Region | 一般敵人 Tier 配置 | 強度用途 | Boss 預期玩家強度 |
| --- | --- | --- | --- |
| Region 0｜遺跡內部 | Tier 1 | 村民前導／劇情殺；讓尚未進入正式職業體系的主角面對正式戰鬥單位。 | 序章固定 Party Wipe，不作正常通關平衡。 |
| Region 1｜遺跡廢棄道路 | Tier 1 → Tier 1 + Tier 2 | 前段以 Tier 1 為主；後段開始混入 Tier 2，形成首次明確轉職壓力。 | 1A Mini Boss：Tier 1 可通過；1B Region Boss：預期 Tier 2。 |
| Region 2｜遺跡出口森林 | Tier 1 + Tier 2 → Tier 2 | 前段仍可保留少量 Tier 1 混編；中後段逐步轉為 Tier 2 主體。 | 2A / 2B：預期完整 Tier 2 隊伍。 |
| Region 3｜沉沒舊城 | Tier 2 → Tier 2 + Tier 3 | 前段以 Tier 2 為主；後段開始出現 Tier 3，形成第二次主要轉職壓力。 | 3A：Tier 2 可挑戰；3B：開始要求隊伍已有 Tier 3 成員。 |
| Region 4｜記憶裂境 | Tier 2 + Tier 3 → Tier 3 | 前段仍可混少量 Tier 2；中後段以 Tier 3 為主。 | 4A / 4B：預期完整 Tier 3 隊伍。 |
| Final Region｜遺忘之地 | Tier 3 / Memory | 高階敵人與四名主角覺醒記憶複製體；是完整 Build 的最終驗證。 | Final：預期完整 Tier 3／已解鎖 Memory Build。 |

整體成長節奏固定為：

- **Region 1～2：Tier 1 → Tier 2 成長區間。**
- **Region 3～4：Tier 2 → Tier 3 成長區間。**
- **Final Region：Tier 3 完成後的最終驗證。**

Boss 本身不使用玩家職業式的 Tier 1／2／3 分類；Boss 使用獨立 Boss Stats 與專屬技能設計。表中的 Tier 僅代表「預期玩家隊伍強度」與該 Region 一般敵人池的配置基準。

Region 1 已由 Combat Test 驗證目前梯度可行：全 Tier 1 隊伍無法合理通過後段 Tier 1 + Tier 2 混編；2 名 Tier 1 + 2 名 Tier 2 已具有低勝率通關可能；完整 Tier 2 則能應付 Region 1 Final Boss，但仍保有適度壓力。後續 Region 的 Enemy Tier 配置可依實測結果微調數量與混編比例，但不改變上述整體 Tier 推進方向。

## 節點規則

採 Roguelike 單向路徑：

- 玩家選擇前進路線。
- 節點完成後不能返回刷取。
- 每個 Region 只有 1 個固定中段轉職點。
- Region Boss 負責結束該 Region 並推進下一區。

## Region 4：記憶神殿

Region 4 額外存在「記憶神殿」類特殊分支節點。

- 神殿只會在 Region 4 出現。
- 每次 Run 的 Region 4 固定只生成 **1 座**記憶神殿。
- 神殿不是必經路線；玩家可以選擇其他路線，放棄本次覺醒機會。
- 進入神殿後，先分別檢查四名角色各自所需的 3 個 Tier 3 Mastery 是否全部完成。
- 符合 Mastery 條件的角色才可進入自己的記憶問答。
- 每名角色的問答與覺醒資格獨立判定；同一座神殿可讓多名符合資格的角色於同一 Run 分別完成首次覺醒。
- 每名角色固定 3 題、每題 3 個選項，至少 2 個選項屬於正確方向；問答偏向理解角色經歷，而非知識考試。
- 該角色若答錯，本次 Run 不可重答，必須等下一次 Run 再抵達 Region 4 神殿。
- 首次覺醒後永久解鎖，後續 Run 可直接選擇已解鎖的記憶形態作為起始職業。

完整覺醒規則以 `docs/systems/memory-awakening-system.md` 為正式來源；Region 文件只描述其在地圖結構中的位置與節點行為。

## Region 目的

每個 Region 都應提供不同的敵人配置、地形、事件與路線取捨，同時讓玩家有機會推進職業 Mastery 與調整隊伍 Build。

角色故事不另外拆成獨立好感度或角色支線系統，而應分散融入主線、Region 主題、地圖事件、特殊戰鬥與記憶神殿。Region 4 是一般遠征與完整記憶覺醒交會的區域；Final Region 則承接玩家與角色一路累積的經歷，走向世界核心與 Final Boss。

## 敘事／事件設計介面

實際事件、戰鬥場景、角色對話、問答題目與演出內容統一在「敘事與事件設計（Event Design）」中編寫。Region 設計頁保留區域結構與系統級規則，不在此重複管理事件內容。

# 遠征與世界｜舊版草稿

> 此文件為舊版整合草稿。正式遠征流程請以 `docs/systems/expedition-system.md` 與 `docs/overview/gameplay-loop.md` 為準。

## 現行遠征摘要

遊戲最初只有一次序章／教學，四名主角以 Tier 0「村民」身分開始。序章結束後，村民不再作為一般 Run 的起始職業。

每次正式 Run 的流程為：

```text
遠征準備
→ Region 1
→ 休整點
→ Region 2
→ 休整點
→ Region 3
→ 休整點
→ Region 4
→ 休整點
→ Final Region
```

遠征準備時：

- 預設四名主角分別使用戰士、斥候、法師、侍祭。
- 玩家可改選任何已解鎖職業，也可讓多名角色使用相同職業。
- 每名主角選擇一件飾品遺產。

Run 中戰鬥負責更新 Mastery 與職業解鎖；正式轉職只在 Region 之間的固定休整點進行，不依賴隨機事件。

## 單向遠征地圖

地圖採前進式節點選擇：從起點選擇下一個節點，完成後不能回頭，也不能重複刷取同一節點。

完整旅程仍以 4 個主要 Region 加 Final Region 為核心框架。

## 世界衝突

玩家所屬的收藏館主張尋找、研究、修復與保存遺產。對立勢力可主張封存或摧毀古代力量。核心衝突仍可圍繞「復原 vs. 封存」展開。

## 舊版規則處理

本文件過去曾描述每個 Region 固定 Mastery Cycle 等早期節奏假設。現行 Mastery 已改為跨 Run、隊伍共享的職業 Checklist，因此不再以「每區練滿幾個職業」作為正式基準。

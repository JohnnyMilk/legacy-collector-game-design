# 遠征與世界

## 單向遠征地圖

地圖採用類似《殺戮尖塔》的前進式節點選擇：從起點選擇下一個節點，完成後不能回頭，也不能重複刷 Mastery、遺產或事件。MVP 先以戰鬥節點驗證節奏，未來可加入事件、休息、招募與故事節點。

完整旅程：

```text
Region 1 → Region 2 → Region 3 → Region 4 → Final Region → Final Boss
```

每個 Region 約提供相當於六場主要戰鬥的成長節奏，約有兩個 Mastery Cycle。正式區域名稱、敵人名單與故事內容尚待設計；早期「失落森林」「古代遺跡」等名稱只是概念草案。

## 世界衝突

玩家所屬的收藏館主張尋找、研究、修復與保存遺產。對立的封存者認為古代文明正是被這些力量摧毀，因此應封存或摧毀遺產。衝突是「復原 vs. 封存」，而非單純善惡對立。

未來可擴充掠奪者、信奉者與其他勢力；同一遺產能因不同立場形成不同 Expedition。

## MVP 與未來擴充

MVP 只需驗證四人、4+Final Region、基本職業分層、少量遺產與少量 Tier 3 Hidden Class。墓地、死亡騎士、復活規則突破、特殊 Final Boss 等內容是後續更新的擴充空間，不能反寫為 MVP 基礎規則。

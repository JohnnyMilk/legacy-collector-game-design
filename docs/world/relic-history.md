# 舊版草稿｜遺產歷史（已取消）

> **狀態：ARCHIVED / CANCELLED**  
> 本頁保留早期世界觀演進紀錄。現行 LEGACY COLLECTOR 不再以「收集、修復、收藏遺產」作為世界主軸或遊戲系統。

## 舊版概念

早期設定曾把 Relic／遺產定義為失落時代製品，玩家會發現、收藏、修復並逐步解放能力，收藏館同時承擔世界敘事。

這套設定已取消。

## 現行 Legacy 定位

「Legacy」仍可存在於故事，但不再是玩家管理的物品類型。

它可以代表：

- 世界最後留下的真相。
- 四名主角失去的過去。
- 某個遠古存在留下的訊息。
- Final Boss 之後才被理解的一句話。

目前最核心的精神是：**不要只看最後得到了什麼，也要記得自己是否享受追逐答案的過程。**

正式世界觀請改看 `docs/world/world-setting.md` 與 `docs/world/narrative-core.md`。

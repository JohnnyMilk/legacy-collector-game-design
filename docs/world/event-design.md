# LEGACY COLLECTOR｜敘事與事件設計（Event Design）

本頁是後續設計 Region 故事、地圖事件、角色事件、特殊戰鬥場景、記憶神殿問答與演出的集中工作頁。

## 核心敘事原則

《遺產收集者》的「遺產」不是裝備、收藏品或單純找回的記憶，而是角色一路經歷、承受、選擇與理解之後留下的經驗。

角色記憶覺醒不是回到過去的自己，而是把過去、現在與遠征途中累積的經歷重新整合。角色故事因此不另外拆成好感度或關係值系統，而是自然融入主線、Region、地圖事件與戰鬥場景。

## 四名角色敘事主軸

### 蒼岳・玄武

- 核心命題：守護／承擔。
- 初始傾向：習慣替所有人承擔風險與責任。
- 成長方向：理解真正的守護不是替別人決定，而是尊重他人的選擇並一起承擔。
- 遺產主題：承擔的遺產。

### 朧月・幻姬

- 核心命題：自由／選擇。
- 初始傾向：擅長保留退路，不喜歡被任何人束縛。
- 成長方向：理解自由不只代表可以離開，也包含能夠主動選擇留下。
- 遺產主題：選擇的遺產。

### 阿斯特蕾雅・星賢

- 核心命題：真理／理解。
- 初始傾向：相信事情應該可以被理解、分析並找到答案。
- 成長方向：理解人的經歷可能存在多種視角；完整不等於知道所有答案。
- 遺產主題：理解的遺產。

### 賽洛恩・聖主

- 核心命題：救贖／接納。
- 初始傾向：傾向以拯救與維持生命作為優先價值。
- 成長方向：理解救贖不一定等於替別人決定活下去，而是理解並尊重對方真正的選擇。
- 遺產主題：接納的遺產。

## Region 敘事骨架（暫定）

目前先以五個階段作為工作骨架，尚未視為正式名稱：

1. **Region 1｜生存**：建立隊伍共同經歷與最基礎的互相依靠。
2. **Region 2｜選擇**：增加沒有唯一標準答案的事件與路線取捨。
3. **Region 3｜代價**：讓先前選擇的後果與失去開始變得具體。
4. **Region 4｜記憶**：讓過去重新進入現在；記憶神殿在此提供完整記憶覺醒。
5. **Final Region｜繼承**：不再只追問過去發生什麼，而是讓角色帶著一路累積的經歷決定現在要成為誰。

以上僅為設計方向，正式 Region 名稱、世界場景與主線內容仍待逐一確認。

## 事件設計模板

每個事件建議使用以下欄位，避免故事、地圖與戰鬥彼此脫節：

- Event ID：事件唯一編號。
- Region：所在區域。
- Event Type：主線／地圖事件／角色事件／特殊戰鬥／Boss／記憶神殿／其他。
- Trigger：如何出現或觸發。
- Scene：場景與環境。
- Narrative Purpose：這個事件要讓玩家經歷或理解什麼。
- Characters：主要涉及角色。
- Character Theme：對應承擔／選擇／理解／接納中的哪一條主軸。
- Player Choice：玩家是否需要做選擇。
- Combat Setup：若進入戰鬥，敵人、地形、勝敗條件與特殊規則。
- Outcome：事件完成後的直接結果。
- Follow-up：是否影響後續事件、對話或遠征紀錄。
- Memory Relevance：是否會成為 Region 4 記憶問答可引用的經歷。
- Status：提案／確認／完成內容製作。

## 事件整合原則

- 不為四名角色各自建立互不相干的「角色副本」。
- 優先讓同一事件同時呈現多名角色不同的觀點。
- 角色差異以對話、選擇、反應與後續理解表現，不建立友好度或關係值。
- 戰鬥場景若能承載敘事，就應讓戰鬥規則本身反映事件命題，而不是戰鬥結束後才另外播放故事。
- Region 事件應同時服務遠征節奏、世界理解、角色經歷與後續記憶問答。
- 記憶問答只驗證玩家是否理解角色一路的經歷，不考冷知識或細節記憶。

## 記憶問答內容原則

系統規則已在角色記憶覺醒系統完成；本頁只負責實際內容。

每名角色共 3 題，每題 3 個選項，至少 2 個選項屬於正確方向。題目應依角色在 Region 1–4 真正發生過的事件編寫，而不是先寫答案再硬塞劇情。

建議三題分別對應：

1. 角色曾經相信什麼。
2. 哪段經歷讓這個理解發生改變。
3. 角色現在真正理解的是什麼。

## 戰鬥場景設計方向

後續可優先開發的特殊戰鬥類型：

- 防守：守住人物、位置或通道。
- 救援：在有限壓力下接近並救出目標。
- 撤離：不是擊敗全部敵人，而是讓指定單位抵達出口。
- 分隔戰場：角色被地形或事件切割，迫使重新理解彼此的角色定位。
- 生存壓力：敵人持續增援，勝利條件是撐過或完成事件目標。
- 抉擇型戰鬥：不同目標無法同時完整達成，玩家必須做取捨。
- Boss 敘事戰：Boss 機制本身對應 Region 的核心命題。

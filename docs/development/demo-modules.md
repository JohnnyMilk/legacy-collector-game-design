# Demo 模組規劃（Demo Modules）

## 目的

每個遊戲系統皆以獨立 Demo 驗證，而非直接開發完整遊戲。

## 核心 Demo

### Class Tree Viewer

驗證：
- Tier 分支
- Mastery
- Hidden Class
- Legacy Trait

### Relic Viewer

驗證：
- 遺產收藏
- 修復狀態
- 能力解鎖

### Timeline Simulator

驗證：
- Hidden Agility
- 行動順序
- 狀態影響

### Battle Grid Editor

驗證：
- Grid
- 地形
- 移動成本
- 單位佔格

### Expedition Editor

驗證：
- Region
- Node
- Boss
- Reward

# Mastery 流程 Demo

這個頁面只用來測試 Mastery 流程，不承載任何正式職業說明。

## 測試目標

- Checklist 達標時，`Mastery X / Y` 立即增加。
- 全部 Checklist 達標時，先顯示 `Mastery Y / Y · 待戰後結算`。
- 只有按下戰鬥結算後，才正式取得 `MASTERED`。
- 模擬角色死亡不會清除已累積的職業紀錄或 Mastery 完成狀態。
- 底層職業戰績檔案可持續超過 Mastery 門檻，例如擊倒需求 45，但長期擊倒數可持續累積至 100 以上。

此 Demo 使用戰士 Mastery 作為單一測試樣本，避免在每一張正式職業卡重複放置互動按鈕。

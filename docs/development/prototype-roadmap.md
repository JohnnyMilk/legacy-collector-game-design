# LEGACY COLLECTOR｜Prototype 開發路線

## 開發原則

採 MVP 方式先驗證核心系統。Prototype 不直接製作完整遊戲，而是用獨立頁面驗證資料結構、規則與 UI。

## Phase 1：職業與長期進度

- Class Tree Viewer
- Mastery Checklist Viewer
- Skill Inheritance Viewer
- Party Composition Viewer / Demo
- Memory Awakening Viewer / Demo

目的：驗證遊戲真正的長期成長核心。

## Phase 2：戰鬥核心

- Timeline Simulator
- Battle Grid Editor
- Movement / Terrain 驗證
- Action / Wait / Skill Exception 驗證

## Phase 3：流程整合

- Expedition Map Editor
- Region 轉職點流程
- Region 4 記憶神殿分支
- Final Region / Final Boss 流程
- Report Generation

## Phase 4：進階系統

- Enemy AI Simulator
- Tier 3 Hidden Class Unlock
- Party Composition 被動組合平衡
- 記憶形態技能與角色專屬限制
- Future Expansion 驗證

## 已取消 Prototype

- Relic Viewer / 遺產收藏館
- 遺產修復階段 Demo
- 特殊遺產解鎖流程
- Relationship Viewer

以上只保留舊版歷史，不再投入現行 Prototype。

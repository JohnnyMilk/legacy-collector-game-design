# Prototype Lab 路線圖

企劃資料優先於遊戲實作。每一個原型都應是獨立、最小且可驗證的工具，而不是搶先製作完整遊戲。

1. **職業樹檢視器**：顯示 Tier、職業分支、Mastery 與未公開的啟發資料。
2. **Timeline 模擬器**：輸入敏捷與技能效果，觀察近期行動序列。
3. **Battle Grid Editor**：驗證 Grid、地形、可移動範圍與佔格規則。
4. **遺產收藏館**：驗證遺產狀態、修復進度與能力預覽。
5. **Expedition Map Editor**：驗證單向節點與 Region 節奏。
6. **Enemy AI Simulator**：驗證目標評分、移動與技能決策。

原型暫時不實作；本網站先成為它們的設計依據與入口。

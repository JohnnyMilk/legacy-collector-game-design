# Prototype 開發路線（Prototype Roadmap）

## 開發原則

採用 MVP（Minimum Viable Product）方式，先驗證核心系統，再逐步擴充完整遊戲。

Prototype 不直接製作完整遊戲，而是作為各個系統的獨立驗證工具。

## Prototype 順序

### Phase 1：資料系統

- 職業樹檢視器
- 遺產收藏館
- Relationship Viewer

目的：驗證遊戲資料結構。

### Phase 2：戰鬥核心

- Timeline 模擬器
- Battle Grid Editor
- Movement 與地形驗證

目的：驗證戰棋核心規則。

### Phase 3：流程整合

- Expedition Map Editor
- Reward Flow
- Class Change
- Report Generation

### Phase 4：進階系統

- Enemy AI Simulator
- Hidden Class Unlock 模擬
- Future Expansion 驗證

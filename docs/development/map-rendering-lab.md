# 戰鬥地圖渲染研究

> 狀態：🔴 進行中 / 尚未定案

## 2026-09-20 新研究分支：Card-SLG 4×4 固定站位戰場

本分支研究把原本「走格子的 SLG」重新抽象成**卡牌式戰術戰鬥**。核心原則是：**拿掉角色移動，但保留空間戰術與地形差異**。

### 核心概念

- 戰鬥場地使用 **4×4 棋盤**。
- 玩家固定 4 人，站在棋盤一側的一整列。
- 敵方最多 4 人，站在相對側的一整列。
- 角色**不需要移動**。
- 中間兩列保留作為視覺戰場、攻擊動畫與空間感使用。
- 每一個角色腳下的格子都有獨立地形。
- 地形不需要和相鄰格合理連接，因為它代表的是「角色目前所處環境／狀態」，不是連續地圖。
- 地形卡可以直接改變某個角色腳下的格子。
- 地形可同時具有「高度」與「材質／類型」兩個層級。

### 視覺方向

目前暫定研究名稱：

**Dark Cinematic Isometric Diorama**

中文可稱：

**暗黑電影感・等距微縮模型風**

核心視覺語彙：

- 45° 左右斜俯視 / Isometric
- 3D miniature tabletop diorama
- Dark fantasy tactical card game
- realistic PBR materials
- modular independent terrain platforms
- handcrafted terrain tiles
- cinematic lighting
- soft volumetric fog
- warm rim lighting
- deep shadows
- weathered stone / moss / natural terrain
- premium board-game miniature aesthetic
- subtle depth of field
- dark desaturated palette
- high contrast

UI 方向：

**Dark Fantasy Premium Card UI**

- 深色半透明面板
- 細金屬／金色邊框
- 低飽和色彩
- 藍／紅陣營提示
- 高級奇幻桌遊卡牌感
- 不使用過度現代或科幻 HUD

> 目標不是做成真人比例 3D RPG，而是維持「高級戰棋模型／實體桌遊微縮模型」的質感。

### 地形高度示意

高度與材質可分離：

| 高度層 | 建議視覺高度 | 說明 |
|---|---:|---|
| 高地 | +2 | 明顯升高 |
| 丘陵 | +1 | 中度升高 |
| 平原 | +0.5 | 比平地略高 |
| 平地 | 0 | 基準 |
| 沼澤 | 0 | 同高但材質不同 |
| 淺水 | -0.2 | 稍微下陷 |
| 洞窟 | -1 | 明顯下沉 |

地形材質候選：

- 草原
- 雪地
- 沼澤
- 熔岩
- 墓園
- 聖域
- 洞窟
- 遺跡

因此可產生：

- 高地沼澤
- 低地冰原
- 高地墓園
- 平地聖域

不需要為每個組合重新建立完整地形邏輯。

### 戰術定位

本研究的核心句：

> **把座標移動拿掉，但不要把空間戰術拿掉。**

地形卡不是單純 Buff UI，而是直接改變戰場立體結構。

例如：

- 高地：角色攻擊 +6
- 沼澤：獲得隱匿／減傷
- 洞窟：下沉，降低遠程受到的傷害
- 熔岩：持續傷害或提高火屬性效果
- 聖域：治療／抗性
- 墓園：死亡／召喚／隱藏職業事件條件

# 舊研究：8×8 移動式 SLG Map Rendering

下列內容保留作為原始移動式 SLG 渲染研究紀錄。若 Card-SLG 方向後續正式採用，需再決定是否封存此分支。

這個頁面原本專門用來研究《遺產收集者》的**戰場地圖視覺渲染、角色對話 UI／渲染，以及兩者最後的整合方式**。

正式研究流程拆成三個彼此獨立、最後再整合的部分：

1. **Map Rendering**：地圖、投影、場景物件、單位與戰術提示。
2. **Dialogue Rendering**：角色肖像、姓名、文字框、選項與劇情對話操作。
3. **Integrated Presentation**：確認前兩者各自穩定後，再研究地圖與角色對話如何共存於同一個遊戲畫面。

目前 Combat Demo 的地圖優先驗證戰鬥規則與操作，因此視覺仍偏功能性；角色對話也不直接綁進 Combat UI。兩個 Renderer 先各自建立清楚邊界，再進行整合。

## 原始基準

- 戰鬥邏輯尺寸：8 × 8。
- 8 × 8 是戰鬥座標與判定基準，不代表畫面最終必須是正方形俯視格。
- 地圖與對話 UI 都必須支援手機、iPad 與桌面瀏覽器。
- 單位、血條、行動提示、移動範圍、攻擊範圍與障礙物必須保持清楚可讀。
- Combat Demo 0 / Demo 1 的正方形俯視棋盤只作為功能性基準，不視為最終美術方向。
- 原始候選方向包含 90° 正上方、45° Diamond、Isometric / 2.5D 與其他斜視投影。

## 原始渲染研究重點

- 邏輯格與畫面格分離。
- 單位可超出單格視覺邊界。
- Unit Renderer 與 Map Projection 解耦。
- Depth Sorting。
- Combat Overlay Layer 獨立於地表美術。
- Region / Theme 用資料或資產設定切換。
- Browser-first，必須兼顧手機與 iPad 效能。
- Dialogue Renderer 與 Map Renderer 分離。
- 最後由 Scene / Presentation Shell 控制 Map、Dialogue、HUD。

## 後續研究決策

目前需優先比較：

1. 8×8 移動式 SLG 是否繼續作為正式核心。
2. 4×4 Card-SLG 固定站位是否成為新核心。
3. 是否保留兩者作為不同遊戲模式。
4. 地形卡是否只存在於 Card-SLG。
5. 若採 Card-SLG，原本移動距離、LOS、障礙物與地圖 AI 規則哪些可被刪除或重構。

# LEGACY COLLECTOR｜GDD Review

## Purpose

此文件是現行 GDD 的一致性基準。若舊版 Relic／遺產、收藏館、Legacy Trait 或 Relationship 文件與本頁衝突，以本頁與對應現行系統文件為準。

## Core Rules

### 遊戲與故事

- 正式名稱只使用 **LEGACY COLLECTOR**，不另設中文正式名稱。
- 四名固定主角曾分別站在戰士、敏捷、魔法、支援四大職業系的頂點，故事開始時失去記憶與力量，以 Tier 0「村民」重新開始。
- 四人可自由跨職業系使用 Tier 1～3；原始職業系只決定各自唯一的「XXX 的記憶」。
- Party Wipe 可視為本次輪迴失敗；職業 Mastery、職業解鎖與已覺醒記憶跨 Run 保留。
- 一次完整遠征維持 Region 1～4 + Final Region；擊敗 Final Boss 是 Run 的最終成功條件。
- 最後的 Legacy 不是裝備，而是一句話／一個理解：終點不是旅程唯一的價值，角色與玩家都應在追逐結果的過程中找到意義。

### 角色與 Build

- 四名固定主角，無角色等級、無自由能力配點。
- **角色沒有任何裝備欄。**
- 不存在武器、防具、飾品、Relic／遺產裝備、修復、收藏館、掉落或特殊遺產解鎖。
- 現行 Build 來源：目前職業、完整技能繼承、四人當前職業系組合、記憶形態與戰鬥決策。
- 隊伍職業組合會提供團隊被動，但具體組合與效果尚未定義，只保留獨立 Prototype 頁。

### 職業與 Mastery

- Tier 0「村民」只存在於首次序章／教學，不參與一般 Mastery。
- Tier 1 / Tier 2 使用 6 項 Mastery：3 共通 + 3 職業專屬。
- Tier 3 不使用共通 Mastery；任務只圍繞自己的 Tier 3 專屬能力，數量不固定。
- Mastery 四名主角共享、以職業為單位、跨 Run 永久保留；角色死亡不回滾。
- Checklist 達標與 `Mastery X / Y` 即時更新；MASTERED 在戰鬥結束後正式判定。
- Tier 1 / Tier 2 自身各提供 1 主動 + 1 被動；Tier 3 專屬能力組合可以依職業玩法調整，不強制固定為 1 主動 + 1 被動。
- Tier 1 自身主動 9 Charge；Tier 2 自身主動 6 Charge；Tier 3 若新增專屬主動，Charge 基準為 3。
- Tier 2 完整繼承正式連線 Tier 1 主／被動；Tier 3 完整繼承 Inspiration Links 對應 Tier 2 與祖先技能，同一來源去重。
- 一般攻擊不繼承，也不視為被動技能。
- Tier 3 全部是隱藏職業；第一次解鎖前正式 UI 不顯示 Tier 3 外圈與 Inspiration Links。

### 「XXX 的記憶」

- 四個最終角色形態不是 Tier 4，正式機制名稱為角色專屬 **「XXX 的記憶」**。
- 四個記憶分別綁定四名主角與戰士、敏捷、魔法、支援四個原始職業系。
- 其他角色不可使用不屬於自己的記憶。
- 首次覺醒條件：對應職業系**全部 Tier 3 Mastery**完成 + 在 Region 4 實際進入合法記憶神殿節點。
- 神殿只出現在 Region 4，且為可選分支，不是必經路線。
- 同一 Run 可以覺醒多名角色，只要各自條件與路線成立。
- 首次覺醒後永久解鎖；後續 Run 可由對應角色直接以自己的記憶開始，不需再次進神殿。
- 四名主角姓名、記憶形態正式顯示名、過去稱號、技能與數值待後續設計。

### Region / 轉職

- 每個 Region 固定只有 1 個轉職點，原則上位於路程中段。
- 戰鬥結束只處理 Mastery、解鎖與一般戰後結算，不直接轉職。
- 角色目前職業必須已 Mastered 才能正式轉出。
- 完成轉職後，新 Build 所有可用主動技能 Charge 補滿。
- Region 4 額外存在可選記憶神殿分支。

### 行動與戰鬥

- 每名存活角色每輪最多取得 1 次自身行動。
- 一般自身行動由「移動 + 行動（普通攻擊或主動技能）」組成，可移動→行動或行動→移動。
- 僅移動或僅行動都只是結束自身行動，**不等於 Wait**。
- Wait 必須明確選擇；只有真正 Wait 才觸發綁定 Wait 的被動／效果。
- 一般移動不可拆成行動前後兩段；個別技能明確授予的中段／攻擊後移動例外。
- 目前技能位移例外包含遊俠「穿越射擊」與舞刃者「旋舞連斬」。
- 9×9 戰場；角色一般移動固定四方向；技能斜向／8 方向由個別技能定義。

## Tier 3 Current State

Tier 3 外圈目前有 16 個概念節點；目前已完成正式設計：**軍團守衛、血煉騎士、戰將、獵刃武者、斷罪士、夜獵手、幻行師、影刃術士、空間魔導士**。戰士系 4 個 Tier 3 已全部完成；敏捷系 4 個 Tier 3 已全部完成；魔法系已有 1 個正式完成。其餘名稱與定位仍 provisional，必須依 Inspiration Links 的既有 Tier 2 技能包逐一重新設計。

### 已確認：軍團守衛

- Tier 3 / 戰士系 / -135°。
- Inspiration Links：騎士、吟遊詩人、煉金術士。
- 定位：前線戰術核心／區域封鎖／隊伍保護。
- 一般攻擊「戰槍」：前方直線 2 格物理攻擊，可同時命中兩格敵人；阻擋地形可截斷後方格。
- 被動「壁壘陣」：軍團守衛位於自己盾牆周圍 8 格內時，該盾牆周圍 8 格我方 DEF / MDEF +20%，重疊不疊加。
- 主動「盾牆陣」：3 Charge；在四個斜角相鄰格各嘗試生成 HP 1、不可穿越的盾牆；占位／阻擋地形格不生成。
- Mastery：單次生成 4 面盾牆 15 次；壁壘陣防護中的我方單位實際承受敵方傷害 30 次。

### 已確認：血煉騎士

- Tier 3 / 戰士系 / -112.5°。
- Inspiration Links：騎士、狂戰士、煉金術士。
- 定位：前線承傷轉化／低血爆發／生命資源運用。
- 一般攻擊「血刃」：只攻擊正前方 1 格的單一敵人，造成物理普通攻擊傷害。
- 被動「赤血之誓」：依目前已損失的最大 HP 比例，提高同等比例的物理攻擊力；治療使 HP 回升時，加成同步下降。
- 主動「血煉分身」：3 Charge；消耗目前 HP 的 50% 生成 1 個分身。分身最大 HP 等於本次實際消耗 HP，僅能移動與使用普通攻擊，且擁有自己的「赤血之誓」。同一名血煉騎士同時最多存在 1 個分身。
- Mastery：赤血之誓至少提供 +50% 物理攻擊力時成功造成物理傷害 30 次；血煉分身普通攻擊成功造成傷害 30 次。

### 已確認：戰將

- Tier 3 / 戰士系 / -90°。
- Inspiration Links：騎士、狂戰士、武士。
- 定位：近身群戰／敵眾增傷／友軍成陣。
- 一般攻擊「橫掃」：同時攻擊左前方、正前方、右前方共 3 格。
- 被動「萬夫莫敵」：周圍 8 格每 1 個敵方單位，造成傷害 +15%。
- 被動「眾志成城」：周圍 8 格每 1 個友方單位，自身防禦 +15%。
- 不新增 Tier 3 專屬主動技能；繼承主動技能照常保留。
- Mastery：周圍至少 3 名敵人時成功造成傷害 20 次；周圍至少 2 名友方時實際承受敵方傷害 20 次。

### 已確認：獵刃武者

- Tier 3 / 戰士系 / -67.5°。
- Inspiration Links：狂戰士、武士、遊俠。
- 一般攻擊「獵刃」：3 格物理普通攻擊。
- 被動「獵痕」：造成傷害後標記敵人；同時最多 1 名。再次傷害自己的獵痕目標時傷害 +30%。
- 被動「鎖獵」：敵人受到獵刃武者傷害後不能移動，直到獵刃武者下一次自身行動開始；仍可原地執行合法行動。
- 不新增 Tier 3 專屬主動技能。
- Mastery：距離 2 格以上命中並建立獵痕 30 次；觸發獵痕 +30% 傷害時擊倒敵人 15 次。

### 已確認：斷罪士

- Tier 3 / 敏捷系 / -45°。
- Inspiration Links：狂戰士、武士、遊俠、刺客。
- 一般攻擊「獵首斬」：1 格物理普通攻擊。
- 被動「處決」：對目前 HP 低於 20% 的敵人進行會造成傷害的攻擊時，直接擊殺該目標。
- 主動「斷首突襲」：3 Charge；指定 3 格內敵人，移動至其相鄰合法格後造成約普通攻擊 1.8 倍物理傷害；若傷害後低於 20% HP，立即觸發處決。
- Mastery：斷首突襲使目標從 20% 以上降到 20% 以下 20 次；成功觸發處決 20 次。

### 已確認：夜獵手

- Tier 3 / 敏捷系 / -22.5°。
- Inspiration Links：武士、遊俠、刺客。
- 一般攻擊「影刃」：1 格物理普通攻擊。
- 被動「潛影」：自己的回合只要成功造成至少 1 次傷害，回合結束後進入隱身，持續至下一次自身行動開始。隱身期間不能成為單體普通攻擊或單體技能指定目標，但範圍攻擊仍可正常命中。
- 主動「影鏢」：3 Charge；只能沿上下左右直線施放，最遠 8 格，造成約普通攻擊 1.5 倍物理傷害；阻擋地形或其他單位會截斷路徑。
- Mastery：造成傷害並於回合結束進入隱身 30 次；影鏢命中距離 5 格以上敵人並造成傷害 20 次。

### 已確認：幻行師

- Tier 3 / 敏捷系 / 0°。
- Inspiration Links：遊俠、刺客、舞刃者。
- 一般攻擊「疾刃」：1 格物理普通攻擊。
- 被動「疾影蓄勢」：造成傷害時，比較前一次造成傷害的位置與目前位置的曼哈頓距離；每相距 1 格，本次傷害 +10%，不設上限；結算後更新目前位置作為下一次判定紀錄。
- 主動「影遁」：3 Charge；傳送至 9×9 戰場任意合法空格，並在周圍合法空格生成 2 個影分身。每個影分身只有 1 HP，攻擊力與施放時本體相同，可移動並使用「疾刃」，但沒有任何主動或被動技能。
- Mastery：相距至少 6 格並以疾影蓄勢取得至少 +60% 傷害後成功造成傷害 20 次；影遁生成的影分身成功造成傷害 30 次。

### 已確認：影刃術士

- Tier 3 / 敏捷系 / +22.5°。
- Inspiration Links：刺客、舞刃者、魔劍士。
- 定位：物魔交替／機動連段／連鎖爆發。
- 一般攻擊「幽刃」：1 格近戰物理普通攻擊，不帶額外效果。
- 主動「雙相刃」：3 Charge；對相鄰 1 名敵人發動攻擊。傷害類型必定與影刃術士前一次由本人執行的攻擊之最後實際傷害類型相反；前一次物理則本次魔法，前一次魔法則本次物理，沒有前一次攻擊紀錄時預設魔法。雙相刃必定視為符合「魔力交織」交替條件並取得 +25% 傷害。多段攻擊以最後一段實際傷害類型更新紀錄，額外傷害事件不更新。
- 被動「魔殞」：影刃術士擊倒敵方單位時，以死亡格為中心，使周圍 8 格敵方各受到相當於影刃術士 1.0 倍魔法攻擊力的魔法傷害；不傷害自己或友方。魔殞擊殺可再次觸發魔殞形成連鎖。只有影刃術士造成的擊殺可觸發；魔殞屬魔法傷害，可正常影響魔力交織，但不更新雙相刃的前一次攻擊紀錄。
- Mastery：使用雙相刃並實際取得魔力交織 +25% 傷害後成功造成傷害 **20 次**；由一次擊殺引發的魔殞連鎖中至少連續觸發 2 次魔殞，完成 **15 次**。

### 已確認：空間魔導士

- Tier 3 / 魔法系 / +45°。
- Inspiration Links：刺客、舞刃者、魔劍士。
- 定位：空間換位／直線魔法／自我防護。
- 一般攻擊「魔導劍」：選擇上下左右 1 個方向，攻擊前方直線 3 格；第 1 格造成 50% 魔法普通攻擊傷害、第 2 格 80%、第 3 格 100%。三格可同時命中 3 名敵人，且不會被單位或阻擋地形截斷。
- Tier 3 專屬能力採 **2 個主動技能、無專屬被動**；合法繼承技能仍完整保留。
- 主動「界位交換」：3 Charge；指定 3 格內任意 1 個可合法交換位置的單位，立即與其交換位置。技能不造成傷害；若交換後任一位置非法則不能施放。使用後本回合不能再普通攻擊或施放其他主動技能；若一般移動尚未使用，仍可依一般規則移動。
- 主動「魔導護盾」：3 Charge；不需選擇目標，立即對自身施放 1 層防護罩。護盾完全抵消下一個實際命中的單一傷害段後消失；多段攻擊只抵消第一個傷害段，後續照常結算；同時最多 1 層。
- Mastery：使用界位交換成功與任意單位交換位置 **25 次**；使用魔導護盾成功抵消原本會使自身 HP 降至 0 或以下的致死傷害段 **15 次**。

## Data / Report

- 本次遠征紀錄只保存本 Run，結束後封存為遠征報告。
- 職業戰績檔案以職業為單位跨 Run 永久累積；Mastery 只是其門檻視圖。
- Expedition Record 不再包含任何 Relic／遺產取得、裝備或修復欄位。
- 可新增隊伍職業組合變化、Region 4 神殿、記憶首次覺醒與 Final Boss 結果等事件。

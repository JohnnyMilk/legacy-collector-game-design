# 遺產收集者｜Legacy Trait 系統（已取消／舊版草稿）

## 狀態

此系統已取消，不屬於現行核心設計。

## 舊版設計

早期版本曾規劃：角色完成職業 Mastery 並轉職後，原職業留下較弱的被動效果，稱為 Legacy Trait，用來表現角色過去職涯痕跡。

這套設計原本希望讓角色因過去修習職業不同而產生差異。

## 取消原因

現行設計已確定：

- Mastery 跨 Run 永久保留。
- 新 Run 可直接選擇任何已解鎖職業。
- Tier 2、Tier 3 改採完整技能繼承，直接保留前置職業的主動與被動技能。

在這個架構下，再額外保留「弱化版被動」會與技能繼承重疊，增加不必要的 Build 管理負擔。

## 現行替代方案

現行規則改為：

- 每個職業自身提供 1 個主動技能與 1 個被動技能。
- Tier 2 完整繼承正式連線 Tier 1 的技能。
- Tier 3 完整繼承 Inspiration Links 對應 Tier 2 與其祖先技能。
- 同一來源技能不重複。

正式規格請以 `class-system.md`、`skill-system.md` 與 `mastery-system.md` 為準。

# 遺產收集者｜Legacy Trait 系統

## 核心概念

Legacy Trait 代表角色過去職業留下的經歷與能力。

轉職不是重新開始，而是在原有道路上累積新的可能性。

## 轉職後保留

當角色完成職業 Mastery 並轉職後，原職業可能留下部分特性，形成角色獨有的成長歷史。

## 設計目的

讓相同職業的角色也可能因為過去選擇不同，而產生不同玩法。

角色差異來自：

- 曾經修習過的職業
- 累積的 Legacy Trait
- 裝備的遺產
- 隊伍配置

## 與職業的關係

職業提供目前定位。

Legacy Trait 提供角色過去的痕跡。

兩者共同形成最終 Build。

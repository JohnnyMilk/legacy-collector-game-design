# 遺產收集者｜職業系統

## 職業階層

職業樹仍保留 Tier 0～Tier 3 的同心圓結構，但 Tier 0「村民」只存在於遊戲序章／教學，不是每次遠征的正常起始職業。

- Tier 0：村民（僅序章／教學使用）
- Tier 1：基礎職業
- Tier 2：進階職業
- Tier 3：全部為隱藏職業

序章中四名主角以村民身分開始，用來完成基礎操作、戰鬥教學與故事導入。序章結束後，村民不再作為一般遠征的起始職業，也不需要 Mastery。

## 正式遠征的起始職業

每次 Run 開始前都會進入「遠征準備」。

預設配置為四名主角各使用一個 Tier 1：

- 戰士
- 斥候
- 法師
- 侍祭

玩家可以在出發前替每名主角重新選擇任何已解鎖的職業，不受預設配置限制。

- 可以選擇已解鎖的 Tier 1、Tier 2、Tier 3 或未來的特殊職業。
- 可以讓多名角色使用相同職業，例如四名主角全部使用戰士。
- Run 開始時的職業選擇不需要重新從村民或 Tier 1 逐層走過。
- 職業是否已 Mastered 與職業是否已解鎖是不同狀態；只要職業已解鎖，就可以作為新 Run 的起始職業。

## 同心圓職業地圖

職業以同心圓方式呈現。

- 圓心：Tier 0
- 第一圈：Tier 1
- 第二圈：Tier 2
- 最外圈：Tier 3
- 半徑代表 Tier；越外圈代表越高 Tier
- 角度代表職業傾向
- 四個主要職業系為戰士系、敏捷系、魔法系、支援系

Tier 1 → Tier 2 的一般晉升，以目前職業角度 ±45° 作為可選範圍；同 Tier 轉職則依職業樹目前定義的相鄰節點規則進行。

## Run 中的轉職時機

戰鬥結束只負責結算 Mastery、恢復與新職業解鎖，不會立即要求或允許角色轉職。

正式遠征途中只能在固定的「休整點」進行轉職。休整點是遠征流程中的必經準備節點，原則上設置於 Region 之間，讓玩家在進入下一段遠征前調整隊伍。

在休整點：

- 可以維持目前職業。
- 可以轉換到職業樹上目前可用的職業。
- 轉職仍須符合職業樹的路徑規則。
- 角色目前所使用的職業必須已被隊伍完成 Mastery，才可以由該職業進行正式轉職。
- 新解鎖的 Tier 3 可以立即顯示為已解鎖，但要到休整點才可真正轉入。

因此「解鎖職業」與「實際轉職」是兩件不同的事。

## Mastery 與轉職

Mastery 是四名主角共用、以職業為單位的隊伍永久進度，並跨 Run 保留。

只要某個職業已被隊伍完成 Mastery，之後任何角色使用該職業時，都視為該職業已 Mastered，不需要每名角色各自重練。

Mastery 的主要用途：

- 允許角色在休整點由目前職業進行轉職。
- 作為 Tier 3 Inspiration 的共享解鎖條件。
- 提供後續 Legacy Trait 等系統使用。

## Tier 3 與啟發連結

出現在同心圓上的每一個 Tier 3 隱藏職業，至少連結 3 個 Tier 2 職業；部分 Tier 3 可以連結 4 個或更多 Tier 2。

這些 Tier 2 連線代表該 Tier 3 的 Inspiration Links（啟發連結），而不是普通的單一路徑晉升。Tier 3 的正式啟發來源以資料中明確指定的 Inspiration Links 為準；職業在圓周上的角度則用來呈現其傾向與跨系位置。

因此同心圓同時表達三種資訊：

- 半徑＝Tier
- 角度＝職業傾向
- Tier 2 → Tier 3 連線＝Inspiration（啟發）關係

Tier 3 是真正跨系職業主要出現的階段。某個 Tier 3 可以同時連結不同職業系的 Tier 2，讓它的混合定位直接由職業地圖呈現。

## 啟發（Inspiration）

Tier 3 的解鎖規則採單一、共享的職業樹邏輯。

每個同心圓上的 Tier 3 都有一組 Inspiration Links。當隊伍共用職業樹已完成該 Tier 3 **所有對應 Tier 2 職業的 Mastery**，該 Tier 3 即完成 Inspiration 並永久解鎖。

- Mastery 為四名主角共用，不區分由哪一名角色完成。
- 不需要角色親密度或 Relationship 條件。
- 不需要額外特殊事件作為一般 Tier 3 的解鎖條件。
- 必須完成該 Tier 3 所列出的全部 Tier 2 Inspiration Links；不是任選其中幾個。
- Inspiration Links 數量可以不同，因此部分 Tier 3 的解鎖門檻自然較高。

### 啟發範例：魔劍士 × 舞刃者 × 刺客

目前正式完整揭露的兩個 Tier 3 範例使用完全相同的三個 Tier 2 Inspiration Links：

- 魔劍士
- 舞刃者
- 刺客

只要隊伍共用職業樹完成「魔劍士」、「舞刃者」與「刺客」三個職業的 Mastery，就同時解鎖「影刃術士」與「幻刃魔導士」。

#### 影刃術士

- Tier：3
- 系別：敏捷系
- 角度：22.5°
- 定位：高速魔法刺殺
- 職業描述：將魔法附著於高速武器與身法，以接近、斬擊與脫離完成高價值目標的刺殺。
- 核心特性：移動後進行攻擊或技能時獲得額外效果；若目標尚未行動，效果再提升。
- Inspiration Links：刺客、舞刃者、魔劍士

#### 幻刃魔導士

- Tier：3
- 系別：魔法系
- 角度：45°
- 定位：連續魔法近戰
- 職業描述：以魔力生成幻刃與魔法劍影，將高速近戰、連續斬擊與魔法爆發串成完整攻勢。
- 核心特性：普通攻擊或技能命中後累積幻刃；達到條件後，下一個主動技能追加魔法斬擊或產生強化效果。
- Inspiration Links：刺客、舞刃者、魔劍士

## 特殊職業

透過遺產直接取得或啟發的職業，統一稱為「特殊職業」。

特殊職業不屬於目前這棵 Tier 0～Tier 3 同心圓職業樹，因此：

- 不會顯示在同心圓職業樹上。
- 不使用一般 Tier 3 的 Inspiration Links / Mastery 解鎖規則。
- 其解鎖條件由對應遺產或其他特殊來源定義。
- 一旦永久解鎖，之後可在新 Run 的遠征準備階段作為起始職業選擇；Run 中是否可切換則依特殊職業個別規則處理。

## 隱藏資訊呈現

未解鎖的同心圓 Tier 3 預設顯示為「？？？」。

即使職業尚未揭露，職業樹仍可顯示／反向標示其 Inspiration Links，讓玩家知道需要精通哪些 Tier 2 職業；正式名稱、定位與能力則在解鎖後才揭露。

目前作為規則範例，已預先完整揭露「影刃術士」與「幻刃魔導士」兩個 Tier 3，以便在職業樹上直接理解 Inspiration Links 與跨系職業的關係。

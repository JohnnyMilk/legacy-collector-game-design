# 遺產收集者｜職業系統

## 職業階層

角色從 Tier 0 開始。

- Tier 0：村民（共同起點）
- Tier 1：基礎職業
- Tier 2：進階職業
- Tier 3：全部為隱藏職業

## 轉職原則

職業轉換必須完成目前職業的 Mastery。

相同 Tier 的職業可以互相轉換，但不能回到較低 Tier。

## 隱藏職業

Tier 3 職業不會直接顯示於初始職業樹。

開啟方式可能包含：

- 特定遺產
- 隊伍職業組合
- 角色關係
- 遠征紀錄
- 特殊事件

## 啟發（Inspiration）

隱藏職業不是單純解鎖，而是角色受到隊伍與經歷影響產生新的可能性。

例如：

騎士 + 牧師 + 高關係值

可能讓角色獲得聖騎士職業啟發。

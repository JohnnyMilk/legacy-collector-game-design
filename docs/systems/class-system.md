# 遺產收集者｜職業系統

## 職業階層

角色從 Tier 0 開始。

- Tier 0：村民（共同起點）
- Tier 1：基礎職業
- Tier 2：進階職業
- Tier 3：全部為隱藏職業

## 同心圓職業地圖

職業以同心圓方式呈現。

- 圓心：Tier 0
- 第一圈：Tier 1
- 第二圈：Tier 2
- 最外圈：Tier 3
- 半徑代表 Tier；越外圈代表越高 Tier
- 角度代表職業傾向
- 四個主要職業系為戰士系、敏捷系、魔法系、支援系

一般晉升只能往下一個 Tier 移動；同 Tier 轉職則沿同一圓周移動。

Tier 1 → Tier 2 的一般晉升，以目前職業角度 ±45° 作為可選範圍；同 Tier 只能轉換至左右相鄰節點。

## 轉職原則

任何正式轉職，都必須先完成角色目前職業的 Mastery（精通）。

相同 Tier 的職業可以互相轉換，但不能回到較低 Tier。

「解鎖某個職業」與「角色可以立即轉職」是兩件不同的事：即使 Tier 3 已經被啟發或解鎖，角色仍必須先完成目前職業的精通，才能進行轉職。

## Tier 3 與啟發連結

出現在同心圓上的每一個 Tier 3 隱藏職業，至少連結 3 個 Tier 2 職業。

這些 Tier 2 連線代表該 Tier 3 的主要啟發來源，而不是普通的單一路徑晉升。Tier 3 的正式啟發來源以資料中明確指定的 Inspiration Links 為準；職業在圓周上的角度則用來呈現其傾向與跨系位置。

因此同心圓同時表達三種資訊：

- 半徑＝Tier
- 角度＝職業傾向
- Tier 2 → Tier 3 連線＝Inspiration（啟發）關係

Tier 3 是真正跨系職業主要出現的階段。某個 Tier 3 可以同時連結不同職業系的 Tier 2，讓它的混合定位直接由職業地圖呈現。

## 啟發（Inspiration）

Tier 3 隱藏職業不是單純依靠一條晉升路徑取得，而是角色受到職業經歷、隊伍關係、特殊事件與遺產影響後產生新的可能性。

對於同心圓上的一般 Tier 3，透過「職業經歷／事件」或「隊伍關係」取得 Inspiration 時，必須由該 Tier 3 啟發連線上的 **3 個不同 Tier 2 職業精通**共同構成條件。三個精通可以全部來自同一名角色的職業經歷，也可以由角色自身與隊伍成員共同提供。

只要滿足下列任一種啟發條件，即可解鎖該 Tier 3：

1. **三職業精通 + 特殊事件**：角色曾精通該 Tier 3 啟發連線上的 3 個不同 Tier 2 職業，並完成該 Tier 3 指定的特殊事件。
2. **一個自身精通 + 兩個隊伍精通 + 關係條件**：角色自身精通該 Tier 3 啟發連線上的 1 個 Tier 2 職業；隊伍中另外任兩名角色，各自精通一個不同的 Tier 2 職業。三個職業必須彼此不同，且全部位於該 Tier 3 的啟發連線上；另外兩名角色彼此的關係值需達到該 Tier 3 指定門檻。
3. **目標 Tier 3 遺產**：直接持有該目標 Tier 3 對應的遺產即可解鎖。此路徑不要求先完成上述三職業精通條件；Tier 3 遺產與其遺產能力，至少都會與對應 Tier 3 職業的主題或能力相關。

### 完整揭露範例：魔劍士 × 舞刃者 × 刺客

目前先完整揭露兩個由相同三個 Tier 2 Inspiration Links 所構成、但分別偏向敏捷系與魔法系的 Tier 3：

- 魔劍士
- 舞刃者
- 刺客

這組三職業共同指向兩個 Tier 3，示範同一組職業經歷可以因不同啟發結果產生不同高階職業。

#### 影刃術士

- Tier：3
- 傾向：敏捷 × 魔法，偏敏捷
- 定位：高速魔法刺殺
- 職業描述：將魔法附著於高速武器與身法，以接近、斬擊與脫離完成高價值目標的刺殺。
- 核心特性「影步」：移動後進行攻擊或技能時獲得額外效果；若目標尚未行動，效果再提升。
- 招牌主動技能「瞬影斬」：移動至目標附近並進行一次魔法斬擊；對尚未行動的敵人效果提升。
- Inspiration Links：刺客、舞刃者、魔劍士

#### 幻刃魔導士

- Tier：3
- 傾向：敏捷 × 魔法，偏魔法
- 定位：連續魔法近戰
- 職業描述：以魔力生成幻刃與魔法劍影，將高速近戰、連續斬擊與魔法爆發串成完整攻勢。
- 核心特性「幻刃共鳴」：普通攻擊或技能命中後累積幻刃；達到條件後，下一個主動技能追加魔法斬擊或產生強化效果。
- 招牌主動技能「萬象幻刃」：消耗累積的幻刃，對單一目標進行多段魔法斬擊。
- Inspiration Links：刺客、舞刃者、魔劍士

兩個職業都可透過以下任一路徑解鎖：

- **三職業精通 + 特殊事件**：同一名角色曾精通「魔劍士」、「舞刃者」與「刺客」，再完成對應 Tier 3 的指定特殊事件。依事件條件，可分別解鎖「影刃術士」或「幻刃魔導士」。
- **隊伍關係路徑**：角色自身精通三者其中一個；隊伍中另外兩名角色分別精通其餘兩個不同職業，且這兩名角色彼此關係達到該 Tier 3 指定門檻，即形成完整的三職業 Inspiration 條件。
- **遺產路徑**：直接取得「影刃術士」或「幻刃魔導士」對應的 Tier 3 遺產，即可直接解鎖該職業。

解鎖後仍不代表可以立刻轉職；要轉入 Tier 3 的角色，仍必須先完成自己目前職業的 Mastery。

## 特殊 Tier 3

某些特殊 Tier 3 使用自己的例外解鎖規則，例如由遠征紀錄取得特定稱號後開啟。

這類特殊 Tier 3 不會出現在目前的同心圓職業地圖上，也不受「至少連結 3 個 Tier 2」的顯示規則限制；之後將以另一套系統另外處理。

## 隱藏資訊呈現

未解鎖的同心圓 Tier 3 預設顯示為「？？？」。

當 Tier 3 被啟發／解鎖後，才揭露其正式職業名稱、定位、能力與相關遺產資訊。

目前作為規則範例，已預先完整揭露「影刃術士」與「幻刃魔導士」兩個 Tier 3，以便在職業樹上直接理解 Inspiration Links 與跨系職業的關係。

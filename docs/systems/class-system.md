# 遺產收集者｜職業系統

## 系統頁面責任

「職業系統」只負責呈現與規範：

- 職業之間的轉職關係
- 所屬職業系
- 職業定位
- 職業特性
- Tier 與角度
- 一般轉職路徑
- Tier 3 Inspiration Links
- 高 Tier 技能繼承規則
- 最終特殊職業的位置與解鎖規則

個別職業的一般攻擊、主動技能、被動技能、Charge 與 Mastery Checklist 不在此頁展開，統一放在「職業熟練系統」頁面。

舊有「職業描述」欄位已取消。定位與職業特性已足以承擔職業說明功能，後續資料與 UI 不再使用 `summary`／職業描述欄位。

## 職業階層

一般職業樹保留 Tier 0～Tier 3 的同心圓結構，但 Tier 0「村民」只存在於遊戲序章／教學。

- Tier 0：村民（僅序章／教學）
- Tier 1：基礎職業
- Tier 2：進階職業
- Tier 3：隱藏高階職業
- 最終特殊職業：不屬於 Tier 4，獨立存在於同心圓之外

四個最終特殊職業分別對應戰士系、敏捷系、魔法系、支援系。它們是各職業系的最終 Build 目標，不納入一般 Tier 編號。

## 正式遠征的起始職業

每次 Run 開始前進入「遠征準備」。預設配置為戰士、斥候、法師、牧師各一名。

玩家可以替每名主角重新選擇任何已解鎖職業：

- 可以選擇已解鎖的 Tier 1、Tier 2、Tier 3 或特殊職業。
- 一般職業可以多人重複使用。
- **同一個最終特殊職業在隊伍中不可重複。**
- 四個不同的特殊職業可以同時存在於隊伍中。
- Run 開始時不需要重新從村民或 Tier 1 逐層走過。

## 職業定位與職業特性

每個職業保留「職業定位」與「職業特性」兩個主要文字欄位；職業特性只說明玩法傾向，不是技能，也不直接提供戰鬥效果。

每一個正式職業自身提供 1 個一般攻擊型態、1 個有限 Charge 的主動技能與 1 個被動技能；特殊職業最終技能組另行設計。

目前一般職業的主動技能 Charge 採 Tier 統一：**Tier 1 一律 9 Charge、Tier 2 一律 6 Charge、Tier 3 自身主動技能一律 3 Charge**；最終特殊職業另行定義。完整 Charge 規則以 `skill-system.md` 為準。

## 一般攻擊與技能繼承

一般攻擊型態由目前職業自己定義，不屬於技能繼承。

- Tier 1：自身 1 主動 + 1 被動。
- Tier 2：自身技能 + 正式連線 Tier 1 的全部主／被動技能。
- Tier 3：完整繼承 Inspiration Links 對應 Tier 2 與其祖先主／被動技能，並額外取得自身 **1 個 Charge 3 主動技能 + 1 個 Tier 3 專屬被動技能**。
- 同一來源技能只計一次。
- 一般攻擊不繼承。
- 特殊職業的最終技能繼承方式尚未定案，不能先假設等同 Tier 3。

## 同心圓職業地圖

一般職業以同心圓方式呈現：

- 圓心：Tier 0
- 第一圈：Tier 1
- 第二圈：Tier 2
- 最外圈：Tier 3
- 半徑代表 Tier，角度代表職業傾向
- 四個主要職業系為戰士系、敏捷系、魔法系、支援系

四個最終特殊職業不再增加第四圈，而是**獨立放置在原同心圓之外**，各自靠近所代表的職業系方向。UI 應讓玩家清楚理解它們不是 Tier 4，而是另一種最終職業節點。

Tier 1 → Tier 2 的一般晉升，以目前職業角度 ±45° 作為可選範圍；同 Tier 轉職依相鄰節點規則進行。

目前支援系 Tier 2 正式排列為：

- **神官**：150°，範圍治療／危急救援。
- **吟遊詩人**：180°，團隊增益／自我維持。
- **煉金術士**：210°，異常狀態支援／範圍弱化。

三者都位於牧師 180° 的 ±45° 晉升範圍內，因此皆正式連線並繼承牧師的「恩典」與「治癒」。原 210° 的「守護者」設計已取消，由「煉金術士」完整取代，內部職業 ID 也改為 `tier2_alchemist`。

Tier 2 → Tier 3 的 Inspiration Links 是解鎖與技能繼承前置關係，不代表可逆轉職路徑。

### 已確認 Tier 3｜軍團守衛

**角度：-135°｜戰士系**

- Inspiration Links：騎士、吟遊詩人、煉金術士。
- 定位：前線戰術核心／區域封鎖／隊伍保護。
- 一般攻擊「戰槍」：選擇上下左右 1 個方向，攻擊前方連續 2 格；兩格內若都有敵人則各受到 1 次物理攻擊。不可穿越阻擋地形攻擊後方格。
- Tier 3 專屬被動「壁壘陣」：軍團守衛位於自己生成的盾牆周圍 8 格內時，該盾牆啟動防護，使盾牆周圍 8 格內我方單位 DEF / MDEF +20%；多面盾牆重疊時不疊加。4 面盾牆完整生成且軍團守衛位於中央時，可形成完整 5×5 防護範圍。
- Tier 3 主動「盾牆陣」：3 Charge。以軍團守衛為中心，在 4 個斜角相鄰格各嘗試生成 1 面 HP 1 盾牆。盾牆不可移動、不可穿越或跨越，必須被擊毀才能通過；若預定生成格已有單位、召喚物或阻擋地形，該格不生成盾牆。
- Mastery 僅 2 項：單次「盾牆陣」成功生成 4 面盾牆 15 次；由「壁壘陣」防護中的我方單位實際承受敵方傷害 30 次。

其餘 Tier 3 仍維持暫定概念，後續逐一重新確認名稱、定位、Inspiration Links、一般攻擊、Tier 3 專屬被動、Charge 3 主動技能與完全職業專屬 Mastery。

## Tier 3 的隱藏與首次揭露

正式遊戲在玩家第一次解鎖 Tier 3 以前，不顯示 Tier 3 的存在。Prototype 02 可為開發驗證提前顯示完整 Tier 3，包括目前 16 個概念節點。

最終特殊職業屬於更後段的系統內容；正式 UI 的實際揭露時機可配合首次取得特殊遺產或滿足其前置條件再決定。Prototype 可預先顯示四個外部節點，以方便驗證整體職業樹結構。

## Run 中的轉職時機

戰鬥結束只負責正式判定 MASTERED、新職業解鎖、恢復等戰後結算，不會立即轉職。

每一個 Region 固定只有 1 個轉職點，原則上設置於該 Region 路程中段。

`Region 起點 → 前半段戰鬥／事件 → 轉職點 → 後半段戰鬥／事件 → Boss → 下一 Region`

角色目前職業必須已 Mastered，才可以從該職業沿正式轉職路徑進行轉職。完成轉職後，新 Build 中所有可用主動技能 Charge 補滿。

## Mastery 與轉職

Mastery 是四名主角共用、以職業為單位、跨 Run 永久保留的進度。

- 同一職業若有多名角色同時使用，符合條件的行為合併累積。
- 戰鬥中即時記錄進度。
- Checklist 達標與 `Mastery X / Y` 在戰鬥中立即更新。
- **MASTERED 與因此產生的新職業解鎖只在戰鬥結束後正式判定。**
- Mastered 本身不提供戰鬥數值加成。
- Mastered 用於允許由目前職業轉出、計入 Tier 3 Inspiration，以及永久保存完成紀錄。

Tier 1 與 Tier 2 固定使用 6 項 Mastery：3 項共通 + 3 項職業專屬。

**Tier 3 不再使用這個共通模板。** Tier 3 Mastery 只圍繞該職業自身的 Tier 3 專屬主動技能與專屬被動技能設計；不加入戰鬥場次、擊殺數或 Elite / Boss 參與等共通任務，且任務數量不固定。

## Tier 3 與啟發連結

出現在同心圓上的每一個 Tier 3 隱藏職業，透過 Inspiration Links 連結多個 Tier 2。當隊伍完成該 Tier 3 所有對應 Tier 2 職業的 Mastery，即永久解鎖該 Tier 3。

目前 16 個 Tier 3 概念節點都已明確列出 Inspiration Links。這些 Links 同時決定該 Tier 3 會完整繼承哪些 Tier 2 主／被動技能及其祖先技能，因此後續逐職業設計時，Tier 3 專屬能力必須建立在既有繼承技能組上，避免重複同樣功能。

## Tier 3 與完整通關難度

Tier 3 不作為進入 Final Region 或挑戰 Final Boss 的硬性門檻，但它是正式難度曲線預期的後期戰力層級。純 Tier 2 隊伍仍允許挑戰完整 Run；若成功可視為高難度特殊成就。

## 最終特殊職業

遊戲規劃四個最終特殊職業，各代表一個主要職業系：

- 戰士系最終特殊職業
- 敏捷系最終特殊職業
- 魔法系最終特殊職業
- 支援系最終特殊職業

目前名稱與技能尚未定義，因此 Prototype 以 `？？？` 顯示。

### 解鎖條件

每個最終特殊職業必須**同時**滿足兩個條件：

1. 完成該職業系要求的全部 Tier 3 Mastery。
2. 取得該職業系對應的特殊遺產。

兩者採 **AND** 條件；只拿到特殊遺產、或只完成 Tier 3 Mastery，都不能解鎖。

### 隊伍限制

- 同一隊伍不可有兩名角色使用同一個特殊職業。
- 四種不同特殊職業可以同時存在。
- 特殊職業不是 Tier 4，不使用一般 Tier 3 Inspiration 解鎖方式。
- 特殊職業不套用 Tier 1／2 的固定 Mastery 模板。
- 特殊職業的技能繼承與轉職細節之後個別定義。

設計目標是讓特殊職業成為各職業系真正的最終 Build：玩家取得後，應因其完整度與特色而自然傾向保留，而不是靠系統禁止轉走。

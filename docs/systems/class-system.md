# LEGACY COLLECTOR｜職業系統

## 系統頁面責任

本頁只負責呈現**職業結構與職業樹關係**：Tier 階層、四大職業系、轉職路徑、Tier 3 Inspiration Links、Tier 3 隱藏／揭露，以及四個角色記憶形態在職業樹外的位置關係。

本頁**不重複個別職業介紹**。各職業的一般攻擊、主動技能、被動技能、Charge、定位說明與 Mastery Checklist，統一放在「職業熟練系統」頁面與 `data/classes.json` 維護。

角色記憶的完整覺醒規則、角色專屬限制與後續設計，統一放在「角色記憶覺醒系統」頁面。

## 職業階層

一般職業樹維持 Tier 0～Tier 3：

- Tier 0：村民，只存在首次序章／教學。
- Tier 1：基礎職業。
- Tier 2：進階職業。
- Tier 3：隱藏高階職業。

四名主角各自的「XXX 的記憶」顯示在一般 Tier 圈之外，**不屬於 Tier 4**。

## 四大職業系

目前職業樹分為四個 sector：

- 戰士系
- 敏捷系
- 魔法系
- 支援系

職業在同心圓上的角度代表其職業傾向與相鄰關係；實際節點、名稱與連線以頁面下方的互動職業樹為準。

## 一般轉職結構

- Tier 0 → Tier 1：序章後進入基礎職業層。
- Tier 1 → Tier 2：一般晉升依職業角度 ±45° 的合法範圍判定。
- 同 Tier 的一般轉換依相鄰節點規則處理。
- Tier 2 → Tier 3 不使用一般可逆轉職線，而是透過 Inspiration Links 表示解鎖與技能來源關係。

本頁只呈現這些結構關係；轉職時機、Mastery 前置、Charge 補充等 Run 內規則由對應系統頁面負責。

## Tier 3 Inspiration Links

每個 Tier 3 節點都有明確的 Tier 2 Inspiration Links。

Inspiration Links 的用途是：

- 表示該 Tier 3 的解鎖前置來源。
- 表示該 Tier 3 的技能繼承來源。
- 在 UI 上以不同於一般轉職線的方式顯示。

Inspiration Links **不是可逆轉職路徑**。

Tier 3 的個別定位、技能與 Mastery 不在本頁展開，請至職業熟練系統查看。

## Tier 3 顯示規則

Tier 3 正式遊戲中在首次解鎖以前保持隱藏；Prototype 可以為了設計與驗證提前顯示完整外圈。

目前 Tier 3 外圈保留 16 個節點。名稱、設計狀態與完整內容由 `data/classes.json` 與職業熟練系統頁面維護。

## 角色記憶與職業樹

四個「XXX 的記憶」作為角色專屬最終形態，顯示在 Tier 3 圈之外，並各自對應一個原始職業系。

本頁只需要呈現它們與四大職業系的結構位置，不展開角色姓名、昔日稱號、技能、使用限制或完整覺醒流程；這些內容統一由「角色記憶覺醒系統」負責。

## 職業樹 Prototype

下方互動職業樹是本頁的主要內容來源。它負責直接呈現：

- Tier 0～Tier 3 的同心圓位置。
- 四大職業系分布。
- Tier 1 → Tier 2 的一般轉職關係。
- 同 Tier 相鄰轉換。
- Tier 3 Inspiration Links。
- 四個角色記憶與各職業系的對應關係。

點選節點時只顯示與**職業樹結構**有關的資訊，不在此頁重複職業技能、被動、Mastery 或完整角色設定。

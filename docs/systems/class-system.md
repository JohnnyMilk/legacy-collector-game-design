# 遺產收集者｜職業系統

## 系統頁面責任

「職業系統」只負責呈現與規範：

- 職業之間的轉職關係
- 所屬職業系
- 職業定位
- 職業特性
- Tier 與角度
- 一般轉職路徑
- Tier 3 Inspiration Links
- 高 Tier 技能繼承規則

個別職業的主動技能、被動技能、Charge 與 Mastery Checklist 不在此頁展開，統一放在「職業熟練系統」頁面。

舊有「職業描述」欄位已取消。定位與職業特性已足以承擔職業說明功能，後續資料與 UI 不再使用 `summary`／職業描述欄位。

## 職業階層

職業樹保留 Tier 0～Tier 3 的同心圓結構，但 Tier 0「村民」只存在於遊戲序章／教學，不是每次遠征的正常起始職業。

- Tier 0：村民（僅序章／教學使用）
- Tier 1：基礎職業
- Tier 2：進階職業
- Tier 3：全部為隱藏職業

序章中四名主角以村民身分開始，用來完成基礎操作、戰鬥教學與故事導入。序章結束後，村民不再作為一般遠征的起始職業，也不需要 Mastery。

## 正式遠征的起始職業

每次 Run 開始前都會進入「遠征準備」。預設配置為四名主角各使用一個 Tier 1：戰士、斥候、法師、侍祭。

玩家可以替每名主角重新選擇任何已解鎖的職業：

- 可以選擇已解鎖的 Tier 1、Tier 2、Tier 3 或特殊職業。
- 可以讓多名角色使用相同職業，例如四名主角全部使用戰士。
- Run 開始時不需要重新從村民或 Tier 1 逐層走過。
- 只要職業已解鎖，就可以作為新 Run 的起始職業；Mastered 與 Unlocked 是不同狀態。

## 職業定位與職業特性

每個職業保留兩個主要文字欄位：

- **職業定位**：簡短說明該職業在戰鬥中的主要角色，例如「高速機動／先手騷擾」。
- **職業特性**：說明玩家應如何理解與操作這個職業的玩法傾向。

「職業特性」只是玩法定位說明，不是技能，也不提供額外戰鬥效果。

每一個正式職業自身仍只提供 1 個有限 Charge 的主動技能與 1 個被動技能；個別技能內容統一在職業熟練系統頁面查閱。

## 技能繼承

轉職採「完整技能繼承」，不再使用弱化版 Legacy Trait。

- Tier 1：使用自己提供的 1 主動 + 1 被動。
- Tier 2：保留自己提供的 1 主動 + 1 被動，並繼承所有與自己存在正式 Tier 1 → Tier 2 職業連線之 Tier 1 的全部主動與被動技能。
- Tier 3：保留自己提供的 1 主動 + 1 被動，並繼承所有 Inspiration Links 對應 Tier 2 的全部主動與被動技能；這些 Tier 2 已繼承的 Tier 1 技能也一併遞迴帶入。
- 同一來源職業的技能只計一次，不因多條路徑重複取得。
- 目前不限制高 Tier 可持有的技能數量；先以 Prototype 驗證實際操作負擔，再決定是否需要額外技能欄限制。

這套規則讓 Tier 2、Tier 3 明確具有「建立在前階職業之上」的成長感。

## 同心圓職業地圖

職業以同心圓方式呈現：

- 圓心：Tier 0
- 第一圈：Tier 1
- 第二圈：Tier 2
- 最外圈：Tier 3
- 半徑代表 Tier；越外圈代表越高 Tier
- 角度代表職業傾向
- 四個主要職業系為戰士系、敏捷系、魔法系、支援系

Tier 1 → Tier 2 的一般晉升，以目前職業角度 ±45° 作為可選範圍；同 Tier 轉職依職業樹目前定義的相鄰節點規則進行。

Tier 2 → Tier 3 的 Inspiration Links 是解鎖與技能繼承前置關係，不代表可逆轉職路徑。UI 應使用與一般轉職實線不同的顏色／虛線呈現，避免玩家誤以為 Tier 3 可以沿 Inspiration Links 退回 Tier 2。

## Tier 3 的隱藏與首次揭露

正式遊戲在玩家第一次解鎖 Tier 3 以前，**不顯示 Tier 3 的存在**。

- 職業樹 UI 只呈現到 Tier 2，視覺上應讓 Tier 2 看起來像完整職業樹的最外圈。
- 不顯示 Tier 3 外圈、問號節點、`Tier 3` 標籤、Inspiration Links 或「尚未解鎖 Tier 3」之類提示。
- 玩家應能合理相信目前最高只有 Tier 2，而不是被 UI 提前暗示還有下一層。
- 當隊伍第一次滿足任一 Tier 3 的 Inspiration 條件時，才第一次正式揭露 Tier 3。
- 首次揭露時，職業樹 UI 應向外擴張／縮放，顯示新的 Tier 3 外圈。
- 揭露後可顯示 Tier 3 外圈與尚未解鎖的 Tier 3 位置，但未揭露職業仍以隱藏資訊方式呈現。

Prototype 02 為設計與開發驗證用途，因此可以預先顯示完整 Tier 3 外圈；這不代表正式遊戲會提前公開 Tier 3。

## Run 中的轉職時機

戰鬥結束只負責結算 Mastery、恢復與新職業解鎖，不會立即轉職。

每一個 Region 固定只有 **1 個轉職點**，位置原則上設置於該 Region 路程的中段。轉職點不是隨機事件，也不限制角色「可轉職幾次」的額外計數；真正的限制來自每個 Region 只有一次進入轉職點的機會。

基本節奏：

`Region 起點 → 前半段戰鬥／事件 → 轉職點 → 後半段戰鬥／事件 → Boss → 下一 Region`

在轉職點：

- 可以維持目前職業。
- 可以依職業樹路徑與解鎖狀態改變職業。
- 角色目前職業必須已被隊伍完成 Mastery，才可以從該職業沿一般轉職路徑進行正式轉職。
- 新解鎖的 Tier 3 可以立即顯示為已解鎖，但要抵達轉職點才可真正轉入。
- 完成轉職後，該角色新 Build 中所有可用主動技能 Charge 補滿。
- 離開該 Region 的轉職點後，本 Region 不再提供第二個轉職機會；下一次要等下一個 Region 的轉職點。

## Mastery 與轉職

Mastery 是四名主角共用、以職業為單位的隊伍永久進度，並跨 Run 保留。

只要某個職業已被隊伍完成 Mastery，之後任何角色使用該職業時，都視為該職業已 Mastered，不需要每名角色各自重練。

Mastery 的主要用途：

- 允許角色在 Region 轉職點由目前職業進行正式轉職。
- 作為 Tier 3 Inspiration 的共享解鎖條件。

舊版「Mastery 後留下弱化被動 Legacy Trait」規則已取消，僅保留於廢棄舊版草稿。

## Tier 3 與啟發連結

出現在同心圓上的每一個 Tier 3 隱藏職業，至少連結 3 個 Tier 2；部分 Tier 3 可以連結 4 個或更多 Tier 2。

這些 Tier 2 連線代表 Inspiration Links，而不是普通的單一路徑晉升。正式啟發來源以資料中明確指定的 Inspiration Links 為準。

當隊伍共用職業樹已完成該 Tier 3 **所有對應 Tier 2 職業的 Mastery**，該 Tier 3 即完成 Inspiration 並永久解鎖。

- Mastery 為四名主角共用。
- 不需要 Relationship／親密度。
- 不需要額外特殊事件作為一般 Tier 3 解鎖條件。
- 必須完成全部 Inspiration Links，不是任選其中幾個。
- Inspiration Links 數量可以不同，因此部分 Tier 3 自然具有更高解鎖門檻。

目前完整揭露的兩個 Tier 3 範例「影刃術士」與「幻刃魔導士」都使用魔劍士、舞刃者、刺客三個 Tier 2 Inspiration Links。

## Tier 3 與完整通關難度

Tier 3 不作為進入 Final Region 或挑戰 Final Boss 的硬性門檻，但它是正式難度曲線預期的後期戰力層級。

- Region 後段敵人與 Boss 應逐步超出一般 Tier 2 Build 可以輕鬆應付的強度。
- 完成一個完整 Run 的正常預期，是隊伍至少已取得並實際使用部分 Tier 3 職業。
- 純 Tier 2 隊伍仍允許繼續推進並挑戰 Final Region / Final Boss，不由系統禁止。
- 若玩家以沒有 Tier 3 的隊伍完成完整 Run，可視為高難度特殊成就／Report 紀錄。

## 特殊職業

透過遺產直接取得或其他例外來源開啟的職業統一稱為「特殊職業」。

特殊職業不屬於 Tier 0～Tier 3 同心圓職業樹，不使用一般 Tier 3 Inspiration Links / Mastery 解鎖規則；其技能繼承與轉職規則由特殊職業個別定義。

## 隱藏資訊呈現

Tier 3 尚未首次揭露前，正式遊戲完全不呈現 Tier 3 相關 UI 資訊。

第一次 Tier 3 解鎖後，才開放 Tier 3 外圈的持續顯示；之後尚未解鎖的 Tier 3 可顯示為隱藏節點，正式名稱、定位與能力仍維持未揭露狀態。

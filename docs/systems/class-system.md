# LEGACY COLLECTOR｜職業系統

## 系統頁面責任

本頁負責：職業階層、職業系、轉職關係、Tier 3 Inspiration Links、技能繼承、Tier 3 隱藏／揭露，以及四名角色最終「XXX 的記憶」與一般職業樹的關係。

個別職業的一般攻擊、主動、被動、Charge 與 Mastery Checklist 以 `mastery-system.md` 與 `data/classes.json` 為準。

## 職業階層

一般職業樹維持 Tier 0～Tier 3：

- Tier 0：村民，只存在首次序章／教學。
- Tier 1：基礎職業。
- Tier 2：進階職業。
- Tier 3：隱藏高階職業。

四名主角各自的「XXX 的記憶」**不屬於 Tier 4**，也不是一般職業樹的共用特殊職業，而是角色本人專屬的最終記憶形態。

## 起始與自由轉職

第一次正式 Run 可預設戰士、斥候、法師、牧師各一名。後續 Run 可由每名角色選擇任何已永久解鎖、且該角色合法使用的職業。

四名角色都能跨戰士、敏捷、魔法、支援四個職業系使用 Tier 1～3；角色原始職業系不限制一般轉職。

「XXX 的記憶」例外：只允許對應角色本人使用。一旦首次覺醒後永久解鎖，後續 Run 可直接作為該角色起始形態。

## 無裝備規則

角色沒有任何裝備欄。舊版 Relic／遺產、飾品、特殊遺產與收藏館不再參與職業 Build 或解鎖。

## 職業自身技能

每個一般正式職業自身提供：

- 1 個一般攻擊型態。
- 1 個有限 Charge 主動技能。
- 1 個被動技能。

職業特性只是定位文字，不直接提供戰鬥效果。

Charge 基準：

- Tier 1：9 Charge。
- Tier 2：6 Charge。
- Tier 3：自身專屬主動 3 Charge。
- 「XXX 的記憶」：待個別設計。

## 技能繼承

- Tier 1：使用自身主動 + 被動。
- Tier 2：自身技能 + 正式連線 Tier 1 的全部主／被動。
- Tier 3：完整繼承 Inspiration Links 對應 Tier 2 與其祖先主／被動，並加上自己的 1 個 Charge 3 主動與 1 個 Tier 3 專屬被動。
- 同一來源技能去重。
- 一般攻擊不繼承。
- 「XXX 的記憶」技能組與是否繼承一般職業技能，留待角色記憶頁逐一設計，不先假設等同 Tier 3。

## 同心圓職業地圖

一般職業維持同心圓：圓心 Tier 0、第一圈 Tier 1、第二圈 Tier 2、最外圈 Tier 3。角度代表職業傾向，四大 sector 為戰士、敏捷、魔法、支援。

Tier 1 → Tier 2 一般晉升採目前職業角度 ±45°；同 Tier 轉職依相鄰節點規則。

Tier 2 → Tier 3 的 Inspiration Links 是**解鎖 + 技能繼承來源**，不是可逆轉職線。

四個角色記憶形態應顯示在一般 Tier 圈之外，但 UI 要清楚標示它們是「角色記憶」，不是 Tier 4。

## 已確認 Tier 3｜軍團守衛

- 角度：-135°，戰士系。
- Inspiration：騎士、吟遊詩人、煉金術士。
- 定位：前線戰術核心／區域封鎖／隊伍保護。
- 一般攻擊「戰槍」：上下左右 1 個方向、前方直線 2 格；兩格有敵人時各受 1 次物理攻擊；阻擋地形截斷後方格。
- 被動「壁壘陣」：軍團守衛位於自己生成的盾牆周圍 8 格內時，該牆周圍 8 格我方 DEF / MDEF +20%；重疊不疊加。4 面盾牆完整生成且守衛居中，可形成完整 5×5 防護區。
- 主動「盾牆陣」：3 Charge；四個斜角相鄰格各嘗試生成 1 面 HP 1 盾牆。盾牆不可移動、不可進入／穿越／跨越；有單位、召喚物或阻擋地形的格子不生成。
- Mastery：單次成功生成 4 面盾牆 15 次；壁壘陣防護中的我方單位實際承受敵方傷害 30 次。

## Tier 3 Mastery

Tier 3 Mastery 只驗證該職業自己的 Tier 3 專屬主動與被動；不加入完成戰鬥、擊殺數、Elite / Boss 等共通項目，也不要求固定任務數。

## 「XXX 的記憶」解鎖

四名主角各自固定對應一個原始職業系。當某系**全部 Tier 3 Mastery**完成後，該系對應角色取得覺醒資格。

首次實際覺醒還必須在 **Region 4** 走到可選的記憶神殿分支。神殿不是必經路線；玩家可以走別條路而錯過本 Run 的覺醒。

同一 Run 可以覺醒多名角色。首次覺醒後永久解鎖，後續 Run 可直接以該角色自己的「XXX 的記憶」開始。

不存在任何特殊遺產、Relic 或物品前置。

## Final Region

Tier 3 與角色記憶都不是進入 Final Region 的硬性門檻；純 Tier 2 通關仍允許，應視為高難度玩法。角色記憶則屬後期最高階形態之一。

# 遺產收集者｜職業系統

## 職業階層

角色從 Tier 0 開始。

- Tier 0：村民（共同起點）
- Tier 1：基礎職業
- Tier 2：進階職業
- Tier 3：全部為隱藏職業

## 同心圓職業地圖

職業以同心圓方式呈現。

- 圓心：Tier 0
- 第一圈：Tier 1
- 第二圈：Tier 2
- 最外圈：Tier 3
- 半徑代表 Tier；越外圈代表越高 Tier
- 角度代表職業傾向
- 四個主要職業系為戰士系、敏捷系、魔法系、支援系

一般晉升只能往下一個 Tier 移動；同 Tier 轉職則沿同一圓周移動。

Tier 1 → Tier 2 的一般晉升，以目前職業角度 ±45° 作為可選範圍；同 Tier 只能轉換至左右相鄰節點。

## 轉職原則

Mastery 是四名主角共用、以職業為單位的隊伍永久進度。

正式轉職前，角色目前所使用的職業必須已被隊伍完成 Mastery（精通）。

相同 Tier 的職業可以互相轉換，但不能回到較低 Tier。

「解鎖某個職業」與「角色可以立即轉職」是兩件不同的事：即使 Tier 3 已經被啟發或解鎖，欲轉職角色目前所使用的職業仍必須已達 Mastered，才能進行轉職。

## Tier 3 與啟發連結

出現在同心圓上的每一個 Tier 3 隱藏職業，至少連結 3 個 Tier 2 職業。

這些 Tier 2 連線代表該 Tier 3 的 Inspiration Links（啟發連結），而不是普通的單一路徑晉升。Tier 3 的正式啟發來源以資料中明確指定的 Inspiration Links 為準；職業在圓周上的角度則用來呈現其傾向與跨系位置。

因此同心圓同時表達三種資訊：

- 半徑＝Tier
- 角度＝職業傾向
- Tier 2 → Tier 3 連線＝Inspiration（啟發）關係

Tier 3 是真正跨系職業主要出現的階段。某個 Tier 3 可以同時連結不同職業系的 Tier 2，讓它的混合定位直接由職業地圖呈現。

## 啟發（Inspiration）

Tier 3 的解鎖規則採單一、共享的職業樹邏輯。

每個同心圓上的 Tier 3 都有一組 Inspiration Links。當隊伍共用職業樹已完成該 Tier 3 **所有對應 Tier 2 職業的 Mastery**，該 Tier 3 即完成 Inspiration 並解鎖。

- Mastery 為四名主角共用，不區分由哪一名角色完成。
- 不需要角色親密度或 Relationship 條件。
- 不需要額外特殊事件作為一般 Tier 3 的解鎖條件。
- 必須完成該 Tier 3 所列出的全部 Tier 2 Inspiration Links；不是任選其中幾個。

解鎖後仍不代表可以立刻轉職；欲轉入 Tier 3 的角色，目前所使用的職業仍必須已達 Mastered。

### 啟發範例：魔劍士 × 舞刃者 × 刺客

以下是目前正式完整揭露的兩個 Tier 3 範例。兩者使用完全相同的三個 Tier 2 Inspiration Links：

- 魔劍士
- 舞刃者
- 刺客

只要隊伍共用職業樹完成「魔劍士」、「舞刃者」與「刺客」三個職業的 Mastery，就同時符合這兩個 Tier 3 的 Inspiration 條件。

這組三職業共同指向兩個 Tier 3，示範同一組職業 Mastery 可以啟發不同方向的高階職業，並且剛好橫跨敏捷系與魔法系。

#### 影刃術士

- Tier：3
- 系別：敏捷系
- 角度：22.5°
- 定位：高速魔法刺殺
- 職業描述：將魔法附著於高速武器與身法，以接近、斬擊與脫離完成高價值目標的刺殺。
- 核心特性：移動後進行攻擊或技能時獲得額外效果；若目標尚未行動，效果再提升。
- Inspiration Links：刺客、舞刃者、魔劍士

#### 幻刃魔導士

- Tier：3
- 系別：魔法系
- 角度：45°
- 定位：連續魔法近戰
- 職業描述：以魔力生成幻刃與魔法劍影，將高速近戰、連續斬擊與魔法爆發串成完整攻勢。
- 核心特性：普通攻擊或技能命中後累積幻刃；達到條件後，下一個主動技能追加魔法斬擊或產生強化效果。
- Inspiration Links：刺客、舞刃者、魔劍士

## 特殊職業

透過遺產直接取得或啟發的職業，統一稱為「特殊職業」。

特殊職業不屬於目前這棵 Tier 0～Tier 3 同心圓職業樹，因此：

- 不會顯示在同心圓職業樹上。
- 不使用一般 Tier 3 的 Inspiration Links / Mastery 解鎖規則。
- 遺產與遺產能力可以直接和對應特殊職業建立主題或能力關聯。
- 其他例外來源（例如遠征紀錄稱號）也可在之後納入特殊職業系統另外處理。

## 隱藏資訊呈現

未解鎖的同心圓 Tier 3 預設顯示為「？？？」。

即使職業尚未揭露，職業樹仍可顯示／反向標示其 Inspiration Links，讓玩家知道需要精通哪些 Tier 2 職業；正式名稱、定位與能力則在解鎖後才揭露。

目前作為規則範例，已預先完整揭露「影刃術士」與「幻刃魔導士」兩個 Tier 3，以便在職業樹上直接理解 Inspiration Links 與跨系職業的關係。

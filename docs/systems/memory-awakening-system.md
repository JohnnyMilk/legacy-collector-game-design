# 角色記憶覺醒系統（Memory Awakening System）

四名主角各有一個唯一最終「XXX 的記憶」。角色記憶不是 Tier 4，而是對應角色在旅途中整合過去、現在與一路累積經歷後所取得的專屬最終職業形態，只允許該角色本人使用。

角色記憶不是「回到過去的自己」。過去只是角色的一部分；真正使角色完整的是遠征途中經歷、選擇、承擔與理解所留下的遺產。

## 四名主角與記憶形態

- 戰士系男性：**蒼岳・玄武** → **玄武的記憶**。
- 敏捷系女性：**朧月・幻姬** → **幻姬的記憶**。
- 魔法系女性：**阿斯特蕾雅・星賢** → **星賢的記憶**。
- 支援系男性：**賽洛恩・聖主** → **聖主的記憶**。

## 解鎖條件

首次覺醒必須完成該角色原始職業系所涵蓋的**全部 Tier 3 Mastery**；這不只包含單系核心，也包含所有 `sectors` 中含有該系的跨系 Tier 3。

- 玄武／戰士：軍團守衛 + 血煉騎士 + 斷罪士。
- 幻姬／敏捷：斷罪士 + 幻行師 + 影刃術士。
- 星賢／魔法：影刃術士 + 空間魔導士 + 咒縛師。
- 聖主／支援：咒縛師 + 聖律師 + 軍團守衛。

首次覺醒固定在 Region 4 的**可選記憶神殿**進行。順序必須為：

1. 先判定該角色所需 3 個 Tier 3 Mastery 是否全部完成。
2. 全部完成後，才開放該角色的記憶問答。
3. 問答全部通過後，永久解鎖該角色的完整記憶形態。

首次成功覺醒後，後續 Run 可直接選擇該角色已解鎖的記憶形態作為起始職業。

## Region 4 記憶神殿

- 每次 Run 的 Region 4 **只生成 1 座**記憶神殿。
- 神殿屬於可選路線，不是強制主線節點。
- 一座神殿可分別處理多名符合資格的角色，因此同一 Run 允許多名角色完成首次覺醒。
- 每名角色的資格與問答獨立判定。
- 已永久解鎖完整記憶的角色不需要再次接受首次覺醒試煉。
- 沒有符合 Mastery 條件的角色時，不會開放該角色的記憶問答。

## 記憶問答

記憶問答的目的不是知識考試，而是確認玩家確實理解角色一路累積的經歷、情感矛盾與成長。

### 問答規則

- 每名角色固定 **3 題**。
- 每題提供 **3 個選項**。
- 每題至少 **2 個選項屬於正確方向**。
- 其中可以有一個「最完整的理解」與一個「合理且符合角色成長的理解」；剩餘選項才是明顯違背角色一路經歷的錯誤方向。
- 不考事件名稱、數字、冷知識或刻意刁鑽的細節。
- 題目與答案必須簡潔，降低玩家抵達神殿後的額外挫折。
- 該角色 3 題全部通過才完成首次覺醒。
- **答錯後本次 Run 不可重答**，必須等下一個 Run 再次抵達 Region 4 記憶神殿挑戰。

實際題目內容屬於敘事／事件設計資料，可在 Event Design 中逐步編寫；本系統只固定問答的運作規則。

## 完整技能鏈繼承

角色記憶的目的，是讓玩家在最終形態中整合該角色原始職業系的完整最高階能力，因此不另外設計新的主動或被動技能。

角色記憶會：

1. 完整取得 `requiredTier3Ids` 中 **3 個相關 Tier 3 的所有 Tier 3 專屬能力**。
2. 沿這 3 個 Tier 3 各自的 Inspiration／職業繼承鏈，**遞迴取得所有對應 Tier 2 主動與被動技能**。
3. 再由這些 Tier 2 繼續向下，**完整取得所有對應 Tier 1 主動與被動技能**。
4. 相同來源職業只計一次，維持既有 `deduplicateBySourceClass` 規則。
5. **一般攻擊不屬於繼承內容**；記憶形態自己擁有 1 個專屬一般攻擊。
6. 記憶形態**不新增其他主動技能、不新增其他被動技能，也不再設 Mastery**。
7. 繼承的主動技能沿用其來源職業既有 Charge 規則。

因此角色記憶是一條完整技能鏈的整合終點，而不是在 Tier 3 之後再追加一層新的技能套件。

## 四個記憶形態的一般攻擊

### 玄武的記憶｜蒼岳

- 傷害類型：物理。
- 選擇上下左右一個方向。
- 攻擊角色前方第一排**橫向排列的 3 格**。
- 三格中的敵人各承受一次完整的一般物理攻擊傷害。
- 傷害不在三格之間分攤。

### 幻姬的記憶｜朧月

- 傷害類型：物理。
- 可指定距離 **4 格內**的單一敵人。
- 造成一次完整的一般物理攻擊傷害。
- 不穿透、不附帶位移，也不額外追加特殊效果。

### 星賢的記憶｜阿斯特蕾雅

- 傷害類型：魔法。
- 可指定距離 **2 格內的敵方單位**，不能指定空地。
- 以被指定敵人所在格為中心形成 **3×3、共 9 格**攻擊區域。
- 本次一般攻擊的總魔法傷害固定平均分成 9 份，每格對其中的敵方單位造成 `1/9` 傷害。
- 空格或沒有敵方單位的格子，其分配到的傷害直接浪費，不重新分配給其他敵人。

### 聖主的記憶｜賽洛恩

- 攻擊距離：**1 格**。
- 只能指定相鄰友方單位，**不能指定自己**。
- 不造成傷害。
- 將該次一般攻擊原應造成的數值以 **1:1** 轉為 HP 治療量。
- 治療的同時解除目標身上的異常狀態。

## Party Composition

角色記憶在隊伍職業組合中只視為角色的**原始單一職業系**，固定貢獻 **1 Count**。即使它繼承的 Tier 3 包含雙系職業，也不額外取得那些 Tier 3 的第二職業系 Count。

- 玄武的記憶：Warrior +1。
- 幻姬的記憶：Agile +1。
- 星賢的記憶：Magic +1。
- 聖主的記憶：Support +1。

因此四名主角若全部使用自己的記憶形態，隊伍 Count 為 `1 / 1 / 1 / 1`，會依 Party Composition 規則觸發四系均衡加成。

## 系統完成狀態

角色記憶覺醒系統的核心規則已完成確認：角色與記憶名稱、Tier 3 Mastery 解鎖條件、Region 4 單一記憶神殿、低挫折記憶問答、完整技能鏈繼承、四種專屬一般攻擊、永久解鎖與 Party Composition 均已定義。

後續仍可在獨立的敘事／事件設計頁補充實際問答題目、神殿視覺演出、角色對話與場景內容；這些屬於內容製作，不影響本系統規則已完成的狀態。

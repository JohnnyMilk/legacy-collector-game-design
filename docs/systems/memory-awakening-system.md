# 角色記憶覺醒系統（Memory Awakening System）

## 系統定位

四名主角在故事開始時失去記憶，並以 Tier 0「村民」身分重新開始。四人各自原本代表戰士、敏捷、魔法、支援其中一個職業系，過去身份屬於英雄級、王者級或同等層級的存在；正式姓名、稱號與完整故事後續另行定義。

遊戲中的 Tier 1～3 是四名主角在輪迴中重新學習、重新理解並逐步接近過去力量的道路。四名主角都可以自由跨職業系發展，不受自己原始職業系限制。

## 「XXX 的記憶」

每名主角各有一個唯一的最終記憶形態，暫以「XXX 的記憶」表示，其中 XXX 為該角色正式姓名。

- 「XXX 的記憶」不是一般 Tier 4。
- 它代表角色找回自己原本身份與力量後的專屬形態。
- 每個「XXX 的記憶」只允許對應角色本人使用。
- 其他三名主角即使完成相同職業系的所有 Mastery，也不能轉為該角色的記憶。
- 四個記憶形態分別對應戰士、敏捷、魔法、支援四大職業系。
- 記憶形態的正式名稱、過去稱號、技能、數值與完整身份目前全部待後續獨立設計。

## 解鎖條件

要首次覺醒某名角色的「XXX 的記憶」，必須同時滿足：

1. 該角色所對應職業系的全部 Tier 3 職業均已完成 Mastery。
2. 在同一次 Run 中抵達 Region 4 的「記憶神殿」類特殊節點。
3. 進入節點後由系統檢查該職業系 Mastery 條件；符合時，對應角色可完成記憶覺醒。

不再需要任何特殊遺產、裝備或物品作為解鎖條件。

## Region 4 神殿規則

- 記憶神殿只會出現在 Region 4。
- 神殿不是必經路線，而是 Roguelike 地圖中的可選分支節點。
- 玩家可以選擇其他路線，因此某次 Run 完全可能不經過神殿。
- 同一個 Run 可以覺醒多名角色的記憶，只要各自對應職業系都已完成全部 Tier 3 Mastery，且本次路線實際提供並進入可完成覺醒的神殿節點。
- 具體神殿數量、是否一座神殿可處理多個職業系、節點生成方式與地圖機率目前待 Region 4 設計時再定義。

## 永久解鎖

「XXX 的記憶」第一次成功覺醒後永久解鎖，跨 Run 保留。

之後新的 Run 可以直接選擇已解鎖的「XXX 的記憶」作為該角色的起始職業／形態，不需要再次前往 Region 4 神殿，也不需要重複完成覺醒儀式。

這表示神殿負責的是**首次找回記憶**，不是每輪遊戲都必須重新取得的資源。

## 與輪迴敘事的關係

Party Wipe 或 Run 結束後，四名主角會再次進入下一輪世界循環；職業 Mastery、職業解鎖與已找回的角色記憶則作為跨 Run 的永久進度保留。

敘事上可理解為：角色即使再次進入輪迴，已真正找回的部分不再完全消失。

## 最終戰定位

「XXX 的記憶」代表四名主角各自最完整的身份恢復，是挑戰 Final Region 與 Final Boss 的最高階角色形態之一。

系統不強迫玩家一定要讓四人全部覺醒才能進入 Final Region；實際 Final Boss 平衡、是否存在全記憶隊伍的特殊演出或結局，後續再定義。

## 尚未定義

- 四名主角正式姓名。
- 四名角色各自的過去身份與稱號。
- 四個「XXX 的記憶」的職業名稱／顯示名稱。
- 記憶形態的技能、被動、一般攻擊與 Charge。
- Region 4 神殿的正式名稱、數量、視覺與生成規則。
- 記憶覺醒的演出、事件文本與故事揭露內容。
- Final Boss 與四名角色過去身份之間的真實關係。

# 戰鬥系統（Combat System）

## 系統定位

**LEGACY COLLECTOR** 採用回合制戰棋戰鬥。

核心：
- 方格地圖
- 依 AGI 每輪重算的行動順序
- 職業定位與技能繼承
- 有限 Charge 主動技能
- 地形與站位策略
- 四人當前職業系組合所形成的隊伍被動（具體效果待獨立 Prototype 定義）

角色沒有裝備欄；舊版 Relic／遺產不參與戰鬥 Build 或戰鬥結算。

## 戰鬥流程

1. 進入戰鬥地圖。
2. 每輪依 AGI 計算存活單位行動順序。
3. 角色依一般行動規則執行移動、普通攻擊、主動技能或 Wait。
4. 即時更新本 Run 紀錄與可歸屬職業的長期戰績／Mastery 進度。
5. 單位 HP 歸零時先結算死亡觸發／復活；確認四名角色在復活結算後皆正式死亡，才判定隊伍全滅。
6. 戰鬥結束後正式判定 MASTERED、新職業解鎖與其他戰後結算；不直接轉職。

## 勝利條件

不同戰鬥可以使用不同目標，例如：

- 消滅所有敵人。
- 擊敗指定敵人／Boss。
- 抵達指定位置。
- 完成其他明確的地圖目標。

Final Region 的最終目標是擊敗 Final Boss。

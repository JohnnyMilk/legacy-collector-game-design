# 舊版草稿｜Relic／遺產系統（已取消）

> **狀態：ARCHIVED / CANCELLED**  
> 本頁只保留歷史設計參考。現行 LEGACY COLLECTOR 不存在 Relic／遺產裝備、修復、收藏館、掉落或特殊遺產解鎖系統。

## 舊版核心概念

早期版本曾規劃：

- 每名主角有 1 個飾品遺產欄位。
- 遺產具備發現、修復、完全激活等長期進度。
- 遺產收藏跨 Run 保留。
- 四大職業系各有特殊遺產，用於搭配 Tier 3 Mastery 解鎖最終特殊職業。
- 已發現遺產保存於收藏館／Reliquary。

以上全部已取消，不得再作為現行規格或 Prototype 實作依據。

## 取消原因

遊戲的 Build 與長期成長重新集中到：

- 職業轉換。
- 完整技能繼承。
- 職業 Mastery。
- 四人當前職業系的隊伍組合。
- 四名角色各自的「XXX 的記憶」。

角色因此不再需要任何裝備欄，避免讓職業核心被額外裝備管理稀釋。

## 「Legacy」仍然存在，但只屬於故事

取消 Relic 系統不代表故事中不能存在遠古 Legacy、古代遺留物或最後的 Legacy。

現行敘事核心把「Legacy」提升為世界謎團與結局意象：Final Boss 之後的最終 Legacy 不是裝備，而是一句話／一個理解，提醒角色與玩家不要只追逐終點，也要享受抵達終點以前的過程。

# 遺產收集者｜遺產系統

## 核心定位

遺產不是一般裝備，而是遊戲世界與角色長期成長的核心收藏。

每名主角有一個遺產欄位。每次正式 Run 開始前，玩家在遠征準備階段替四名主角各選擇一件目前可用的遺產，作為本次遠征的「飾品遺產」。

不同角色可以依本次 Build 需求搭配不同遺產；實際可否重複裝備同一件一般遺產，待遺產唯一性規則另外定義。

## 遺產狀態

### 發現

玩家首次取得遺產時，只能使用部分能力。

### 修復

透過完成旅程與事件逐步恢復能力。

### 完全激活

完成多次完整歷程後，遺產展現完整力量。

## 每次 Run 的配置

遺產收藏與修復進度跨 Run 永久保留，但每次 Run 實際由哪名角色攜帶哪件遺產，會在遠征準備階段重新選擇。

因此：

- 收藏／修復狀態屬於長期 Meta Progression。
- 本次攜帶配置屬於單次 Run Build。
- 遠征中途的遺產更換時機尚待另外定義；目前至少確認 Run 開始前可自由配置。

## 特殊遺產與最終特殊職業

四大職業系各有一個對應的**特殊遺產**，分別連結戰士系、敏捷系、魔法系、支援系的最終特殊職業。

特殊遺產本身**不會直接解鎖特殊職業**。每個最終特殊職業必須同時滿足：

1. 完成該職業系要求的全部 Tier 3 Mastery。
2. 取得該職業系對應的特殊遺產。

兩者採 AND 條件。只取得遺產但尚未完成該系 Tier 3 Mastery，特殊職業仍維持鎖定；反之亦然。

四個最終特殊職業獨立存在於 Tier 0～Tier 3 同心圓之外，不是 Tier 4。

同一隊伍不可重複使用同一個特殊職業；四個不同特殊職業可以同時存在。

特殊職業的技能繼承、是否需要額外成長，以及特殊遺產在解鎖後是否仍需裝備，之後再個別定義。

## 收藏館

已發現的遺產會永久記錄於收藏館。

即使本次遠征失敗，也不會失去已發現的遺產紀錄與既有長期進度。

## 設計目的

遺產提供跨 Run 的長期目標，同時讓每次遠征開始前的遺產配置成為 Build 構築的重要部分。特殊遺產則進一步與 Tier 3 高階 Mastery 合流，形成四大職業系的最終職業解鎖目標。

# 遺產收集者｜遺產系統

## 核心定位

遺產不是一般裝備，而是遊戲世界與角色長期成長的核心收藏。

每名主角有一個遺產欄位。每次正式 Run 開始前，玩家在遠征準備階段替四名主角各選擇一件目前可用的遺產，作為本次遠征的「飾品遺產」。

不同角色可以依本次 Build 需求搭配不同遺產；實際可否重複裝備同一件遺產，待遺產唯一性規則另外定義。

## 遺產狀態

### 發現

玩家首次取得遺產時，只能使用部分能力。

### 修復

透過完成旅程與事件逐步恢復能力。

### 完全激活

完成多次完整歷程後，遺產展現完整力量。

## 每次 Run 的配置

遺產收藏與修復進度跨 Run 永久保留，但每次 Run 實際由哪名角色攜帶哪件遺產，會在遠征準備階段重新選擇。

因此：

- 收藏／修復狀態屬於長期 Meta Progression。
- 本次攜帶配置屬於單次 Run Build。
- 遠征中途的遺產更換時機尚待另外定義；目前至少確認 Run 開始前可自由配置。

## 特殊職業

部分遺產可以直接啟發或解鎖「特殊職業」。

特殊職業不屬於一般 Tier 0～Tier 3 同心圓職業樹，也不使用一般 Tier 3 的 Inspiration Links 解鎖規則。

一旦特殊職業被永久解鎖，後續 Run 可依其個別規則在遠征準備階段選用。

## 收藏館

已發現的遺產會永久記錄於收藏館。

即使本次遠征失敗，也不會失去已發現的遺產紀錄與既有長期進度。

## 設計目的

遺產提供跨 Run 的長期目標，同時讓每次遠征開始前的遺產配置成為 Build 構築的重要部分。

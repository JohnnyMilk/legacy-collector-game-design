# 遠征系統（Expedition System）

## 系統定位

遠征是《遺產收集者》的主要 Roguelike 循環。

玩家從遠征準備開始，經過多個 Region 與節點，直到完成最終目標。

## 序章與正式 Run

遊戲最初有一次序章／教學流程。

序章中四名主角以 Tier 0「村民」身分開始，用來導入故事與基本操作。序章結束後，村民不再作為一般 Run 的起始職業。

之後每次正式 Run 都從「遠征準備」開始。

## 遠征準備

每次 Run 開始前，玩家替四名主角完成以下配置：

- 選擇本次遠征的起始職業。
- 為每名主角選擇一件可用的遺產作為飾品遺產。

職業預設配置為四個 Tier 1 各一名：

- 戰士
- 斥候
- 法師
- 侍祭

這只是預設配置。玩家可以將任一角色改成任何已解鎖的職業，也可以讓多名角色使用同一職業，例如四名角色全部選擇戰士。

已解鎖職業可以直接作為新 Run 的起始職業，不需要重新從村民或較低 Tier 走起。

## 遠征結構

基本流程：

遠征準備 → Region 1 → 休整點 → Region 2 → 休整點 → Region 3 → 休整點 → Region 4 → 休整點 → Final Region

每個 Region 具有：
- 節點選擇
- 戰鬥
- 特殊事件
- Boss 戰

休整點是 Region 之間的固定準備節點，不屬於隨機事件。

## 節點規則

- 採用不可返回設計。
- 節點通過後消失。
- 玩家需要做出路線選擇。
- 轉職不依賴隨機事件節點。

## 休整點

正式遠征中的轉職只在固定休整點進行。

休整點主要用途：

- 查看 Mastery 與新解鎖職業
- 依目前職業樹規則進行轉職
- 調整進入下一個 Region 前的隊伍配置
- 處理其他之後定義的遠征準備功能

戰鬥結束後即使完成 Mastery 或解鎖 Tier 3，也只會更新狀態；角色要到下一個休整點才可實際轉職。

## Region 設計

目前規劃：
- 4 個主要 Region
- 1 個 Final Region

每個 Region 同時提供戰術挑戰、Mastery 累積與路線選擇。

## 戰鬥結算

每場戰鬥結束後：
- 恢復固定 HP／技能 Charge（依戰鬥系統最終規格）。
- 更新 Mastery Checklist。
- 檢查新的 Tier 3 Inspiration 或其他職業解鎖。
- 不直接進行轉職。

## 遠征失敗

條件：
- 四名角色全部死亡。

失敗仍會產生 Report，且跨 Run 的 Mastery、已解鎖職業、遺產收藏與其他 Meta Progression 不會因此消失。

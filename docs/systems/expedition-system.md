# 遠征系統（Expedition System）

## 系統定位

遠征是《遺產收集者》的主要 Roguelike 循環。

玩家從遠征準備開始，經過多個 Region 與節點，直到完成最終目標。

## 序章與正式 Run

遊戲最初有一次序章／教學流程。四名主角以 Tier 0「村民」身分開始，用來導入故事與基本操作。序章結束後，村民不再作為一般 Run 起始職業。

之後每次正式 Run 都從「遠征準備」開始。

## 遠征準備

每次 Run 開始前：

- 為四名主角選擇本次遠征起始職業。
- 為每名主角選擇一件可用的飾品遺產。

預設職業配置為戰士、斥候、法師、牧師各一名；玩家可改成任何已解鎖職業，也可讓多人使用相同職業。

## 遠征結構

基本流程：

`遠征準備 → Region 1 → Region 2 → Region 3 → Region 4 → Final Region`

每個 Region 內部的標準節奏：

`Region 起點 → 前半段戰鬥／事件 → 固定轉職點 → 後半段戰鬥／事件 → Boss → 下一 Region`

每個 Region 固定只有 **1 個轉職點**，原則上配置在路程中段。它不是隨機事件節點。

## 節點規則

- 採不可返回設計。
- 節點通過後不能回頭重複刷取。
- 玩家需要做出路線選擇。
- 每個 Region 的轉職點為固定節奏節點，不依賴隨機事件。

## 轉職點

正式遠征中的轉職只在 Region 內的固定轉職點進行。

轉職點主要用途：

- 查看 Mastery 與新解鎖職業。
- 依職業樹規則進行轉職。
- 重新確認後半段 Region 的隊伍 Build。

不另外限制角色的轉職次數計數；轉職頻率由「每個 Region 只有一個轉職點」控制。玩家離開該點後，本 Region 不再提供第二次轉職機會。

角色完成轉職後，新職業 Build 中所有可用主動技能 Charge 補滿。

戰鬥結束後即使完成 Mastery 或解鎖 Tier 3，也只更新狀態；角色要到該 Region 的轉職點，或若已錯過則等下一個 Region 的轉職點，才可實際轉職。

## Region 設計

目前規劃：

- 4 個主要 Region
- 1 個 Final Region

每個 Region 同時提供戰術挑戰、Mastery 累積、路線選擇與一次中段 Build 調整機會。

## 戰鬥結算

每場戰鬥結束後：

- 恢復固定 HP／技能 Charge（依戰鬥系統最終規格）。
- 更新 Mastery Checklist。
- 檢查新的 Tier 3 Inspiration 或其他職業解鎖。
- 不直接進行轉職。

## 遠征失敗

四名角色全部死亡時該 Run 失敗。

失敗仍會產生 Report；跨 Run 的 Mastery、已解鎖職業、遺產收藏與其他 Meta Progression 不會因此消失。

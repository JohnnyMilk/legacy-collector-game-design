# 隊伍職業組合系統（Party Composition System）

## 系統定位

本系統用來承接角色取消裝備欄與 Relic Build 後的隊伍構築深度。

遊戲不再透過遺產、飾品或其他裝備提供角色額外能力；玩家的主要 Build 來源改為：目前職業、技能繼承、四人隊伍的職業系配置，以及戰鬥中的站位與行動決策。

## 核心規則

- 四名主角目前所使用職業的職業系，會共同形成一個「隊伍職業組合」。
- 職業系目前分為戰士系、敏捷系、魔法系、支援系。
- 判定依據是角色**當前職業所屬職業系**，不是角色原本的身份或記憶歸屬。
- 同一角色可以跨職業系轉職，因此同一名主角在不同 Run 或不同 Region 可以參與不同組合。
- 隊伍職業組合將提供團隊被動能力，但目前**不定義任何具體組合、數值或效果**。
- 此系統不新增裝備欄，也不要求玩家攜帶任何物品。

## 設計目的

本系統的核心不是增加額外裝備管理，而是讓「四個位置要放什麼職業」本身成為 Build 決策。

同一套已解鎖職業，可以因四人配置不同而形成不同隊伍方向；玩家應透過職業搭配，而不是物品堆疊，建立每次 Run 的差異。

## Prototype / Demo 預留

後續 Demo 將在本頁逐步驗證：

- 不同職業系數量組合的辨識方式。
- 不同組合可啟動哪些隊伍被動。
- 同時存在多個符合條件組合時的優先序或並存規則。
- 角色轉職後，隊伍被動如何即時重新計算。
- 「XXX 的記憶」加入隊伍後，應以何種職業系參與組合判定。
- UI 如何讓玩家在不增加操作負擔的情況下理解目前啟動的隊伍被動。

## 尚未定義

- 組合清單。
- 被動名稱。
- 被動效果與數值。
- 是否存在 4 系各 1、2+2、3+1、單系 4 人等特殊組合。
- 多個組合效果是否能同時啟動。

以上全部保留給後續 Prototype 設計，不在目前規格中先行假設。

# 職業能力值系統（Class Stats System）

## 設計目的

本作沒有角色等級、自由配點與裝備成長，因此角色的戰鬥基礎數值由**當前職業固定決定**。

換職業＝換成該職業的固定 Stat Template。

設計採低數值、容易心算的戰棋尺度：

- HP 常見約 40～70。
- ATK / MATK / DEF / MDEF / AGI 多落在 15～50。
- 多數數值使用 5 的倍數，讓 +10% / +20% / +25% / +30% 等修正仍容易人工計算。
- Tier 3 與 Memory Form 不以全面數值膨脹壓過 Tier 1 / 2；主要強度來自技能、Charge、繼承與戰術能力。

## 能力值定義

| Stat | 功能 |
|---|---|
| HP | 最大生命值 |
| ATK | 物理攻擊力 |
| MATK | 魔法攻擊力與基礎治療量 |
| DEF | 物理防禦 |
| MDEF | 魔法防禦 |
| AGI | 每輪行動順序 |
| MOVE | 一般移動格數 |
| HIT | 隱藏命中值 |
| EVA | 隱藏迴避值 |

HIT / EVA 的正式命中公式與暴擊規則由「傷害系統」維護。

## 固定數值結算順序

能力值與傷害相關修正統一依下列順序處理：

1. 職業固定基礎值。
2. Party Composition 修正。
3. Buff / Debuff。
4. 技能或被動的特殊修正。
5. 套用傷害／治療公式。
6. 若觸發暴擊，再套用暴擊倍率。
7. 最終四捨五入至整數。

所有中間百分比計算保留小數，不在中途逐步取整。

## 最低傷害

- 一般物理／魔法傷害最低為 **1**。
- 即使 DEF / MDEF 高於攻擊公式結果，只要該攻擊不是明確的免疫／無效效果，最終仍造成 1 點傷害。
- 只有技能或狀態明確定義「0 傷害」「免疫」「完全無效」時才能低於 1。

## 治療與 Max HP

- 治療不能使 Current HP 超過 Max HP。
- 超過 Max HP 的治療量直接浪費。
- 不建立通用 Overheal Shield；若未來技能需要，必須由該技能明確定義。

## 轉職時 HP 處理

轉職時保持目前 HP 百分比，不補滿生命。

例：

- 原職業 Max HP 60，Current HP 30 → 50%。
- 新職業 Max HP 70。
- 轉職後 Current HP = 35。

規則：

- Current HP 依原本 HP 百分比換算至新 Max HP。
- 換算結果最後四捨五入。
- 存活角色透過轉職不得因此死亡；轉職後 Current HP 最低保留 **1 HP**。
- 其他基礎能力值立即改用新職業固定值。

## AGI 修正與 Timeline

- 最終 AGI 可受到 Party Composition、Buff / Debuff、技能與被動修正。
- 每輪開始時，以當下所有存活單位的最終 AGI 重新建立該輪行動順序。
- 輪中發生的 AGI 增減不重新排列當輪已建立的 Timeline。
- AGI 變化從**下一輪**開始反映在新的行動順序。
- 若未來技能需要立即插隊、額外行動或重排 Timeline，必須由技能明確定義為例外。

## HIT / EVA 修正範圍

- HIT / EVA 可因技能、Buff / Debuff 等暫時高於或低於目前職業表的基礎範圍。
- HIT 可高於 100；普通攻擊最終命中率仍依傷害系統規則封頂 100%。
- EVA 可高於 30；普通攻擊最終命中率仍依傷害系統規則最低封底 80%，除非技能明確突破此限制。

## 百分比與四捨五入

- 中間百分比計算保留小數。
- 最終能力值、傷害、治療、HP 百分比換算與暴擊結果才四捨五入至最接近整數。
- 不因基礎數值低而額外設定「百分比至少 +1」；目前 Stat 尺度已刻意設計成常用百分比修正具有實際差異。

## Demo 使用原則

Combat Demo 不使用臨時角色數值；應直接讀取正式的固定職業能力值資料。

首輪 Demo 優先驗證：

1. 固定職業 Stat Template。
2. MOVE 與 9×9 Grid。
3. AGI Timeline。
4. 固定傷害／治療。
5. HIT / EVA。
6. 包圍暴擊。
7. Party Composition 百分比修正。
8. 技能與被動對 Stat / Damage 的修正。

## 平衡狀態

以上數值為**正式 Demo 基準值**，不是最終商業版不可調整數字。若 Combat Demo 顯示 TTK、命中率、治療量、職業差異或特定技能組合失衡，可依實測調整；任何調整都應同步此頁與資料檔。

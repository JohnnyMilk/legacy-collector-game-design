# 遠征報告系統（Report System）

## 系統定位

Report 是記錄玩家每次遠征歷程的 Meta 系統。

失敗的旅程也具有價值，會成為未來探索的一部分。

## 記錄內容

包含：
- 遠征結果
- 完成 Region 數量
- 角色死亡紀錄
- 職業轉換紀錄
- 遺產發現紀錄
- 傷害與戰鬥統計

## 遠征稱號

每次旅程會根據表現產生稱號。

不一定需要完成遊戲才能獲得稱號。

例如：
- 特殊職業組合
- 極端生存方式
- 特殊失敗條件

都可能產生獨特評價。

## 長期價值

Report 可以作為：
- 玩家歷史收藏
- 成就來源
- 未來解鎖條件

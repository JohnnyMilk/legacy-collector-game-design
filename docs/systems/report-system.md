# LEGACY COLLECTOR｜遠征報告系統（Report System）

## 系統定位

Report System 同時承接單次 Run 的故事紀錄與跨 Run 的職業戰績檔案。失敗的輪迴也具有價值，會成為玩家完整歷史的一部分。

系統分成兩層：

1. **本次遠征紀錄（Expedition Record）**：只記錄目前 Run。
2. **職業戰績檔案（Class Combat Archive）**：以職業為單位跨 Run 永久累積。

## 本次遠征紀錄

可記錄：

- 遠征結果與完成 Region 數量。
- 角色死亡紀錄。
- 職業使用與轉換紀錄。
- 四人當前職業系組合與組合變化。
- 地圖節點與特殊事件。
- Region 4 記憶神殿進入紀錄。
- 「XXX 的記憶」首次覺醒紀錄。
- Named Enemy／Mini Boss／Boss 遭遇與擊敗。
- 傷害、治療、擊倒、受擊、技能使用等戰鬥統計。
- Mastery 在本 Run 增加的進度。
- Final Boss 結果與其他可用於稱號／成就的特殊行為。

舊版「遺產發現、取得、裝備、使用、修復」欄位全部取消，不再寫入現行 Expedition Record。

## 職業戰績檔案

職業戰績檔案是四名主角共用、以職業分類的永久長期紀錄。內容不限於戰鬥，可以包含探索、事件、特定敵人與職業玩法行為。

Mastery 是這些統計的門檻視圖，不是戰績檔案本身；即使 Mastery 已完成，底層數值仍可繼續累積。

尚未揭露的 Tier 3、角色記憶或其他隱藏內容，不得透過玩家可見的統計名稱提前曝光。

## 與 Mastery 的資料關係

同一筆事件可以同時更新本次遠征紀錄與職業戰績檔案；只有被 Mastery Checklist 使用的統計才檢查門檻。

Checklist 達標可立即顯示完成；MASTERED 狀態仍於戰鬥結束後正式結算。

## 隊伍職業組合紀錄

隊伍職業組合系統未來會依四名角色當前職業系啟動團隊被動。Report 可以保存本 Run 曾使用過哪些組合、持續多久、在哪些關鍵戰鬥使用，但在組合規則尚未定義以前不建立假資料欄位或數值評分。

## 記憶覺醒紀錄

首次在 Region 4 記憶神殿覺醒「XXX 的記憶」屬重大長期事件，應同時：

- 寫入本次遠征紀錄。
- 更新該角色永久記憶解鎖狀態。
- 在遠征報告中作為重要事件呈現。

後續 Run 直接使用已解鎖記憶時，只記錄本 Run 的使用狀態，不重複記為首次覺醒。

## 遠征報告

Run 結束時，本次遠征紀錄封存為遠征報告。報告描述這一趟旅程，而不是只列長期總數。

可呈現：關鍵職業轉換、隊伍組合、Mastery 完成、Tier 3 解鎖、記憶覺醒、角色死亡、特殊節點、Boss 與 Final Boss 結果，以及本 Run 最有代表性的戰術行為。

## 遠征稱號

稱號優先依本 Run 的突出內容產生，例如特殊隊伍組合、極端生存方式、純 Tier 2 通關、單 Run 特殊技能紀錄、記憶覺醒或特殊地圖路線。

## 資料保留

- 本次遠征紀錄：每 Run 重建，結束後封存。
- 職業戰績檔案：跨 Run 永久累積。
- 遠征報告：每 Run 各自永久保存。
- 記憶首次覺醒：永久保存。
- Relic／遺產裝備與收藏資料：**現行系統不存在，不保存。**

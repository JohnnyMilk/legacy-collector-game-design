# 遠征報告系統（Report System）

## 系統定位

Report System 同時承接「單次 Run 的故事紀錄」與「長期職業戰績檔案」。失敗的旅程也具有價值，會成為玩家完整歷史的一部分。

這裡的「戰績」不是只指戰鬥數字，而是玩家使用某個職業經歷過的**完整遊戲歷程統計**；同樣地，本次遠征紀錄也不只保存戰鬥資料。

本系統明確區分兩個資料層：

1. **本次遠征紀錄（Expedition Record）**：只記錄目前這一個 Run 的短期完整歷程。
2. **職業戰績檔案（Class Combat Archive）**：跨 Run 永久累積、以職業為單位的長期完整歷程紀錄。

## 本次遠征紀錄

本次遠征紀錄從 Run 開始建立，到該 Run 成功或失敗時封存為遠征報告。

它可以記錄所有值得回顧、分析或產生稱號的事件，不限定於 Mastery 或戰鬥內容，例如：

- 遠征結果與完成 Region 數量
- 角色死亡紀錄
- 職業使用與轉換紀錄
- 遺產發現、取得與使用紀錄
- 地圖節點與特殊事件進入次數
- 特定事件的選擇、完成或失敗次數
- 固定 Named Enemy／小 Boss／Boss 的遭遇與擊敗次數
- 各職業在本 Run 的行為與統計增量
- 傷害、治療、擊倒、受擊、技能使用等戰鬥統計
- Mastery 條件在本 Run 增加了多少進度
- 其他未來可用於遠征報告、稱號、成就或解鎖的探索／事件紀錄

這一層是**短期內容**，描述本次遠征真正發生了什麼，而不是單純的戰鬥計分板。

## 職業戰績檔案（Class Combat Archive）

職業戰績檔案是**長期、整個遊戲生命週期**的永久紀錄，四名主角共用，並以職業分類。

雖然目前沿用「戰績」名稱，但內容範圍是玩家使用該職業時留下的完整歷程，不限定於戰鬥。可記錄的資料類型包含：

- 戰鬥：完成戰鬥、擊倒、受擊、傷害、治療、技能使用、Elite / Boss 參與等。
- 探索：進入某類地圖事件、探索特殊節點、到達特定區域等。
- 事件：觸發、完成或選擇特定事件與事件分支的次數。
- 特定敵人：遭遇或擊敗固定 Named Enemy、小 Boss、Boss 的次數。
- 職業行為：被動觸發、主動技能達成特定結果、特殊戰術條件等。
- 其他未來需要長期保存、可與職業使用狀態關聯的遊戲統計。

它同時是 Mastery 背後的統計資料來源，但 **Mastery 只使用其中一部分欄位**。換句話說，職業戰績檔案的用途比 Mastery 更廣，不應只為了熟練度任務而存在。

例如戰士可以長期記錄：

- 完成戰鬥：67 場
- 擊倒敵人：100 名
- 參與 Elite / Boss：18 次
- 承受敵方攻擊：142 次
- 「堅守」生效期間受擊：76 次
- 「猛擊」擊倒敵人：51 次
- 進入特定戰場事件：12 次
- 擊敗某個固定小 Boss：7 次

即使戰士 Mastery 的「擊倒敵人」只要求 45 名，底層仍會繼續統計到 100、200 或更高，不因 Mastery 完成而停止。

玩家可以查看已揭露職業的職業戰績檔案；尚未揭露的隱藏職業不出現在檔案 UI 中。若玩家尚未知道某個隱藏事件、職業或內容的存在，UI 也不應藉由統計名稱提前暴露該資訊。

## 與 Mastery 的資料關係

Mastery 是職業戰績檔案中的**門檻視圖**，不是職業戰績檔案本身。

每一個 Mastery Checklist 都指向一項已經被系統長期統計的資料；達到門檻後 Checklist 完成，但原始統計仍繼續增加。

同一筆遊戲事件可能同時寫入：

- 本次遠征紀錄：增加本 Run 統計。
- 職業戰績檔案：若該事件可歸屬目前使用職業，增加跨 Run 永久統計。
- Mastery 顯示：只有該統計被某個 Mastery Checklist 使用時，才檢查是否達到門檻。

因此不是所有被記錄的事件都一定是 Mastery 任務，也不是所有長期統計都必須顯示在 Mastery 頁面。

Checklist 達標時可以立即顯示完成並增加 `Mastery X / Y`；只有 **MASTERED 狀態本身**需要等戰鬥結束後正式結算。

角色死亡不會影響已寫入的紀錄，也不會取消已達成的 Mastery 條件。

## 遠征報告

Run 結束時，本次遠征紀錄被整理成一份正式遠征報告。

報告重點不是重複顯示所有長期總數，而是描述**這一趟旅程**：

- 哪些角色與職業最活躍
- 本 Run 的關鍵戰鬥表現
- 走過哪些特殊事件、地圖節點與重要選擇
- 遭遇／擊敗了哪些固定 Named Enemy、小 Boss 或 Boss
- 是否有角色死亡或殘隊通關
- 本 Run 完成了哪些 Mastery 條件或取得 MASTERED
- 解鎖了哪些 Tier 3、特殊職業或遺產相關進度
- 特殊戰術、探索方式、事件結果、異常高低數值或稀有組合

## 遠征稱號

每次旅程可以根據**本次遠征紀錄**中的突出內容產生稱號，而不是直接用跨 Run 的長期總數。

稱號來源不限於戰鬥，例如：

- 特殊職業組合
- 極端生存方式
- 特殊失敗條件
- 某職業在單一 Run 中異常高的擊倒、承傷、治療或技能使用
- 大量進入某類地圖事件
- 完成特殊事件鏈或做出特殊選擇
- 多次擊敗／避開特定 Named Enemy 或小 Boss
- 全程幾乎只依賴特定戰術或探索方式
- 純 Tier 2 完整通關等高難度紀錄

稱號的目的，是讓每一個 Run 留下可以被記住的故事摘要。

## 長期價值

Report System 可以作為：

- 玩家歷史收藏
- 每次遠征的故事回顧
- 職業戰績檔案的長期查看入口
- 成就來源
- 稱號來源
- 未來解鎖條件
- 平衡、事件分布與玩家行為分析的資料基礎

## 資料保留原則

- 本次遠征紀錄：Run 期間即時累積；Run 結束後封存進遠征報告。
- 職業戰績檔案：跨 Run 永久累積，不因 Mastery 完成停止計數。
- 遠征報告：每次 Run 各自永久保存。
- 尚未揭露的職業或隱藏內容：不得藉由玩家可見的統計項目提前暴露。

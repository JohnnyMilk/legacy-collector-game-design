# 遠征報告系統（Report System）

## 系統定位

Report System 同時承接「單次 Run 的故事紀錄」與「長期職業戰鬥檔案」。失敗的旅程也具有價值，會成為玩家完整歷史的一部分。

本系統明確區分兩個資料層：

1. **本次遠征紀錄（Expedition Record）**：只記錄目前這一個 Run 的短期資料。
2. **職業戰績檔案（Class Combat Archive）**：跨 Run 永久累積、以職業為單位的長期完整戰鬥紀錄。

## 本次遠征紀錄

本次遠征紀錄從 Run 開始建立，到該 Run 成功或失敗時封存為遠征報告。

可包含：

- 遠征結果
- 完成 Region 數量
- 角色死亡紀錄
- 職業使用與轉換紀錄
- 遺產發現與使用紀錄
- 各職業在本 Run 的戰鬥行為增量
- 傷害、治療、擊倒、受擊、技能使用與其他戰鬥統計
- Mastery 條件在本 Run 增加了多少進度

這一層是**短期內容**，只描述本次遠征發生了什麼。

## 職業戰績檔案（Class Combat Archive）

職業戰績檔案是**長期、整個遊戲生命週期**的永久紀錄，四名主角共用，並以職業分類。

它同時是 Mastery 背後的統計資料來源。Mastery 任務不是另一份獨立計數器，而是針對職業戰績檔案中的相關數值設定完成門檻。

例如戰士可以長期記錄：

- 完成戰鬥：67 場
- 擊倒敵人：100 名
- 參與 Elite / Boss：18 次
- 承受敵方攻擊：142 次
- 「堅守」生效期間受擊：76 次
- 「猛擊」擊倒敵人：51 次

即使戰士 Mastery 的「擊倒敵人」只要求 45 名，底層仍會繼續統計到 100、200 或更高，不因 Mastery 完成而停止。

玩家可以查看已揭露職業的職業戰績檔案；尚未揭露的隱藏職業不出現在檔案 UI 中。

## 與 Mastery 的資料關係

每一筆符合條件的戰鬥事件可以同時寫入：

- 本次遠征紀錄：增加本 Run 統計。
- 職業戰績檔案：增加跨 Run 永久統計。
- Mastery 顯示：依職業戰績檔案目前值即時判斷 Checklist 是否已達門檻。

因此 Mastery 是「職業戰績檔案的門檻視圖」，不是獨立的角色經驗系統。

Checklist 達標時可以立即顯示完成並增加 `Mastery X / Y`；只有 **MASTERED 狀態本身**需要等戰鬥結束後正式結算。

角色死亡不會影響已寫入的職業戰績檔案，也不會取消已達成的 Mastery 條件。

## 遠征報告

Run 結束時，本次遠征紀錄被整理成一份正式遠征報告。

報告重點不是重複顯示所有長期總數，而是描述**這一趟旅程**：

- 哪些角色與職業最活躍
- 本 Run 的關鍵擊倒、治療、承傷與技能使用
- 是否有角色死亡或殘隊通關
- 本 Run 完成了哪些 Mastery 條件或取得 MASTERED
- 解鎖了哪些 Tier 3、特殊職業或遺產相關進度
- 特殊戰術、異常高低數值或稀有組合

## 遠征稱號

每次旅程可以根據**本次遠征紀錄**中的突出內容產生稱號，而不是直接用跨 Run 的長期總數。

可能來源包括：

- 特殊職業組合
- 極端生存方式
- 特殊失敗條件
- 某職業在單一 Run 中異常高的擊倒、承傷、治療或技能使用
- 全程幾乎只依賴特定戰術
- 純 Tier 2 完整通關等高難度紀錄

稱號的目的，是讓每一個 Run 留下可以被記住的故事摘要。

## 長期價值

Report System 可以作為：

- 玩家歷史收藏
- 每次遠征的故事回顧
- 職業戰績檔案的長期查看入口
- 成就來源
- 稱號來源
- 未來解鎖條件
- 平衡與玩家行為分析的資料基礎

## 資料保留原則

- 本次遠征紀錄：Run 期間即時累積；Run 結束後封存進遠征報告。
- 職業戰績檔案：跨 Run 永久累積，不因 Mastery 完成停止計數。
- 遠征報告：每次 Run 各自永久保存。
- 尚未揭露的職業：不在玩家可查看的職業戰績檔案中顯示。

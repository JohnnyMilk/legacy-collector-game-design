# 技能系統（Skill System）

## 基本規則

「職業特性」是純文字定位說明，不是技能，也不提供額外戰鬥效果。

每個正式職業自身只提供：

- 1 個主動技能
- 1 個被動技能

主動技能具有有限 Charge；被動技能持續生效，不消耗 Charge。

## 技能繼承

高 Tier 職業會完整繼承其前置職業技能。

- Tier 1：自身 1 主動 + 1 被動。
- Tier 2：自身技能 + 所有正式連線 Tier 1 的全部主動／被動技能。
- Tier 3：自身技能 + 所有 Inspiration Links 對應 Tier 2 的全部主動／被動技能，並遞迴包含這些 Tier 2 已繼承的 Tier 1 技能。
- 相同來源職業的技能只取得一次，不因多條路徑重複。
- 目前不設定技能欄上限；先透過 Prototype 驗證 Tier 3 實際技能數量與操作負擔。

此規則取代舊版「轉職後留下弱化 Legacy Trait」設計。

## 主動技能 Charge

Charge 代表遠征中的有限技能資源。

- 不會因單一回合自然恢復。
- 戰鬥後可依戰鬥結算規則恢復部分 Charge。
- 角色在 Region 轉職點完成轉職後，新職業 Build 中所有可用主動技能 Charge 直接補滿。
- 每個 Region 只有一個轉職點，因此不另外設定角色轉職次數限制。

## Tier 設計方向

Tier 1 應維持簡單、清楚、容易理解的技能組，作為四個主要職業系的基礎。

Tier 2 與 Tier 3 的力量感主要來自：

- 新職業自身新增的主動／被動技能
- 完整保留前置職業技能
- 多個技能之間形成新的戰術組合

## 已定案 Tier 1：斥候

### 職業定位

斥候定位為「高速機動／先手騷擾」。職業特性僅作文字說明：擅長利用高機動與較早的行動順序取得位置優勢，在敵人完成部署前先行接觸、攻擊或調整站位。

### 被動技能：游擊

若斥候在本回合 **先移動，再進行普通攻擊或主動技能**，行動結束後獲得暫時閃避提升，持續至下一次自身行動開始。

- 初版平衡值：閃避提升約 15%～20%，最終數值待戰鬥 Prototype 調整。
- 效果不疊加。
- 若該回合沒有先移動，則不觸發。

此被動的目的不是增加斥候爆發傷害，而是建立「移動 → 出手 → 降低被反打風險」的基本節奏。

### 主動技能：疾行

消耗 1 Charge，使斥候 **本回合移動距離 +3 格**。

- 最大 Charge：3。
- 使用後仍可依一般行動規則執行移動後攻擊／技能等合法行動。
- 技能本身不直接造成傷害。

「疾行」作為 Tier 1 的基礎機動工具，未來被刺客、舞刃者等高 Tier 職業繼承後，應能與其職業技能形成更強的戰術組合。

# 關係、敵人與 Report

## 關係

四名固定主角共有 6 組雙向關係（A-B 與 B-A 視為同一組）。關係值隱藏，玩家看到陌生、熟識、友好、親密等描述。

關係透過鄰近支援與共同經歷增加，例如角色在彼此周圍 8 格內攻擊，或對特定角色治療、施加增益。關係不提供追加攻擊或數值戰鬥加成；它只影響 Inspiration 與隱藏職業的發現。關係跨 Run 保存，累積速度應是長週期的。

## 敵人

敵人提供戰術挑戰，而非養成。一般敵人沒有等級、Mastery、Promotion、Relationship 或 Legacy；基本資料是名稱、類型、能力、移動、敏捷、技能、攻擊模式與 AI。

敵人分為 Normal、Elite、Mini Boss、Boss／Final Boss。Boss 可有多階段、改變戰場規則，並可作為遺產與隱藏職業的世界線索。普通敵人使用模板；Elite、Mini Boss 與 Boss 可以有完整職業感與獨特 Build，但「看到 Boss」不等於立刻能轉為該職業。

AI 依目標價值、距離、可造成傷害、目標脆弱程度與戰術價值選擇行動。常見個性包含 Aggressive、Assassin、Guardian、Ranged 與 Support；AI 會追擊落單或脆弱目標，也會保護己方弱點。

## Expedition Report

每趟遠征無論成功或失敗都留下歷史紀錄：路徑、戰鬥、事件、死亡、存活者、轉職、遺產、發現與戰鬥統計。系統可從紀錄給予稱號、評價與未來內容條件。

Report 應獎勵玩法，不獎勵重複刷取。全滅、特殊隊伍組合、極端職業選擇與抵達深處的失敗，都可能成為隱藏職業或稱號的線索。

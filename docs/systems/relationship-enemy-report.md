# 關係、敵人與 Report｜舊版草稿

> 此文件為舊版整合草稿。Relationship／親密度系統已取消，不再作為現行設計的一部分。敵人與 Report 規格請以拆分後的正式文件為準。

## Relationship 狀態

Relationship／親密度系統已取消。

現行設計中：

- 四名主角沒有需要長期累積的親密度數值。
- Relationship 不影響戰鬥。
- Relationship 不參與 Tier 3 Inspiration。
- 一般 Tier 3 只檢查共用職業樹上所有對應 Inspiration Links 的 Tier 2 Mastery 是否完成。

## 敵人

敵人提供戰術挑戰，而非養成。一般敵人沒有角色等級、Mastery、Promotion、Relationship 或 Legacy；基本資料仍以名稱、類型、能力、移動、敏捷、技能、攻擊模式與 AI 為主。

敵人可分為 Normal、Elite、Mini Boss、Boss／Final Boss。Boss 可有多階段、改變戰場規則，也可作為遺產、特殊職業或世界觀的線索。

## Expedition Report

每趟遠征無論成功或失敗都留下歷史紀錄，例如路徑、戰鬥、事件、死亡、存活者、轉職、遺產、發現與戰鬥統計。

Report 可以提供稱號、評價與未來內容條件，但不再用 Relationship 作為職業解鎖來源。

## 現行職業解鎖摘要

- 一般 Tier 3：完成該 Tier 3 所有 Inspiration Links 對應 Tier 2 Mastery 後永久解鎖。
- 特殊職業：由遺產或其他特殊條件取得，不顯示於一般同心圓職業樹。

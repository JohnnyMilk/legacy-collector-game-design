# 敵方角色能力值（Enemy Stats）

## 狀態

- Tier 1：**已確認**。
- Tier 2：待測試／待確認。
- Tier 3：待測試／待確認。
- Mini Boss、Region Boss、Final Boss：獨立設計，不套用一般敵人 Tier 模板。

## 設計原則

一般敵人使用固定 Tier + 兵種類型模板。一般敵人的單體強度原則上低於同 Tier 玩家職業，因為一般遭遇常由數量與兵種混編形成壓力。

正式 Runtime 數值來源：`data/enemy-stats.json`。

Combat Demo 的 Scenario 只應保存敵人種類、數量、位置與地圖配置，不應重複寫入已確認的敵方基礎數值。

### Tier 1 定位

- **獵兵**：高機動的遠距物理兵；四種 Tier 1 中 AGI、MOVE、EVA 較高。
- **劍兵**：標準近戰物理兵；能力分布最平均。
- **術士**：遠距魔法兵；MATK、MDEF 較高，物理面較弱。
- **重衛**：低機動防禦兵；HP、DEF 最高，AGI、MOVE、EVA 最低。

## 驗證來源

Tier 1 四種敵方模板已在 Demo 0 與 Demo 1 實際戰鬥中使用；使用者確認目前數值表現可接受，因此正式升格為 Tier 1 Enemy Baseline。

後續 Demo 不再以「調整 Tier 1 基礎數值」作為預設平衡手段，而優先透過敵人數量、Tier 混編、兵種比例、站位、地圖與技能配置測試遭遇強度。若未來確有系統性問題，才回到此正式資料版本修訂。

# 關係系統（Relationship System）｜已取消

## 狀態

此系統已從目前遊戲設計中取消，不再作為正式核心系統。

原本 Relationship 的主要用途，是作為 Tier 3 隱藏職業 Inspiration 的其中一種條件；目前 Tier 3 已改為使用更單純的共享職業樹 Mastery 規則，因此不再需要角色親密度／關係數值。

## 現行替代規則

- 四名主角共用同一棵職業樹與職業 Mastery 進度。
- 每個同心圓 Tier 3 都有自己的 Inspiration Links。
- 當隊伍完成該 Tier 3 所有對應 Tier 2 職業的 Mastery，即解鎖該 Tier 3。
- 不再檢查角色之間的 Relationship、親密度或關係階級。

## 保留原因

本文件保留作為設計演進紀錄，避免未來誤用舊版 Relationship 規則。

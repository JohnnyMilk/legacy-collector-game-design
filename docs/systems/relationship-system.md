# 關係系統（Relationship System）

## 系統定位

角色關係是跨 Run 保存的 Meta Progression 系統。

四名固定角色會因共同經歷產生長期連結，並影響隱藏職業啟發。

## 基本規則

- 四名角色之間建立關係。
- 關係為隱藏數值。
- 玩家只看到描述等級，例如：陌生、友好、親密。
- 關係不影響直接戰鬥數值。

## 關係提升方式

主要來源：

- 在彼此附近（8 格範圍）共同參與戰鬥。
- 為特定角色提供治療或支援。
- 共同完成事件。

## 隱藏職業啟發

Relationship 是 Tier 3 隱藏職業的重要條件之一。

例如：

聖騎士可能需要：
- 與騎士角色達到親密。
- 與牧師角色達到親密。

角色受到隊友影響而獲得職業啟發。

## 跨 Run 保存

由於四名角色保留前一次遠征記憶，Relationship 不會重置。

因此：
- 關係成長速度需要緩慢。
- 最大關係需要長期投入。

# 行動時間系統（Timeline System）

## 基本規則

角色依照敏捷值（AGI）決定每一輪的行動順序。

敏捷為隱藏數值，玩家不可直接查看精確值；介面可以顯示本輪可理解的行動先後結果。

## 行動流程

- 每輪開始時重新計算所有存活單位的**最終 AGI**，並建立該輪行動順序。
- 每名存活角色每輪最多取得 1 次自身行動。
- AGI 較高者優先。
- AGI 相同時，我方角色優先於敵方角色；仍相同時依固定生成順序處理。
- 死亡角色立即從本輪剩餘行動順序移除。
- 復活角色不插入當前輪，從下一輪重新加入計算。

## AGI 修正與重算時機

最終 AGI 可以受到以下來源修正：

1. 職業固定基礎 AGI。
2. Party Composition。
3. Buff / Debuff。
4. 技能或被動的特殊修正。

規則：

- 每輪開始時，以當下所有存活單位的最終 AGI 建立新的 Timeline。
- 輪中發生的 AGI 增減**不重新排列當輪已建立的 Timeline**。
- 輪中的 AGI 變化從**下一輪**開始反映。
- 這項規則避免單一 Buff / Debuff 在輪中反覆改寫已排定的行動順序，讓玩家能穩定預測當輪剩餘行動。

## 特殊效果

目前沒有裝備或 Relic 提供通用的 Timeline 優先權。

若未來職業技能、角色記憶能力或狀態需要：

- 立即插入行動。
- 額外行動。
- 立即重排 Timeline。
- 跳過既定順序。

必須由該效果明確定義為例外；不能從一般 AGI 規則自行推導。

## Demo 基準

Combat Demo 的 Timeline 應直接讀取正式職業能力值資料中的 AGI，並在每輪開始重算一次。

目前基礎 Timeline 規則視為已可供 Demo 實作；未來只有在新增「額外行動／立即插隊」類技能時才需要擴充。

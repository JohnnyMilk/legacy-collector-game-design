# 行動時間系統（Timeline System）

## 基本規則

角色依照敏捷值（AGI）決定每一輪的行動順序。

敏捷為隱藏數值，玩家不可直接查看精確值；介面可以顯示本輪可理解的行動先後結果。

## 行動流程

- 每輪開始時重新計算所有存活單位的行動順序。
- 每名存活角色每輪最多取得 1 次自身行動。
- AGI 較高者優先。
- AGI 相同時，我方角色優先於敵方角色；仍相同時依固定生成順序處理。
- 死亡角色立即從本輪剩餘行動順序移除。
- 復活角色不插入當前輪，從下一輪重新加入計算。

## 特殊效果

目前沒有裝備或 Relic 提供通用的 Timeline 優先權。

若未來職業技能、角色記憶能力或狀態需要直接改變 AGI、插入行動或改寫行動優先序，必須由該效果明確定義；不能從一般 Timeline 規則自行推導。

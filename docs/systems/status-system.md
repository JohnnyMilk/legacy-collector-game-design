# 狀態系統（Status System）

## 基本規則

所有增益與減益狀態主要來源：

- 職業技能
- 遺產能力

## 狀態規則

- 相同狀態不疊加；若未來個別狀態需要刷新或覆蓋，必須在該狀態規格中明確定義。
- 不同狀態可以同時存在，但各自依自己的效果與解除條件結算。
- 一般暫時狀態於戰鬥結束後清除，不跨越下一場戰鬥。
- 遺產或職業被動若本身定義為長期能力，不視為一般暫時狀態。
- Legacy Trait 系統已取消，不再作為狀態例外來源。

## 煉金術士異常狀態

Tier 2「煉金術士」的「藥劑投擲」每次施放隨機抽取 1 種異常，該次 3 格噴濺命中的所有敵人使用同一種異常：

- **衰弱**：造成的物理與魔法傷害降低 20%。
- **腐蝕**：DEF 與 MDEF 降低 20%。
- **遲緩**：AGI 降低 20%。

「再調製」若成功強化同一主動技能，以上數值效果提高 30%，因此 20% 的基礎異常幅度會提升為 26%。異常狀態的正式持續時間／解除時機目前尚未定案，資料中明確保留為 `to-be-defined`，不得先假設持續整場或固定回合數。

「藥劑投擲」只在施放結算當下把異常附加到有效格內敵人，不在地面留下持續狀態區域。

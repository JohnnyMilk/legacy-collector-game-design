# 狀態系統（Status System）

## 基本規則

所有增益與減益狀態主要來源：

- 職業技能
- 角色記憶能力
- 其他未來正式定義的戰鬥效果

## 狀態規則

- 相同狀態不疊加；若未來個別狀態需要刷新或覆蓋，必須在該狀態規格中明確定義。
- 不同狀態可以同時存在，但各自依自己的效果與解除條件結算。
- **一般時間型狀態**若技能沒有另外指定解除條件，自施加時開始，持續至**效果來源角色下一次自身行動開始時**解除。
- 個別技能可以明確覆寫上述預設，例如「目標下一次自身行動完成後」、「下一次受到傷害後」、「下一次攻擊後」、「直到來源角色移動」或「直到目標死亡」。
- 一般暫時狀態於戰鬥結束後清除，不跨越下一場戰鬥。
- 職業被動或角色記憶能力若本身定義為長期能力，不視為一般暫時狀態。
- Legacy Trait 系統已取消，不再作為狀態例外來源。

## 已確認的特殊解除條件

以下現有技能不套用一般時間型狀態的預設解除點，而依自己的事件條件解除：

- **咒術師｜束縛咒**：限制目標下一次自身行動的移動；該次行動完成後解除。
- **神官｜祝福**：下一次受到傷害時減傷 30%，該次傷害結算後消耗。
- **吟遊詩人｜戰歌**：受影響友方下一次自身行動造成的傷害 +20%，完成該次行動後解除。
- **武士｜見切**：下一次攻擊原攻擊者時提供傷害加成，攻擊完成後消耗。
- **魔劍士｜魔力交織**：由下一次對應傷害類型觸發並消耗。
- **騎士｜守護**：持續至騎士位置發生改變。
- **巫師｜魔力刻印**：屬目標標記，持續至目標死亡。

## 咒術師｜衰咒

「衰咒」屬一般時間型減益。咒術師以魔法傷害命中敵人後附加衰咒，使該敵人的物理與魔法傷害降低 30%；效果持續至**施加該次衰咒的咒術師下一次自身行動開始時**解除。

「束縛咒」仍保留自己的特殊解除條件，不改為咒術師週期。

## 煉金術士異常狀態

Tier 2「煉金術士」的「藥劑投擲」每次施放隨機抽取 1 種異常，該次 3 格噴濺命中的所有敵人使用同一種異常：

- **衰弱**：造成的物理與魔法傷害降低 20%。
- **腐蝕**：DEF 與 MDEF 降低 20%。
- **遲緩**：AGI 降低 20%。

「再調製」若成功強化同一主動技能，以上數值效果提高 30%，因此 20% 的基礎異常幅度會提升為 26%。

以上 3 種異常皆屬一般時間型減益：自「藥劑投擲」命中並附加時開始，持續至**施放該次藥劑投擲的煉金術士下一次自身行動開始時**解除。

「藥劑投擲」只在施放結算當下把異常附加到有效格內敵人，不在地面留下持續狀態區域。

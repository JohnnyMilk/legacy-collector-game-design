# 遺產收集者｜Mastery 系統

## 頁面用途

本頁不再重複以長篇文字列出各職業已定案內容。所有職業的定位、一般攻擊、主動技能、被動技能與 Mastery 任務，統一由下方三個橫向捲軸瀏覽。

## 橫向捲軸說明

- **Tier 1**：顯示 Tier 1 全部職業與目前已確認內容；所有 Tier 1 自身主動技能統一為 **9 Charge**。
- **Tier 2**：顯示 Tier 2 全部職業；所有 Tier 2 自身主動技能統一為 **6 Charge**。共通 Mastery 固定為 16 場戰鬥 / 30 擊倒 / 5 次 Elite / Boss，後 3 項依職業玩法、被動、主動個別設計。
- **Tier 3**：目前先顯示 16 個暫定名稱、職業定位與 Inspiration 方向。Tier 3 完整繼承所連結 Tier 2 與祖先技能，並額外取得 **1 個 Charge 3 專屬主動技能 + 1 個 Tier 3 專屬被動技能**；取消共通 Mastery 模板，每個職業使用完全專屬的 Mastery 設計。
- `CONFIRMED` 代表該職業目前所有必要規格均已定案。
- `DRAFT` 代表已有正式設計內容，但仍存在至少一項未定規則；卡片必須照常顯示已完成的技能與 Mastery，不得用「待定義」覆蓋已定案內容。
- Tier 3 目前的名稱／定位概念尚未逐職業封版；未建立 `classDesigns` 的 Tier 3 卡片仍顯示技能與 Mastery 待定義，但 Charge 3 規則已確定。
- 完全尚未設計的內容才標示「待定義」，不使用猜測資料補滿。
- Mastery 的互動流程測試獨立放在 `development/mastery-flow-demo.html`，不嵌入每張職業卡。

## Mastery 計數語意

Mastery Checklist 的 `target` 與 `unit` 依該任務的實際事件計數，不會因描述中出現「同一場戰鬥」就自動改成以「場」為單位。

例如魔劍士的職業玩法任務：

- **在同一場戰鬥中，先造成物理傷害，再造成魔法傷害：12 次。**
- 判定範圍是單一完整戰鬥，但達成的是「物理 → 魔法」的完整觸發事件；每次合法完成該事件就累積 1 次。
- 每完成 1 次「物理 → 魔法」的完整順序後，該序列立即歸零；必須再次先造成物理傷害，後續魔法傷害才可計為新的 1 次完成。
- 戰鬥結束時尚未完成的序列不跨到下一場。

## 煉金術士 Mastery

煉金術士的 Tier 2 Mastery 已正式建立，共 6 項：

- 使用煉金術士完成戰鬥：16 場。
- 使用煉金術士擊倒敵人：30 名。
- 使用煉金術士參與擊敗 Elite / Boss：5 次。
- 在同一場戰鬥中，讓 3 名不同敵人受到「藥劑投擲」異常：8 場。
- 觸發「再調製」強化主動技能：20 次。
- 單次「藥劑投擲」同時讓至少 2 名敵人獲得異常狀態：10 次。

煉金術士的技能、Mastery 與異常持續時間都已定案，因此目前狀態為 `CONFIRMED`。衰弱、腐蝕、遲緩皆自命中附加時開始，持續至施放該次「藥劑投擲」的煉金術士下一次自身行動開始時解除。

> 本頁的目的就是快速比較所有職業；職業詳細內容以橫向卡片為準，不再於卡片上方重複列出相同資訊。

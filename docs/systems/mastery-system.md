# 遺產收集者｜Mastery 系統

## 核心概念

遊戲不存在角色等級。

Mastery（職業精通）是 **四名主角共用、以職業為單位、跨 Run 永久保留** 的進度。四名主角共同完成同一份職業 Mastery，不需要每名角色重複精通同一職業。

Tier 0「村民」只作為序章／教學狀態，不需要 Mastery，因此不列入正式職業熟練度瀏覽器。

## 本頁負責的職業資訊

「職業熟練系統」是個別職業詳細資訊的主要瀏覽頁面。每張職業卡應顯示：

- 所屬 Tier
- 所屬職業系
- 職業定位
- 職業特性
- 一般攻擊型態、射程與傷害類型
- 主動技能與 Charge 次數
- 被動技能
- 6 項 Mastery Checklist
- 職業設計狀態（已定案／待定義）

職業之間的轉職線、角度、Inspiration Links 與技能繼承路徑則由「職業系統」頁面負責。

舊有「職業描述」欄位已取消，不再於本頁或資料層使用；職業定位與職業特性就是主要文字說明。

## 一般攻擊型態

一般攻擊不是被動技能，也不屬於技能繼承的一部分。

每個職業自行定義 `basicAttack`，包含射程、傷害類型與攻擊型態。高 Tier 轉職後採用新職業自己的普通攻擊，不會因繼承前置職業技能而自動保留前置職業的普通攻擊型態。

以 9×9 戰場作為目前尺度：

- 1 格：近戰
- 2 格：標準遠距
- 3 格：長距離
- 4 格以上：特殊／狙擊級

因此法師可以擁有 2 格魔法普通攻擊，而未來魔劍士仍可自行定義為近戰普通攻擊，不會因繼承法師技能而被強制改為遠距。

## Mastery Checklist

每個一般職業先採固定 **6 項 Checklist**：

- 3 項共通條件：所有職業使用同類型的長期基礎目標，例如使用該職業完成戰鬥、擊倒敵人、參與高威脅戰鬥等。
- 3 項職業專屬條件：分別依照該職業的玩法定位、被動技能、主動技能設計。

「職業特性」本身只是定位說明，不是技能；職業專屬 Mastery 應測試玩家是否真的理解並運用該職業的戰鬥方式。

## Framework First

目前不一次定完所有職業技能與 Mastery。

先固定所有職業共用的資料與 UI 框架，再逐職業討論、測試與確認：

1. 職業樹上的所有既有職業都先出現在 Mastery UI。
2. 已定案職業顯示完整一般攻擊、技能與 6 項 Mastery。
3. 尚未定義的職業仍顯示職業系、定位與特性，但一般攻擊、主動技能、被動技能與 Mastery 明確標示「待定義」。
4. 不使用猜測內容把未討論職業補滿。
5. 每完成一個職業，再把正式內容寫入 `data/classes.json` 的 `classDesigns`。

目前已確認的 Tier 1 範本為 **戰士、斥候、法師**。

## 累積節奏

Mastery 會跨多個 Run 保留，因此不能設計成單次遠征很快完成。

初步平衡目標：

- 正常使用一個職業時，大約需要 **2 個 Run** 才能自然完成全部 6 項 Checklist。
- 共通條件負責驗證長期使用量。
- 職業專屬條件負責驗證對主動技能、被動技能與職業玩法的理解。
- 實際數值會在 Prototype 03 與後續戰鬥測試中調整。

## 隊伍共享進度

只要角色目前正在使用該職業，就可以替該職業 Mastery Checklist 累積進度。

同一個 Checklist 的累積進度可以由不同角色共同貢獻；不同 Checklist 項目也可以由不同角色分別完成。

當全部 6 項完成後，該職業被全隊標記為 **Mastered（已精通）**，並永久跨 Run 保留。

## 新 Run 與 Mastery

每次正式 Run 開始前，玩家可以替四名主角選擇任何已解鎖職業作為起始職業。

- 不需要重新從村民練起。
- 不需要重新完成已 Mastered 職業。
- 已解鎖但尚未 Mastered 的職業也可以作為新 Run 起始職業，並繼續累積 Mastery。
- 四名角色可以使用相同職業。

## 轉職條件與時機

戰鬥結束只負責更新 Mastery Checklist、檢查新職業解鎖與一般戰鬥後恢復，不會立即轉職。

每個 Region 固定只有 **1 個轉職點**，原則上位於路程中段。角色目前職業必須已 Mastered，才可在轉職點沿正式職業路徑轉換。完成轉職後，新 Build 中所有可用主動技能 Charge 補滿。

## 與技能繼承的關係

Mastery 不再產生弱化版 Legacy Trait。

高 Tier 的主動／被動技能採完整繼承：Tier 2 繼承正式連線 Tier 1 的主／被動技能；Tier 3 繼承 Inspiration Links 對應 Tier 2 及其祖先技能。

**一般攻擊型態不繼承。** 新職業使用自己的 `basicAttack`。

## 與 Tier 3 Inspiration 的關係

Tier 3 Inspiration 只檢查 **隊伍共享的職業 Mastery 紀錄**。

每個 Tier 3 都有自己的 Inspiration Links。當其中列出的所有 Tier 2 都已 Mastered，該 Tier 3 即永久解鎖。

不使用 Relationship／親密度或額外特殊事件作為一般 Tier 3 解鎖條件。

## 已定案範例：戰士 Mastery

### 戰士基本資訊

- 所屬職業系：戰士系
- 職業定位：近戰前排／穩定輸出
- 職業特性：擅長在前線持續作戰，依靠較高的生存能力與穩定近戰輸出維持戰線，是最直接、可靠的基礎近戰職業。
- 一般攻擊：1 格物理近戰攻擊。
- 被動技能「堅守」：受到敵方攻擊後，直到下一次自身行動開始前，後續受到的傷害降低 **29%**。第一次攻擊仍承受完整傷害，效果不疊加。
- 主動技能「猛擊」：對相鄰敵人造成約普通攻擊 1.5 倍的近戰傷害；Charge 9。

### Mastery

1. 使用戰士完成 **24 場戰鬥**。
2. 使用戰士擊倒 **45 名敵人**。
3. 使用戰士參與擊敗 **8 次 Elite / Boss**。
4. 使用戰士承受敵方攻擊，共 **60 次**。
5. 在「堅守」生效期間受到敵方攻擊，共 **30 次**。
6. 使用「猛擊」擊倒敵人，共 **20 次**。

## 已定案範例：斥候 Mastery

### 斥候基本資訊

- 所屬職業系：敏捷系
- 職業定位：高速機動／先手騷擾
- 職業特性：擅長利用高機動與較早的行動順序取得位置優勢，在敵人完成部署前先行接觸、攻擊或調整站位。
- 一般攻擊：1 格物理近戰攻擊。
- 被動技能「游擊」：本回合若先移動，再進行普通攻擊或主動技能，行動結束後獲得暫時閃避提升，持續至下一次自身行動開始。
- 主動技能「疾行」：本回合移動距離 +3 格；Charge 6。

### Mastery

1. 使用斥候完成 **24 場戰鬥**。
2. 使用斥候擊倒 **45 名敵人**。
3. 使用斥候參與擊敗 **8 次 Elite / Boss**。
4. 先移動，再於同一回合完成普通攻擊或主動技能，共 **50 次**。
5. 觸發「游擊」後，在效果持續期間成功迴避敵方攻擊，共 **15 次**。
6. 使用「疾行」後，在同一回合完成普通攻擊，共 **20 次**。

## 已定案範例：法師 Mastery

### 法師基本資訊

- 所屬職業系：魔法系
- 職業定位：遠距魔法輸出／定點爆發
- 職業特性：擅長保持安全距離並預先選擇施法位置，以有限的主動技能 Charge 換取高於普通攻擊的遠距魔法傷害。
- 一般攻擊「魔法射擊」：對 2 格內單一敵人進行不消耗 Charge 的遠距魔法普通攻擊。
- 被動技能「凝神」：本回合施放造成傷害的主動技能前若未移動，該次主動技能傷害 **+30%**。
- 主動技能「魔力彈」：對 3 格內單一敵人造成約普通攻擊 1.5 倍的魔法傷害；Charge 9。

### Mastery

1. 使用法師完成 **24 場戰鬥**。
2. 使用法師擊倒 **45 名敵人**。
3. 使用法師參與擊敗 **8 次 Elite / Boss**。
4. 在距離敵人 **2 格以上** 的位置造成傷害，共 **50 次**。
5. 觸發「凝神」後，以獲得加成的主動技能命中敵人，共 **30 次**。
6. 使用「魔力彈」擊倒敵人，共 **20 次**。

## UI 呈現

Prototype 03 依 Tier 分區：Tier 1、Tier 2、Tier 3 各自有自己的橫向滑動列。

每張職業卡依所屬職業系使用不同背景色，並顯示一般攻擊、主動技能、被動技能與 Mastery。Tier 3 在 Prototype 中可顯示開發用槽位；正式遊戲仍遵守首次 Tier 3 解鎖前完全隱藏 Tier 3 的規則。

職業卡不在尾端重複顯示 Prototype 平衡備註，以避免文案過長。

## 設計目的

Mastery 的目的不是鼓勵玩家重複刷同一種戰鬥，而是讓玩家在約兩個 Run 的長期使用中真正理解該職業。

# LEGACY COLLECTOR｜Mastery 系統

## 頁面用途

本頁不再重複以長篇文字列出各職業已定案內容。所有職業的定位、一般攻擊、主動技能、被動技能與 Mastery 任務，統一由下方三個橫向捲軸瀏覽。

## 橫向捲軸說明

- **Tier 1**：顯示 Tier 1 全部職業與目前已確認內容；所有 Tier 1 自身主動技能統一為 **9 Charge**。
- **Tier 2**：顯示 Tier 2 全部職業；所有 Tier 2 自身主動技能統一為 **6 Charge**。共通 Mastery 固定為 16 場戰鬥 / 30 擊倒 / 5 次 Elite / Boss，後 3 項依職業玩法、被動、主動個別設計。
- **Tier 3**：現行固定為 8 個隱藏高階職業（4 個單系核心 + 4 個跨系）。Tier 3 完整繼承 Inspiration Links 對應 Tier 2 與祖先技能，再取得自己的專屬能力；專屬能力組合不強制固定格式。
- `CONFIRMED` 代表該職業目前所有必要規格均已定案。
- `DRAFT` 代表已有正式設計內容，但仍存在至少一項未定規則；卡片必須照常顯示已完成的技能與 Mastery，不得用「待定義」覆蓋已定案內容。
- 未建立 `classDesigns` 的 Tier 3 卡片仍顯示技能與 Mastery 待定義；已完成逐職業確認的 Tier 3 則直接顯示正式內容。
- 完全尚未設計的內容才標示「待定義」，不使用猜測資料補滿。
- Mastery 的互動流程測試獨立放在 `development/mastery-flow-demo.html`，不嵌入每張職業卡。

## Tier 2 已確認技能補充

### 神官｜聖癒

- 指定自身 **2 格內任意合法中心格**，中心格可為空白格，也可已有單位。
- **不可指定神官自身所在格**作為中心格。
- 以神官到中心格的施放方向為基準，形成與該方向垂直的 **3 格治療帶**。
- 治療帶中的所有友方角色各自接受正常治療；空白格不產生效果，敵方不受影響。
- 每一名實際被治療的角色都要**獨立判定「恩典」與「祝福」**：治療開始時 HP 低於 50% 時，若神官繼承「恩典」，該名角色本次治療量 +30%；若治療後由低於 50% 回到 50% 以上，則取得「祝福」的下一次受到傷害 -30%。

## Tier 3 Mastery 原則

Tier 3 Mastery **只圍繞該職業自身的 Tier 3 專屬能力設計**。

- 不加入「完成戰鬥場次」。
- 不加入「擊殺敵人數」作為共通模板；若擊殺本身直接驗證某個 Tier 3 專屬機制，仍可作為該職業專屬 Mastery 條件。
- 不加入「Elite / Boss 參與或擊敗數」。
- 不要求固定項目數；依職業自身專屬能力的學習目標決定。
- 專屬能力可以是主動、被動或其他正式定義的 Tier 3 機制，不強制固定為 1 主動 + 1 被動。
- Mastery 的目的，是驗證玩家是否真正理解並使用該 Tier 3 的專屬玩法，而不是單純累積遊玩時間。

## Mastery 計數語意

Mastery Checklist 的 `target` 與 `unit` 依該任務的實際事件計數，不會因描述中出現「同一場戰鬥」就自動改成以「場」為單位。

例如魔劍士的職業玩法任務：

- **在同一場戰鬥中，先造成物理傷害，再造成魔法傷害：12 次。**
- 判定範圍是單一完整戰鬥，但達成的是「物理 → 魔法」的完整觸發事件；每次合法完成該事件就累積 1 次。
- 每完成 1 次「物理 → 魔法」的完整順序後，該序列立即歸零；必須再次先造成物理傷害，後續魔法傷害才可計為新的 1 次完成。
- 戰鬥結束時尚未完成的序列不跨到下一場。

> 各職業的定位、一般攻擊、主動技能、被動技能與 Mastery 任務只在下方職業卡維護，不再於本頁正文逐職業重複記錄。完成新職業時只更新職業資料與卡片內容。

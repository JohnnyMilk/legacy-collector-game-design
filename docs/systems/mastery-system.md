# 遺產收集者｜Mastery 系統

## 核心概念

遊戲不存在角色等級。

Mastery（職業精通）是 **四名主角共用、以職業為單位、跨 Run 永久保留** 的進度。它真正訓練的是玩家對職業的理解，而不是某一名遊戲角色本身。

Tier 0「村民」只作為序章／教學狀態，不需要 Mastery。

## 累積、完成與結算規則

- 只要角色目前使用某職業，就能替該職業累積相關戰鬥紀錄與 Mastery。
- **同一職業若有多名角色同時使用，所有符合條件的行為合併到同一份職業進度。**
- 戰鬥中的行為會即時寫入職業戰績檔案，相關 Checklist 進度也即時更新。
- 某項 Checklist 一旦達到目標值，該項目立即視為完成，職業顯示的 `Mastery X / Y` 也立即增加，不需要等到戰後。
- 若所有 Checklist 在戰鬥中都已完成，畫面顯示 `Mastery Y / Y · 待戰後結算`；**MASTERED 狀態本身只在戰鬥結束時正式判定與授予。**
- 角色死亡不會取消、扣除或回滾任何已累積的職業戰績與 Mastery。即使完成最後一項條件的角色已死亡，只要戰後檢查時全部條件成立，該職業仍取得 MASTERED。

## 顯示規則

每項 Checklist 顯示「目前值 / 目標值」，例如 `17 / 24`。

- 未完成：`17 / 24`
- 已達標：`✓ 24 / 24`
- 職業總進度：`Mastery 4 / 6`
- 所有項目已達標但尚未戰後結算：`Mastery 6 / 6 · 待戰後結算`
- 戰後正式精通：`MASTERED`

不另外顯示百分比。

Checklist 的顯示值可以在 UI 上封頂於目標值，但底層統計不封頂；真正累積值由「職業戰績檔案」持續保存。

## 職業戰績檔案（Class Combat Archive）

「職業戰績檔案」是所有 Mastery 背後的長期戰鬥統計來源，跨 Run 永久累積，並可供玩家查看。

它不是另一套獨立於 Mastery 的成長值，而是對每個職業實際使用歷史的完整記錄。例如：

- 戰士完成戰鬥場數
- 戰士擊倒敵人數
- 戰士參與 Elite / Boss 次數
- 戰士承受敵方攻擊次數
- 「堅守」生效期間受擊次數
- 「猛擊」擊倒敵人次數

這些數值**不因 Mastery 任務完成而停止累積**。例如戰士 Mastery 的擊倒需求是 45 人，但職業戰績檔案可以持續顯示 `戰士擊倒敵人：100`。

Mastery Checklist 只是對職業戰績檔案中的相關統計設定「完成門檻」。因此玩家早已超過門檻時，該 Mastery 條件自然保持完成，而長期紀錄仍持續成長。

尚未揭露的隱藏職業不出現在玩家可查看的職業戰績檔案中；職業揭露後才顯示對應頁面與統計。

## 與本次遠征紀錄的關係

職業戰績檔案是**長期、整個遊戲生命週期**的累積紀錄；「本次遠征紀錄」則只保存目前這一個 Run 內的統計增量。

同一個戰鬥事件可以同時更新：

1. 本次遠征紀錄：只計本 Run，用於遠征結束報告與稱號發想。
2. 職業戰績檔案：跨 Run 永久累積，用於 Mastery 與長期玩家紀錄。

遠征結束後，Report System 依本次遠征紀錄產生遠征報告；稱號也可以從本 Run 中特別突出的行為或組合產生，而不是直接用長期總數判定。

## Mastered 的效果

Mastered 本身**不提供任何戰鬥數值加成**。

Mastered 固定具有三個用途：

1. 允許角色在 Region 轉職點由目前職業正式轉出。
2. 作為 Tier 3 Inspiration，以及更後段特殊職業解鎖條件的一部分。
3. 完成狀態跨 Run 永久保留。

## Tier 1 / Tier 2 Checklist

Tier 1 與 Tier 2 固定使用 **6 項 Mastery Checklist**：

- 3 項共通條件：完成戰鬥、擊倒敵人、參與高威脅戰鬥等長期基礎目標。
- 3 項職業專屬條件：依職業玩法、被動技能、主動技能設計。

初步平衡目標仍是正常使用一個職業約兩個 Run 自然完成。

## Tier 3 Mastery

Tier 3 **取消 Tier 1／2 的「3 共通 + 3 專屬」模板**。

Tier 3 的 Mastery 將完全依該職業本身的特色設計：

- 不要求固定 6 項。
- 不保留共通 Checklist。
- 每一項都應反映該 Tier 3 的核心玩法、技能組合、戰術目標或高階操作方式。
- 具體 Checklist 數量與內容逐職業設計，不預先用通用任務填滿。

這是因為 Tier 3 不只是更高數值的職業，而是通往各職業系最終特殊職業的高階精通階段。

## 與最終特殊職業的關係

遊戲規劃四個最終特殊職業，分別代表戰士系、敏捷系、魔法系、支援系。

每個最終特殊職業的預設解鎖條件為：

1. 完成該職業系要求的全部 Tier 3 Mastery。
2. 取得該職業系對應的特殊遺產。

兩者必須同時滿足。

特殊職業不使用 Tier 1／2 的固定 6 項 Mastery 模板；它們自身是否另有最終成長規則，之後再個別定義。

## Framework First

目前不一次定完所有職業技能與 Mastery。

1. Tier 1 / Tier 2 共用同一套固定資料框架。
2. Tier 3 使用完全職業專屬 Mastery 框架。
3. 未完成設計的內容明確標示「待定義」。
4. 不使用猜測內容補滿尚未討論的職業。
5. 每完成一個職業，再寫入 `data/classes.json` 的 `classDesigns`。

目前已確認的 Tier 1 範本為 **戰士、斥候、法師、牧師**。

## 新 Run 與 Mastery

每次正式 Run 開始前，玩家可以替四名主角選擇任何已解鎖職業作為起始職業。

- 不需要重新從村民練起。
- 不需要重新完成已 Mastered 職業。
- 已解鎖但尚未 Mastered 的職業也可以作為新 Run 起始職業，並繼續累積 Mastery。
- 一般職業可由多名角色重複使用；特殊職業另有隊伍唯一性限制。

## 轉職條件與時機

戰鬥結束負責正式判定 MASTERED、檢查新職業解鎖與一般戰鬥後恢復，不會立即轉職。

每個 Region 固定只有 1 個轉職點，原則上位於路程中段。角色目前職業必須已 Mastered，才可在轉職點沿正式職業路徑轉換。完成轉職後，新 Build 中所有可用主動技能 Charge 補滿。

## 與 Tier 3 Inspiration 的關係

Tier 3 Inspiration 檢查隊伍共享的職業 Mastery 紀錄。每個 Tier 3 都有自己的 Inspiration Links；所有對應 Tier 2 都已 Mastered 後，該 Tier 3 永久解鎖。

不使用 Relationship／親密度或額外特殊事件作為一般 Tier 3 解鎖條件。

## 已定案：戰士 Mastery

1. 使用戰士完成 **24 場戰鬥**。
2. 使用戰士擊倒 **45 名敵人**。
3. 使用戰士參與擊敗 **8 次 Elite / Boss**。
4. 使用戰士承受敵方攻擊，共 **60 次**。
5. 在「堅守」生效期間受到敵方攻擊，共 **30 次**。
6. 使用「猛擊」擊倒敵人，共 **20 次**。

## 已定案：斥候 Mastery

1. 使用斥候完成 **24 場戰鬥**。
2. 使用斥候擊倒 **45 名敵人**。
3. 使用斥候參與擊敗 **8 次 Elite / Boss**。
4. 先移動，再於同一回合完成普通攻擊或主動技能，共 **50 次**。
5. 觸發「游擊」後，在效果持續期間成功迴避敵方攻擊，共 **15 次**。
6. 使用「疾行」後，在同一回合完成普通攻擊，共 **20 次**。

## 已定案：法師 Mastery

1. 使用法師完成 **24 場戰鬥**。
2. 使用法師擊倒 **45 名敵人**。
3. 使用法師參與擊敗 **8 次 Elite / Boss**。
4. 在距離敵人 **2 格以上** 的位置造成傷害，共 **50 次**。
5. 觸發「凝神」後，以獲得加成的主動技能命中敵人，共 **30 次**。
6. 使用「魔力彈」擊倒敵人，共 **20 次**。

## 已定案：牧師 Mastery

1. 使用牧師完成 **24 場戰鬥**。
2. 使用牧師擊倒 **45 名敵人**。
3. 使用牧師參與擊敗 **8 次 Elite / Boss**。
4. 使用牧師對友方角色進行治療，共 **50 次**。
5. 對 HP 低於 50% 的友方觸發「恩典」並完成治療，共 **25 次**。
6. 使用「治癒」將友方角色從低於 50% HP 恢復至 50% 以上，共 **20 次**。

## UI 呈現

Prototype 03 依 Tier 分區顯示 Tier 1、Tier 2、Tier 3，負責瀏覽職業內容，不在每張職業卡內重複放置互動測試按鈕。

獨立的 Mastery 流程互動測試放在 `development/mastery-flow-demo.html`：用單一示範職業驗證即時 Checklist 完成、`Mastery X / Y` 更新、角色死亡不回滾、超過門檻仍持續統計，以及戰後才授予 MASTERED。

- Tier 1 / Tier 2 未定義職業可顯示固定 6 項框架的待定義位置。
- Tier 3 未定義職業不可顯示「3 共通 + 3 專屬」假任務；只標示「Tier 3 Mastery：完全職業專屬，待設計」。
- 正式遊戲仍遵守首次 Tier 3 解鎖前完全隱藏 Tier 3 的規則。

## 設計目的

Mastery 的目的不是鼓勵重複刷同一種戰鬥，而是讓玩家真正理解職業。遊戲角色只是執行者；真正被訓練的是玩家對職業玩法的掌握。Tier 1 / Tier 2 驗證基礎掌握；Tier 3 則用更具特色的條件驗證高階玩法，並成為最終特殊職業的必要前置。

# LEGACY COLLECTOR｜Mastery 系統

## 頁面用途

本頁不再重複以長篇文字列出各職業已定案內容。所有職業的定位、一般攻擊、主動技能、被動技能與 Mastery 任務，統一由下方三個橫向捲軸瀏覽。

## 橫向捲軸說明

- **Tier 1**：顯示 Tier 1 全部職業與目前已確認內容；所有 Tier 1 自身主動技能統一為 **9 Charge**。
- **Tier 2**：顯示 Tier 2 全部職業；所有 Tier 2 自身主動技能統一為 **6 Charge**。共通 Mastery 固定為 16 場戰鬥 / 30 擊倒 / 5 次 Elite / Boss，後 3 項依職業玩法、被動、主動個別設計。
- **Tier 3**：目前先顯示 16 個名稱／定位概念。Tier 3 完整繼承所連結 Tier 2 與祖先技能，再依個別職業取得專屬能力。預設可採 **1 個 Charge 3 專屬主動 + 1 個專屬被動**，但不是硬性格式；戰將與獵刃武者目前皆採 **2 個專屬被動 + 0 個額外專屬主動**。
- `CONFIRMED` 代表該職業目前所有必要規格均已定案。
- `DRAFT` 代表已有正式設計內容，但仍存在至少一項未定規則；卡片必須照常顯示已完成的技能與 Mastery，不得用「待定義」覆蓋已定案內容。
- 未建立 `classDesigns` 的 Tier 3 卡片仍顯示技能與 Mastery 待定義；已完成逐職業確認的 Tier 3 則直接顯示正式內容。
- 完全尚未設計的內容才標示「待定義」，不使用猜測資料補滿。
- Mastery 的互動流程測試獨立放在 `development/mastery-flow-demo.html`，不嵌入每張職業卡。

## Tier 3 Mastery 原則

Tier 3 Mastery **只圍繞該職業自身的 Tier 3 專屬能力設計**。

- 不加入「完成戰鬥場次」。
- 不加入「擊殺敵人數」作為共通模板；若擊殺本身直接驗證某個 Tier 3 專屬機制，仍可作為該職業專屬 Mastery 條件。
- 不加入「Elite / Boss 參與或擊敗數」。
- 不要求固定項目數；依職業自身專屬能力的學習目標決定。
- 專屬能力可以是主動、被動或其他正式定義的 Tier 3 機制，不強制固定為 1 主動 + 1 被動。
- Mastery 的目的，是驗證玩家是否真正理解並使用該 Tier 3 的專屬玩法，而不是單純累積遊玩時間。

## Mastery 計數語意

Mastery Checklist 的 `target` 與 `unit` 依該任務的實際事件計數，不會因描述中出現「同一場戰鬥」就自動改成以「場」為單位。

例如魔劍士的職業玩法任務：

- **在同一場戰鬥中，先造成物理傷害，再造成魔法傷害：12 次。**
- 判定範圍是單一完整戰鬥，但達成的是「物理 → 魔法」的完整觸發事件；每次合法完成該事件就累積 1 次。
- 每完成 1 次「物理 → 魔法」的完整順序後，該序列立即歸零；必須再次先造成物理傷害，後續魔法傷害才可計為新的 1 次完成。
- 戰鬥結束時尚未完成的序列不跨到下一場。

## 軍團守衛 Mastery

軍團守衛是第一個完成正式技能與 Mastery 的 Tier 3 職業。Mastery 共 2 項，全部直接對應自身 Tier 3 專屬主動與被動：

- 單次「盾牆陣」成功生成 4 面盾牆：**15 次**。
- 由「壁壘陣」防護中的我方單位實際承受敵方傷害：**30 次**。

這 2 項分別驗證玩家能否正確安排「盾牆陣」的施放空間，以及是否真正利用「壁壘陣」的 DEF / MDEF +20% 防護區域承受敵方攻擊。

## 血煉騎士 Mastery

血煉騎士是第二個完成正式技能與 Mastery 的 Tier 3 職業。其核心是把自身 HP 當成戰鬥資源，並透過「赤血之誓」與「血煉分身」把低血狀態轉化成物理輸出。

- 在「赤血之誓」提供至少 **+50% 物理攻擊力**的狀態下成功造成物理傷害：**30 次**。
- 由「血煉分身」使用普通攻擊成功造成傷害：**30 次**。

這 2 項分別驗證玩家能否主動管理低血量風險，以及是否真正使用分身作為額外戰鬥單位，而不是只把「血煉分身」當成單次扣血手段。

## 戰將 Mastery

戰將是第三個完成正式設計的 Tier 3 職業。戰將不新增 Tier 3 專屬主動技能，而是以一般攻擊「橫掃」配合 2 個專屬被動建立群戰定位。

- **萬夫莫敵**：周圍 8 格內至少存在 3 名敵方單位時，成功造成傷害：**20 次**。
- **眾志成城**：周圍 8 格內至少存在 2 名友方單位時，實際承受敵方造成的傷害：**20 次**。

一般攻擊「橫掃」本身不是被動技能，因此不另外配置 Tier 3 Mastery。這 2 項任務只驗證戰將是否真正利用「敵人越多，輸出越高」與「友軍越多，防禦越高」的兩種站位邏輯。

## 獵刃武者 Mastery

獵刃武者是第四個完成正式設計、也是目前戰士系最後一個完成的 Tier 3 職業。其核心是先以遠距離攻擊建立「獵痕」，再持續追擊被標記的單一目標；「鎖獵」則使被自己命中的敵人直到獵刃武者下一次自身行動開始前都不能移動。

- 使用距離 **2 格以上**的攻擊命中敵人，並成功使該敵人獲得「獵痕」：**30 次**。
- 在本次攻擊實際觸發「獵痕」**+30% 傷害**的狀況下擊倒敵人：**15 次**。

這 2 項都圍繞「獵痕」的完整狩獵循環設計；「鎖獵」沒有獨立 Mastery，因為它主要負責維持獵物位置，讓玩家更容易持續追擊同一目標。

## 獵首者 Mastery

獵首者是第一個完成正式設計的敏捷系 Tier 3 職業。其核心是利用「斷首突襲」快速切入，把敵人壓進 **20% HP** 的處決線，再由專屬被動「處決」直接完成擊殺。

- 使用「斷首突襲」造成傷害後，使目標 HP 從 **20% 以上降到 20% 以下**：**20 次**。
- 成功觸發「處決」，直接擊殺目前 HP 低於 **20%** 的敵人：**20 次**。

這 2 項分別驗證玩家是否會主動製造斬殺線，以及是否真正利用 Tier 3 專屬處決機制完成收尾。

## 煉金術士 Mastery

煉金術士的 Tier 2 Mastery 已正式建立，共 6 項：

- 使用煉金術士完成戰鬥：16 場。
- 使用煉金術士擊倒敵人：30 名。
- 使用煉金術士參與擊敗 Elite / Boss：5 次。
- 在同一場戰鬥中，讓 3 名不同敵人受到「藥劑投擲」異常：8 場。
- 觸發「再調製」強化主動技能：20 次。
- 單次「藥劑投擲」同時讓至少 2 名敵人獲得異常狀態：10 次。

煉金術士的技能、Mastery 與異常持續時間都已定案，因此目前狀態為 `CONFIRMED`。衰弱、腐蝕、遲緩皆自命中附加時開始，持續至施放該次「藥劑投擲」的煉金術士下一次自身行動開始時解除。

> 本頁的目的就是快速比較所有職業；職業詳細內容以橫向卡片為準，不再於卡片上方重複列出相同資訊。

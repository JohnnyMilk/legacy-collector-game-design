# 遺產收集者｜Mastery 系統

## 核心概念

遊戲不存在角色等級。

Mastery（職業精通）是 **四名主角共用、以職業為單位、跨 Run 永久保留** 的進度。四名主角共同完成同一份職業 Mastery，不需要每名角色重複精通同一職業。

Tier 0「村民」只作為序章／教學狀態，不需要 Mastery，因此不列入正式職業熟練度瀏覽器。

## 本頁負責的職業資訊

「職業熟練系統」是個別職業詳細資訊的主要瀏覽頁面。每張職業卡應顯示：

- 所屬 Tier
- 所屬職業系
- 職業定位
- 職業特性
- 主動技能與 Charge 次數
- 被動技能
- 6 項 Mastery Checklist
- 職業設計狀態（已定案／待定義）

職業之間的轉職線、角度、Inspiration Links 與技能繼承路徑則由「職業系統」頁面負責。

舊有「職業描述」欄位已取消，不再於本頁或資料層使用；職業定位與職業特性就是主要文字說明。

## Mastery Checklist

每個一般職業先採固定 **6 項 Checklist**：

- 3 項共通條件：所有職業使用同類型的長期基礎目標，例如使用該職業完成戰鬥、擊倒敵人、參與高威脅戰鬥等。
- 3 項職業專屬條件：分別依照該職業的玩法定位、被動技能、主動技能設計。

「職業特性」本身只是定位說明，不是技能；職業專屬 Mastery 應測試玩家是否真的理解並運用該職業的戰鬥方式，而不是把職業特性當作額外被動。

## Framework First

目前不一次定完所有職業技能與 Mastery。

先固定所有職業共用的資料與 UI 框架，再逐職業討論、測試與確認：

1. 職業樹上的所有既有職業都先出現在 Mastery UI。
2. 已定案職業顯示完整技能與 6 項 Mastery。
3. 尚未定義的職業仍顯示職業系、定位與特性，但主動技能、被動技能與 Mastery 明確標示「待定義」。
4. 不使用猜測內容把未討論職業補滿。
5. 每完成一個職業，再把正式內容寫入 `data/classes.json` 的 `classDesigns`。

斥候是第一個 confirmed 範本。

## 累積節奏

Mastery 會跨多個 Run 保留，因此不能設計成單次遠征很快完成。

初步平衡目標：

- 正常使用一個職業時，大約需要 **2 個 Run** 才能自然完成全部 6 項 Checklist。
- 共通條件負責驗證長期使用量。
- 職業專屬條件負責驗證對主動技能、被動技能與職業玩法的理解。
- 實際數值會在 Prototype 03 與後續戰鬥測試中調整。

## 隊伍共享進度

只要角色目前正在使用該職業，就可以替該職業 Mastery Checklist 累積進度。

同一個 Checklist 的累積進度可以由不同角色共同貢獻；不同 Checklist 項目也可以由不同角色分別完成。

當全部 6 項完成後，該職業被全隊標記為 **Mastered（已精通）**，並永久跨 Run 保留。

## 新 Run 與 Mastery

每次正式 Run 開始前，玩家可以替四名主角選擇任何已解鎖職業作為起始職業。

因此：

- 不需要重新從村民練起。
- 不需要重新完成已 Mastered 職業。
- 已解鎖但尚未 Mastered 的職業也可以作為新 Run 起始職業，並繼續累積 Mastery。
- 四名角色可以使用相同職業。

## 轉職條件與時機

Mastery 完成不會在戰鬥結束後立即轉職。

戰鬥結束只負責：

- 更新 Mastery Checklist
- 檢查新職業是否解鎖
- 執行一般戰鬥後恢復

每個 Region 固定只有 **1 個轉職點**，原則上位於該 Region 路程中段。角色必須抵達轉職點才可進行正式轉職。

當角色目前職業已 Mastered，到了轉職點後：

- 可以維持原職業。
- 可以依職業樹目前的正式轉職路徑轉換到可用職業。
- 若有新解鎖 Tier 3，可在轉職點選擇是否轉入。
- 完成轉職後，新 Build 中所有可用主動技能 Charge 補滿。

不另外限制「每個角色可轉職幾次」；節奏由每個 Region 只有一個轉職點自然控制。

## 與技能繼承的關係

Mastery 不再產生弱化版 Legacy Trait。

高 Tier 的成長改由完整技能繼承承擔：Tier 2 繼承正式連線 Tier 1 的主／被動技能；Tier 3 繼承 Inspiration Links 對應 Tier 2 及其祖先技能。

本頁顯示的是「該職業自身提供的主動／被動技能」與 Mastery；完整繼承關係請回到職業系統頁查看。

## 與 Tier 3 Inspiration 的關係

Tier 3 Inspiration 只檢查 **隊伍共享的職業 Mastery 紀錄**。

每個 Tier 3 都有自己的 Inspiration Links。當其中列出的所有 Tier 2 都已 Mastered，該 Tier 3 即永久解鎖。

不使用 Relationship／親密度或額外特殊事件作為一般 Tier 3 解鎖條件。

## 已定案範例：斥候 Mastery

### 斥候基本資訊

- 所屬職業系：敏捷系
- 職業定位：高速機動／先手騷擾
- 職業特性：擅長利用高機動與較早的行動順序取得位置優勢，在敵人完成部署前先行接觸、攻擊或調整站位。
- 被動技能「游擊」：本回合若先移動，再進行普通攻擊或主動技能，行動結束後獲得暫時閃避提升，持續至下一次自身行動開始。
- 主動技能「疾行」：本回合移動距離 +3 格；Charge 6。

### 共通條件

1. 使用斥候完成 **24 場戰鬥**。
2. 使用斥候擊倒 **45 名敵人**。
3. 使用斥候參與擊敗 **8 次 Elite / Boss**。

### 職業專屬條件

4. **職業玩法**：先移動，再於同一回合完成普通攻擊或主動技能，共 **50 次**。
5. **被動技能「游擊」**：觸發游擊後，在效果持續期間成功迴避敵方攻擊，共 **15 次**。
6. **主動技能「疾行」**：使用疾行後，在同一回合完成普通攻擊，共 **20 次**。

## UI 呈現

Prototype 03 不使用一條跨所有 Tier 的長捲軸，而是依 Tier 分區：

- Tier 1：自己的橫向滑動列
- Tier 2：自己的橫向滑動列
- Tier 3：自己的橫向滑動列

每個 Tier 區塊都可獨立左右滑動，避免職業數量增加後需要大量向下展開單一職業內容。

每張職業卡依所屬職業系使用不同背景色，讓玩家不看文字也能快速辨識大方向。色彩只作為分類輔助，仍須保留職業系文字標示。

Tier 3 在 Prototype 03 中可完整顯示開發用槽位；正式遊戲仍遵守「首次解鎖 Tier 3 前完全隱藏 Tier 3 存在」的規則。

職業卡只顯示玩家真正需要閱讀的職業資訊與任務，不在卡片尾端重複顯示 Prototype 平衡備註，以避免文案過長。

## 設計目的

Mastery 的目的不是鼓勵玩家重複刷同一種戰鬥，而是讓玩家在約兩個 Run 的長期使用中真正理解該職業。

共通條件確保使用時間足夠；三項職業專屬條件則應分別驗證職業玩法、被動技能與主動技能。

# 戰場系統（Battlefield System）

## 地圖規則

- 正方形 Grid
- 俯視角
- 無高度差
- 無角色面向
- 四方向移動

## 移動

角色移動距離依職業決定。

角色移動維持四方向，不因技能可斜向瞄準而改變。

地形會影響：
- 移動成本
- 戰鬥補正

## 技能瞄準方向

移動規則與技能瞄準規則分開處理。

- 基礎移動固定使用上、下、左、右四方向。
- 技能是否可使用斜向格，由個別技能自行定義，不自動套用到所有技能。
- 若技能標示支援 8 方向，則可使用上、下、左、右、左上、右上、左下、右下進行直線瞄準或延伸。
- 目前 Tier 2「煉金術士」的「藥劑投擲」明確支援 8 方向：命中起始格後，沿同一方向繼續向前延伸 2 格，因此斜向投擲時也會形成連續 3 個斜向有效格。

## 單位穿越

友軍：
- 可穿越
- 不可停留同格

敵軍：
- 不可穿越
- 不可停留同格

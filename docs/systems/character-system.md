# LEGACY COLLECTOR｜角色系統（Character System）

## 系統定位

LEGACY COLLECTOR 採固定四名主角、深度職業構築設計。

玩家始終操作同一組四名主角，不透過大量招募建立隊伍。角色差異來自職業、完整技能繼承、隊伍職業系組合、記憶覺醒與戰術決策。

## 核心規則

- 玩家固定擁有四名主角。
- 不存在角色等級系統。
- 不存在自由能力配點。
- **角色沒有任何裝備欄。**
- 不存在武器、防具、飾品、Relic／遺產裝備配置。
- 成長來自職業解鎖、共享 Mastery、高 Tier 技能繼承與角色記憶覺醒。
- Relationship／親密度系統已取消。
- 舊版 Legacy Trait／弱化被動繼承系統已取消。

## 四名主角與原始職業系

四名主角過去分別代表戰士、敏捷、魔法、支援四大職業系的頂點人物。故事開始時四人失去記憶與力量，以 Tier 0「村民」重新開始。

每名角色有一個固定的「原始職業系歸屬」，但這**不限制 Tier 1～3 的自由發展**。例如原本屬敏捷系的角色仍然可以在 Run 中使用戰士、魔法或支援系職業。

原始職業系只決定該角色最後能覺醒哪一個專屬「XXX 的記憶」。

## 序章

Tier 0「村民」只存在於遊戲最初序章／教學；序章結束後不再是正式 Run 的一般起始職業，也不參與 Mastery。

## 每次 Run 的初始配置

遠征開始前，玩家只需要替四名主角選擇合法的起始職業／記憶形態，不需要任何裝備配置。

第一次正式 Run 可預設戰士、斥候、法師、牧師各一名。之後可改選任何已永久解鎖的 Tier 1～3；若某角色已永久覺醒自己的「XXX 的記憶」，也可直接以該記憶形態開始新 Run。

## 職業與角色的關係

一般職業解鎖與 Mastery 是隊伍共享的 Meta Progression，不綁定特定角色。

Tier 1～3 都可以由四名主角自由使用；「XXX 的記憶」則是角色本人專屬，其他三人即使完成相同職業系的所有 Tier 3 Mastery，也不能使用。

角色個體差異主要來自：

- 本次選擇的職業。
- 該職業依 Tier 繼承而來的完整技能組。
- 四人當前職業系形成的隊伍組合。
- 是否已找回自己的「XXX 的記憶」。
- 當前戰鬥站位與玩家決策。

## 死亡與輪迴

單次遠征中，角色死亡後從行動順序移除，且無法參與後續戰鬥。四名角色全部死亡時，本次 Run 失敗。

敘事上，Party Wipe 可理解為本次輪迴失敗；下一個 Run 四人再次開始新的循環，但職業 Mastery、職業解鎖與已真正找回的角色記憶不會被抹除。

## 跨 Run

跨 Run 保留：職業 Mastery、職業解鎖、Tier 3 揭露、角色記憶覺醒與長期紀錄。

不再保存任何 Relic 收藏、裝備或修復資料。

# 角色系統（Character System）

## 系統定位

《遺產收集者》採用固定角色、深度養成設計。

玩家始終操作四名固定主角，不透過大量招募角色建立隊伍，而是透過職業、遺產與經歷塑造角色差異。

## 核心規則

- 玩家固定擁有四名主角。
- 四名角色初始條件一致。
- 不存在角色等級系統。
- 不存在自由能力配點。
- 成長來自職業、Mastery、Legacy Trait、Relationship 與 Relic。

## 角色資料

公開資訊：
- HP
- 攻擊能力
- 防禦能力
- 力量
- 智力

隱藏資訊：
- 敏捷（決定行動順序）
- 命中
- 迴避

## 死亡規則

單次遠征中，角色死亡後：
- 從行動順序移除。
- 無法參與後續戰鬥。

四名角色全部死亡時，該 Run 失敗。

## 跨 Run 設計

隊伍全滅後，透過遺產力量重新開始下一次遠征。

角色保留：
- 名稱
- 關係記憶
- Meta 解鎖內容

死亡只代表上一輪遠征結果，不代表角色永久消失。

# 角色系統（Character System）

## 系統定位

《遺產收集者》採用固定四名主角、深度職業構築設計。

玩家始終操作同一組四名主角，不透過大量招募角色建立隊伍，而是透過職業、技能繼承、遺產與遠征決策塑造差異。

## 核心規則

- 玩家固定擁有四名主角。
- 不存在角色等級系統。
- 不存在自由能力配點。
- 成長來自職業解鎖、共享 Mastery、高 Tier 技能繼承與 Relic。
- Relationship／親密度系統已取消。
- Legacy Trait／弱化被動繼承系統已取消。

## 序章起點

遊戲只有最初序章使用 Tier 0「村民」。序章結束後，村民不再作為一般 Run 起始職業，也不需要 Mastery。

## 每次 Run 的初始配置

每次正式遠征開始前，玩家重新設定本次 Run 的 Build。

預設職業配置為戰士、斥候、法師、牧師各一名；玩家可自由改選任何已解鎖職業，也可讓多名角色使用相同職業。

每名主角同時選擇一件可用的飾品遺產。

## 職業與角色的關係

職業解鎖與 Mastery 是隊伍共享的 Meta Progression，不綁定特定角色。

每個職業自身只提供 1 個主動技能與 1 個被動技能；職業特性只是文字定位說明。Tier 2、Tier 3 透過完整技能繼承形成更高階 Build，而不是透過 Legacy Trait 保留弱化效果。

角色個體差異主要來自：

- 本次選擇的職業
- 該職業依 Tier 繼承而來的完整技能組
- 本次裝備的飾品遺產
- 當前戰鬥配置與玩家決策

## 角色資料

公開資訊：HP、攻擊能力、防禦能力、力量、智力。

隱藏資訊：敏捷（決定行動順序）、命中、迴避。

## 死亡規則

單次遠征中，角色死亡後從行動順序移除，且無法參與後續戰鬥。四名角色全部死亡時，該 Run 失敗。

## 跨 Run 設計

跨 Run 保留職業樹 Mastery、職業解鎖、遺產收藏與其他 Meta Progression；每次 Run 的起始職業與飾品遺產重新選擇。

死亡只代表上一輪遠征結果，不代表角色永久消失。

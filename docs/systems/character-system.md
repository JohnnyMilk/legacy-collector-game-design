# 角色系統（Character System）

## 系統定位

《遺產收集者》採用固定角色、深度養成設計。

玩家始終操作四名固定主角，不透過大量招募角色建立隊伍，而是透過職業、遺產與經歷塑造角色差異。

## 核心規則

- 玩家固定擁有四名主角。
- 不存在角色等級系統。
- 不存在自由能力配點。
- 成長來自職業、Mastery、Legacy Trait 與 Relic。
- Relationship／親密度系統已取消，不再作為角色成長或 Tier 3 Inspiration 條件。

## 序章起點

遊戲只有最初序章使用 Tier 0「村民」。

四名主角在序章中以村民身分完成故事導入與基礎教學。序章結束後，村民不再作為一般 Run 的起始職業，也不需要 Mastery。

## 每次 Run 的初始配置

每次正式遠征開始前，玩家都會替四名主角重新設定本次 Run 的 Build。

預設職業配置為四個 Tier 1 各一名：

- 戰士
- 斥候
- 法師
- 侍祭

玩家可以自由替任一角色改選任何已解鎖職業，也可以讓多名角色選擇相同職業，例如四名角色全部使用戰士。

此外，每名主角在遠征準備時可選擇一件目前可用的遺產作為飾品遺產。

## 職業與角色的關係

職業解鎖與 Mastery 是隊伍共享的 Meta Progression，不綁定特定角色。

因此同一個已解鎖職業可以由不同主角在不同 Run 中使用；已 Mastered 的職業也不需要由每名角色重新精通。

角色個體差異主要來自：

- 本次選擇的職業
- 過去形成的 Legacy Trait
- 本次裝備的飾品遺產
- 當前戰鬥配置與玩家決策

## 角色資料

公開資訊：
- HP
- 攻擊能力
- 防禦能力
- 力量
- 智力

隱藏資訊：
- 敏捷（決定行動順序）
- 命中
- 迴避

## 死亡規則

單次遠征中，角色死亡後：
- 從行動順序移除。
- 無法參與後續戰鬥。

四名角色全部死亡時，該 Run 失敗。

## 跨 Run 設計

隊伍全滅或完成遠征後，下一次 Run 仍由同一組四名主角出發。

跨 Run 保留的是職業樹 Mastery、職業解鎖、遺產收藏與其他 Meta Progression；每次 Run 的起始職業與飾品遺產則在遠征準備階段重新選擇。

死亡只代表上一輪遠征結果，不代表角色永久消失。

# 角色、職業與熟練度｜廢棄舊版草稿

> 此文件只保存已被取代的職業／Mastery／轉職設計，不再作為現行規格來源。正式規則請以 `character-system.md`、`class-system.md`、`skill-system.md`、`mastery-system.md` 與 `expedition-system.md` 為準。

## 已廢棄：每次 Run 從低 Tier 重新成長

早期曾考慮每次 Run 都從村民或低 Tier 職業重新往上轉職。此規則已取消。

現行設計改為：村民只存在首次序章；正式 Run 可直接選擇任何已解鎖職業作為起始職業。

## 已廢棄：戰鬥後立即轉職

早期版本曾讓角色在戰鬥結束、Mastery 達成後立即進行轉職。此規則已取消，避免形成「打一場就換職業」的節奏。

## 已廢棄：Region 之間固定休整點轉職

上一版曾把轉職安排在 Region 之間的固定休整點。

此規則已被新的節奏取代：**每個 Region 固定只有一個轉職點，原則上位於該 Region 路程中段。**

不另外限制角色轉職次數；真正的頻率限制來自每個 Region 只有一次進入轉職點的機會。

## 已廢棄：Legacy Trait／弱化被動繼承

早期版本曾規劃角色完成 Mastery 後，轉職時保留原職業的一個弱化被動，稱為 Legacy Trait。

此規則已取消。現行設計改為高 Tier **完整技能繼承**：

- 每個正式職業自身提供 1 主動 + 1 被動。
- Tier 2 完整繼承正式連線 Tier 1 的主／被動技能。
- Tier 3 完整繼承 Inspiration Links 對應 Tier 2 與其祖先技能。
- 同一來源技能不重複。

## 已廢棄：Relationship 作為 Tier 3 Inspiration

角色親密度／Relationship 曾被用來作為 Tier 3 解鎖條件。此系統已取消。

一般 Tier 3 現在只檢查其全部 Inspiration Links 對應 Tier 2 是否已 Mastered。

## 歷史參考原則

本文件中的內容皆屬被取代設計。若與正式系統文件衝突，一律以正式文件與 `data/classes.json` 的現行版本為準。

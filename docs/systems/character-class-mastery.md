# 角色、職業與熟練度｜舊版草稿

> 此文件為舊版整合草稿，不再作為現行規格來源。正式規則請以 `character-system.md`、`class-system.md`、`mastery-system.md` 為準。

## 現行設計摘要

- 玩家固定操作四名主角。
- 遊戲只有最初序章使用 Tier 0「村民」；村民只負責故事導入與教學，不需要 Mastery。
- 序章後每次正式 Run 都從遠征準備開始。
- 預設起始配置為戰士、斥候、法師、侍祭各一名，但玩家可改成任何已解鎖職業，也可以讓四名角色使用相同職業。
- 每名角色在 Run 開始前選擇一件飾品遺產。
- Mastery 是四名主角共用、以職業為單位、跨 Run 永久保留的 Checklist 進度。
- 已解鎖職業可直接作為新 Run 的起始職業，不需要重新從低 Tier 練起。
- 戰鬥只推進 Mastery 與職業解鎖，不在每場戰鬥後直接轉職。
- Run 中正式轉職只在 Region 之間的固定休整點進行。
- 一般 Tier 3 只要其所有 Inspiration Links 對應 Tier 2 都完成 Mastery，即永久解鎖。
- Relationship／親密度系統已取消。
- 透過遺產直接取得的職業稱為「特殊職業」，不顯示於一般同心圓職業樹。

## 保留價值

本文件只保留早期設計思考的歷史參考。若內容與拆分後的正式系統文件衝突，一律以正式系統文件為準。

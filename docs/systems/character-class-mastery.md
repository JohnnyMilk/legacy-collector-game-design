# 角色、職業與 Mastery

## 隊伍

- 起始隊伍為四名固定角色，全部強制出戰，沒有候補席。
- 角色死亡後在該輪永久離隊，隊伍可少於四人繼續遠征。
- 人數不足時，未來可透過特殊 Route Event 遇見暫時同行的新角色；此為事件內容，不是自動補人規則。

## 角色成長

角色沒有 Level，也沒有自由配點。能力由下列來源共同決定：

```text
目前職業 + 職業 Trait + 職業遺緒 × 1 + 遺產 × 1 + 關係
```

基礎資料包含 HP、物理攻擊／防禦、魔法攻擊／防禦與移動力。移動力由目前職業決定。敏捷、命中與迴避為隱藏數值。

## 職業金字塔

```text
Tier 0：Villager
Tier 1：公開基礎職業
Tier 2：公開進階職業
Tier 3：全部為隱藏職業
```

- 同 Tier 的已 Master 職業可橫向轉換。
- 可在 Master 後向更高 Tier 進階。
- 不可回到較低 Tier。
- 玩家沒有義務升 Tier；停留在喜歡的 Tier 並橫向發展是合法玩法，Report 可用稱號記錄這類挑戰。

## Mastery

Mastery 屬於「目前職業」，不是角色經驗。正常參與約 2～3 場戰鬥即可練滿一個職業。

會累積 Mastery 的有效行為：普通攻擊、使用主動技能、受到敵方攻擊。單純移動或 Wait 不會累積。玩家只看見進度與結果，不需要計算精確點數。

## 職業 Trait 與職業遺緒

- **Class Trait**：只在目前職業有效，可強烈定義玩法；轉職後失去。
- **Legacy Trait**：Master 一個職業留下的較小職涯痕跡；角色同時只能保留一個，可在新的 Master 後選擇替換。
- 主動技能屬於目前職業，轉職後不保留。轉職同時取得新職業的技能與 Charge。

## 隱藏職業與 Inspiration

Tier 3 全部是 Hidden Class，也是未來更新的主要內容接口。隱藏職業不會出現在未發現的職業樹中；其存在應透過 NPC、敵人、Boss、書籍、遺物敘事與世界事件讓玩家自行察覺。

Inspiration 可能由目前／過去職業、Mastery、隊伍組合、角色關係、遺產、戰鬥歷史、Route Event 或 Report 共同觸發。得到 Inspiration 後仍須完成目前職業的 Mastery 才能轉職。正式條件不直接公開。

# 遊戲循環與長期進度

## 序章

遊戲最初只有一次序章／教學。四名主角以 Tier 0「村民」身分開始，用來導入故事、移動、攻擊、技能與基本戰鬥規則。序章結束後，村民不再作為正式 Run 起始職業，也不需要 Mastery。

## 單次遠征

```text
遠征準備
→ 選擇四名角色起始職業 + 飾品遺產
→ Region 起點
→ 前半段戰鬥／事件
→ 固定轉職點
→ 後半段戰鬥／事件
→ Boss
→ 下一 Region
→ …
→ Final Region
→ 成功或全滅
→ 遠征報告
→ 下一次 Run
```

## 遠征準備

每次正式 Run 開始時，預設隊伍為戰士、斥候、法師、牧師各一名。

玩家可以自由改成任何已解鎖職業，也可以讓多名角色使用相同一般職業。每名主角同時選擇一件目前可用的飾品遺產；同一最終特殊職業不可在隊伍中重複。

已解鎖的高 Tier 職業可以直接作為新 Run 起始職業，不需要重新從村民或 Tier 1 開始。

## 戰鬥、Mastery 與戰績

戰鬥中的職業行為會即時寫入兩個資料層：

- **本次遠征紀錄**：只統計目前 Run 的增量。
- **職業戰績檔案**：跨 Run 永久累積、以職業為單位的長期統計。

Mastery Checklist 直接以職業戰績檔案作為判定來源。某項統計達到門檻時，Checklist 立即完成，`Mastery X / Y` 也立即增加；如果全部項目都已完成，先顯示 `Mastery Y / Y · 待戰後結算`。

戰鬥結束時才正式判定該職業是否取得 **MASTERED**，並檢查新職業解鎖與一般戰後恢復。戰鬥後不直接轉職。

角色死亡不會影響已累積的職業戰績或已完成 Mastery 條件。

職業戰績檔案不會因 Mastery 完成而停止計數；例如戰士擊倒需求為 45，人數仍可長期累積到 100 以上。

## Mastery 框架

Tier 1 / Tier 2 固定 6 項 Checklist：3 項共通 + 3 項職業專屬。

Tier 3 不使用共通模板，改為完全依職業特色設計，且不固定項目數量。

## Tier 3 的發現節奏

正式遊戲在第一次 Tier 3 解鎖前，職業樹 UI 只顯示 Tier 1 與 Tier 2；不提前顯示 Tier 3 外圈、問號節點、標籤或 Inspiration Links。

第一次滿足任一 Tier 3 的 Inspiration 條件時，職業樹才向外展開／縮放並第一次揭露 Tier 3。此後 Tier 3 才成為玩家可持續觀察與追求的長期職業層。

## Region 轉職點

每個 Region 固定只有 **1 個轉職點**，原則上位於路程中段，而不是 Region 之間或隨機事件。

到達轉職點時，玩家可以依職業樹規則調整角色職業。角色目前職業必須已 Mastered 才能由該職業進行正式轉職。

不另外限制角色轉職次數；頻率由每 Region 只有一次轉職點控制。離開後，本 Region 不再提供第二次轉職機會。

完成轉職時，新 Build 中所有可用主動技能 Charge 補滿。

## 高 Tier 技能成長

每個職業自身只提供 1 個主動技能與 1 個被動技能；職業特性只是文字定位，不是技能。

Tier 2 完整繼承正式連線 Tier 1 的主／被動技能；Tier 3 完整繼承 Inspiration Links 對應 Tier 2 及其祖先技能。同一來源技能不重複。

舊版轉職後留下弱化 Legacy Trait 的規則已取消。

## 最終特殊職業

四個最終特殊職業分別代表戰士、敏捷、魔法、支援四大職業系，位於 Tier 0～3 同心圓之外，不是 Tier 4。

預設解鎖條件為：完成該職業系要求的全部 Tier 3 Mastery，並取得該系對應特殊遺產。兩者必須同時成立。

## 後期難度與完整通關

Tier 3 不作為進入 Final Region 或 Final Boss 的硬性條件，但遊戲後期的敵人與 Boss 強度會以「隊伍已取得部分 Tier 3」作為正常完整通關的平衡預期。

純 Tier 2 隊伍仍可繼續推進與挑戰完整 Run；若成功，屬高難度特殊通關，可由 Report／成就系統記錄。

## 成功、失敗與遠征報告

- 框架層唯一失敗條件是隊伍全滅。
- 只要尚有角色存活，遠征可以以殘缺隊伍繼續。
- 無論成功或失敗，都會產生完整遠征報告。
- 遠征報告主要由「本次遠征紀錄」整理而來，描述這一趟 Run 的表現。
- 稱號可依本 Run 的突出行為、特殊組合或極端紀錄產生。

## 跨 Run 保留與重置

跨 Run 永久保留：

- 職業解鎖狀態
- 職業 Mastery Checklist 與 Mastered 狀態
- **職業戰績檔案**中的完整長期統計
- Tier 3 Inspiration 解鎖與 Tier 3 已揭露狀態
- 遺產收藏與遺產長期進度
- 已封存的遠征報告與其他 Meta Progression

每個新 Run 會重新建立一份新的「本次遠征紀錄」，並重新選擇四名角色的起始職業、飾品遺產與其他本輪 Build 配置。

## Meta Progression 原則

跨 Run 成長以「發現、精通、紀錄與解鎖」為核心，而不是永久 HP 或傷害加成。高 Tier 職業透過完整技能繼承自然形成更強、更完整的 Build；職業戰績檔案則保留玩家對每個職業真正累積出的完整歷史。

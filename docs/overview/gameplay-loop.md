# LEGACY COLLECTOR｜遊戲循環與長期進度

## 序章

遊戲最初只有一次序章／教學。四名主角以 Tier 0「村民」開始；序章結束後，村民不再作為一般 Run 起始職業，也不需要 Mastery。

## 單次遠征

```text
遠征準備
→ 選擇四名角色起始職業
→ Region 1
→ Region 2
→ Region 3
→ Region 4（可選記憶神殿分支）
→ Final Region
→ Final Boss
→ 成功或全滅
→ 遠征報告
→ 下一次輪迴
```

角色沒有任何裝備欄，因此遠征準備不再包含 Relic／飾品配置。

## 遠征準備

第一次正式 Run 預設隊伍仍可用戰士、斥候、法師、牧師各一名作為基礎配置。之後玩家可以替每名主角選擇任何已永久解鎖且該角色合法使用的職業。

一般 Tier 1～3 可跨角色、跨職業系自由使用；「XXX 的記憶」只允許對應角色本人使用。

## Run 內成長

戰鬥與事件可持續更新：

- 本次遠征紀錄。
- 職業戰績檔案。
- Mastery Checklist。
- 新 Tier 3 Inspiration 解鎖。

戰鬥結束只負責 Mastery／解鎖與一般結算，不直接轉職。

## Region 轉職點

每個 Region 固定只有 1 個轉職點，原則上位於路程中段。角色目前職業必須已 Mastered 才能由該職業正式轉出。

完成轉職後，新 Build 中所有可用主動技能 Charge 補滿。

## Tier 3

Tier 3 在第一次解鎖前不顯示。每個 Tier 3 透過明確 Inspiration Links 連結 Tier 2；所有對應 Tier 2 Mastery 完成後永久解鎖。

Tier 3 Mastery 不使用共通模板，只圍繞自己的 Tier 3 專屬主動與被動技能設計。

## Region 4 記憶神殿

記憶神殿只出現在 Region 4，而且不是必經路線。玩家可以走其他分支直接放棄本次覺醒機會。

當某一職業系的全部 Tier 3 Mastery 已完成，且玩家在 Region 4 實際進入合法的記憶神殿節點時，該系對應主角可首次覺醒自己的「XXX 的記憶」。

同一 Run 可以覺醒多名角色，只要各自條件成立且地圖路線提供相應機會。

首次覺醒後永久解鎖；之後新 Run 可直接以該角色自己的記憶形態開始，不需要再次前往神殿。

## 隊伍職業組合

四名角色當前職業所屬職業系會形成隊伍職業組合。這套系統將提供隊伍被動能力，作為取消裝備 Build 後的重要隊伍構築層。

具體組合、效果與數值目前不定義，留待 `party-composition-system` 的獨立 Demo。

## 成功、失敗與輪迴

- Party Wipe 是本次 Run 的失敗條件。
- 敘事上可理解為本次世界循環失敗，四名角色再次進入下一輪。
- 只要尚有角色存活，隊伍可繼續遠征。
- 擊敗 Final Boss 代表完成本次世界的最終目標。
- 無論成功或失敗，都產生遠征報告。

## 跨 Run 永久保留

- 職業解鎖。
- Mastery Checklist 與 Mastered 狀態。
- 職業戰績檔案。
- Tier 3 揭露與解鎖。
- 已覺醒的「XXX 的記憶」。
- 已封存遠征報告與其他不提供直接永久數值加成的紀錄型 Meta Progression。

不再保存任何 Relic 收藏、裝備或修復進度，因該系統已取消。

## Meta Progression 原則

跨 Run 成長集中在**發現、精通、記憶與紀錄**，而不是永久 HP、傷害或裝備堆疊。

玩家越接近終點，角色越接近原本的自己；但故事最後要反問的不是「你終於拿到了什麼」，而是「你是否享受了走到這裡的過程」。

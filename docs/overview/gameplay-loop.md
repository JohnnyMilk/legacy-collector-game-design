# 遊戲循環與長期進度

## 單次遠征

```text
選擇遺產 → 四人出發 → 單向節點遠征 → 戰鬥與事件
→ 職業熟練度／轉職結算 → 頭目挑戰 → 成功或全滅
→ 遠征報告 → 下一次遠征
```

每場戰鬥後都會進行結算：存活角色回復本場失去生命值的 50%、計算職業熟練度，並在熟練度滿時讓玩家選擇是否轉職。區域小頭目與最終頭目的遺產獎勵也在此處處理。

## 成功與失敗

- 框架層的唯一失敗條件是隊伍全滅。
- 只要尚有角色存活，遠征可以以殘缺隊伍繼續。
- 個別事件或地圖未來可增加自己的特殊失敗條件。
- 無論成功或失敗，都會產生完整遠征報告。

## 跨 Run 保留與重置

全滅後，遺產使固定四人再次復甦並展開新的遠征。角色保有共同記憶與關係；遺產收藏、已發現的隱藏職業與遠征報告也會保留。

本輪的職業、職業遺緒、攜帶配置與戰鬥狀態會失去。這使每一次遠征保有風險，而長期歷史不會被抹去。

## Meta Progression 原則

跨 Run 的成長以「發現」為核心，而不是永久 HP 或傷害加成：遺產修復、隱藏職業、世界記錄與玩家對系統的理解才是主要進度。

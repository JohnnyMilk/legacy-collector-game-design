# 遊戲循環與長期進度

## 序章

遊戲最初只有一次序章／教學。

四名主角以 Tier 0「村民」身分開始，用來導入故事、移動、攻擊、技能與基本戰鬥規則。序章結束後，村民不再作為正式 Run 的起始職業，也不需要 Mastery。

## 單次遠征

```text
遠征準備
→ 為四名主角選擇起始職業與飾品遺產
→ Region 1
→ 休整點
→ Region 2
→ 休整點
→ Region 3
→ 休整點
→ Region 4
→ 休整點
→ Final Region
→ 成功或全滅
→ 遠征報告
→ 下一次遠征
```

## 遠征準備

每次正式 Run 開始時，預設隊伍為四名主角各使用一個 Tier 1：戰士、斥候、法師、侍祭。

玩家可以自由改成任何已解鎖的職業；可以跨職業系，也可以讓多名角色選擇相同職業，例如四名角色全部使用戰士。

同時，每名主角都可以選擇一件目前可用的遺產作為本次遠征的飾品遺產。

已解鎖的高 Tier 職業可以直接作為新 Run 的起始職業，不需要重新從村民或 Tier 1 開始。

## 戰鬥與 Mastery

每場戰鬥後進行一般結算，包括恢復、Mastery Checklist 更新與新職業解鎖檢查。

戰鬥後不直接轉職。

Mastery 為四名主角共用、以職業為單位的跨 Run 永久進度。已完成的 Mastery 不會因下一次遠征重新開始而重置。

## 休整點與轉職

轉職只在 Region 之間的固定休整點進行，不依賴隨機事件，也不在每場戰鬥後立即發生。

到了休整點，玩家可以：

- 查看目前 Mastery 進度
- 查看新解鎖的 Tier 3 或其他職業
- 維持目前職業
- 依職業樹規則轉換至目前可用職業

欲從目前職業轉出時，該職業必須已由隊伍完成 Mastery。

## 成功與失敗

- 框架層的唯一失敗條件是隊伍全滅。
- 只要尚有角色存活，遠征可以以殘缺隊伍繼續。
- 個別事件或地圖未來可增加自己的特殊失敗條件。
- 無論成功或失敗，都會產生完整遠征報告。

## 跨 Run 保留與重置

跨 Run 永久保留：

- 職業解鎖狀態
- 職業 Mastery Checklist 與 Mastered 狀態
- Tier 3 Inspiration 解鎖
- 遺產收藏與遺產長期進度
- 遠征報告與其他 Meta Progression

每個新 Run 都重新選擇：

- 四名角色的起始職業
- 每名角色本次攜帶的飾品遺產
- 其他屬於本輪 Build 的配置

## Meta Progression 原則

跨 Run 的成長以「發現、精通與解鎖」為核心，而不是永久 HP 或傷害加成。

玩家長期累積的是共用職業樹的 Mastery、Tier 3 Inspiration、遺產修復、世界記錄與對系統的理解；每次遠征則重新組合這些已取得的選項形成新的 Build。

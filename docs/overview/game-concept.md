# 遊戲概念

## 定位

《遺產收集者》是一款 **隨機遠征式戰術角色扮演遊戲（Roguelike Tactical RPG）**。核心由戰棋戰鬥、跨 Run 的職業 Mastery、遠征前 Build 構築、完整技能繼承、遺產修復與不可回頭的遠征組成。

玩家帶領四名固定角色，在多次遠征中擴張共用職業樹、完成 Mastery、解鎖高 Tier 與最終特殊職業，並逐步修復世界的遺產。

## 序章與正式遠征

遊戲最初只有一次序章／教學。四名主角以 Tier 0「村民」身分開始；序章結束後，村民不再作為一般 Run 起始職業。

每次正式 Run 開始前：

- 預設四名主角分別使用戰士、斥候、法師、牧師。
- 玩家可以改成任何已解鎖職業。
- 一般職業可以多人重複；同一最終特殊職業不可在隊伍中重複。
- 每名主角同時選擇一件可用的飾品遺產。

## 設計支柱

1. **構築先於戰鬥**：戰前職業、繼承技能、飾品遺產與隊伍組合，是戰術深度主要來源。
2. **小隊伍、深成長**：固定四名主角，共用職業樹與跨 Run Mastery。
3. **高 Tier 有明確成長感**：Tier 2、Tier 3 透過完整技能繼承逐步形成更完整 Build。
4. **Mastery 是長期進度**：同職業多人行為合併累積，戰鬥中記錄、戰後統一判定。
5. **Tier 1 / Tier 2 使用共同框架**：固定 6 項 Mastery，3 共通 + 3 職業專屬。
6. **Tier 3 進入高階精通**：取消共通 Mastery 模板，全部依職業特色個別設計。
7. **轉職有節奏**：每個 Region 固定只有一個轉職點，原則上位於路程中段。
8. **Tier 3 是系統揭密**：第一次解鎖前，正式 UI 完全不顯示 Tier 3。
9. **最終特殊職業是另一條終點**：四個特殊職業分別代表戰士、敏捷、魔法、支援四大職業系，獨立位於 Tier 0～3 同心圓之外，不是 Tier 4。
10. **特殊職業解鎖需要雙條件**：完成該職業系要求的全部 Tier 3 Mastery，並取得該系特殊遺產。
11. **每件遺產都有旅程**：遺產是跨 Run 長期 Meta Progression，也是最終職業解鎖的一部分。

## 職業解鎖與技能繼承

一般 Tier 3 透過共用職業樹的 Inspiration Links 解鎖：所有對應 Tier 2 都完成 Mastery 後即永久解鎖。

Tier 2 繼承正式連線 Tier 1 的全部主／被動技能；Tier 3 繼承 Inspiration Links 對應 Tier 2 與其祖先技能，同一來源技能不重複。

四個最終特殊職業不屬於 Tier 4，也不使用一般 Tier 3 Inspiration 解鎖方式。它們的預設解鎖條件為：完成對應職業系要求的全部 Tier 3 Mastery **且** 取得該系特殊遺產。

特殊職業的技能繼承方式尚未定案，不先套用 Tier 3 規則。

Relationship／親密度系統已取消。

## Tier 3 資訊揭露

正式遊戲第一次 Tier 3 解鎖以前：

- 職業樹只顯示到 Tier 2。
- 不顯示 Tier 3 外圈、問號、標籤或 Inspiration Links。
- 玩家應能合理相信 Tier 2 就是目前最高職業階級。

第一次完成任一 Tier 3 的 Inspiration 條件時，UI 才第一次揭露 Tier 3 並向外展開職業樹。Prototype 與開發頁面可為驗證目的提前顯示完整 Tier 3 與四個外部特殊職業節點。

## 完整通關難度定位

Tier 3 不是進入 Final Region 或 Final Boss 的硬性門票，但它是正式平衡預期的後期戰力層級。

純 Tier 2 隊伍仍可嘗試完成整個 Run；若成功，應視為值得 Report／成就系統記錄的高難度玩法，而非一般通關基準。

## 已定案的限制

- 無角色等級、無自由配點。
- 無元素相剋、無元素抗性、無消耗道具。
- 每名角色僅有一個遺產欄位。
- 同一最終特殊職業在隊伍中不可重複；不同特殊職業可並存。
- 底層數值可隱藏，但結果必須讓玩家看得懂。

## 名稱與敘事狀態

正式遊戲名稱為《遺產收集者》。四名主角姓名、完整 Tier 3 清單、四個最終特殊職業正式名稱、特殊遺產清單、四個 Region 正式名稱與 Final Boss 名稱尚未全部設定。

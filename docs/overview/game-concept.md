# 遊戲概念

## 定位

《遺產收集者》是一款 **Roguelike 戰術角色扮演遊戲**。核心由戰棋戰鬥、短週期職業養成、遺產修復與不可回頭的遠征組成。

玩家帶領四名固定角色，找回失落的古代遺產，讓它們在多次遠征中逐漸恢復力量，並從遺產與世界遺跡拼出失落文明的歷史。

## 核心目標

遊戲不是培養單一最強角色，而是在一次次失敗與重來中，建立四名角色共同經歷的歷史，並逐步修復世界的遺產。

## 設計支柱

1. **構築先於戰鬥**：戰前的職業、遺緒、遺產與隊伍組合，是戰術深度的主要來源。
2. **小隊伍、深成長**：僅有四名核心角色，但每人都能走向不同的職涯。
3. **損失有後果**：角色在單次遠征中死亡後不會復活；全滅才結束遠征。
4. **協同勝過純數值**：職業、遺緒、遺產與關係共同形成 Build。
5. **每趟遠征都是故事**：成功或失敗都會留下 Report、稱號與發現。
6. **每件遺產都有旅程**：遺產不是即時裝備，而是需要兩次完整遠征才能完全喚醒的長期目標。

## 已定案的限制

- 無角色等級、無自由配點。
- 無元素相剋、無元素抗性、無消耗道具。
- 每名角色僅有一個遺產欄位。
- 底層數值可隱藏，但結果必須讓玩家看得懂。

## 名稱與敘事狀態

正式遊戲名稱為《遺產收集者》。角色姓名、正式職業清單、遺產清單、四個 Region 的正式名稱與 Final Boss 名稱尚未設定；文件中的 Paladin、Death Knight、古代王冠等皆為系統示例或未來擴充方向。

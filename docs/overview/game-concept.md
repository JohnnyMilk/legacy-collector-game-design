# 遊戲概念

## 定位

《遺產收集者》是一款 **隨機遠征式戰術角色扮演遊戲（Roguelike Tactical RPG）**。核心由戰棋戰鬥、跨 Run 的職業 Mastery、遠征前 Build 構築、遺產修復與不可回頭的遠征組成。

玩家帶領四名固定角色，找回失落的古代遺產，讓它們在多次遠征中逐漸恢復力量，並從遺產與世界遺跡拼出失落文明的歷史。

## 核心目標

遊戲不是培養單一最強角色，而是在一次次遠征中擴張共用職業樹、完成職業 Mastery、解鎖新的 Tier 3 與特殊職業，並逐步修復世界的遺產。

## 序章與正式遠征

遊戲最初只有一次序章／教學。

四名主角以 Tier 0「村民」身分開始，用來完成故事導入與基本戰鬥教學。序章結束後，村民不再作為一般 Run 的起始職業。

每次正式 Run 開始前，玩家進入遠征準備：

- 預設四名主角分別使用戰士、斥候、法師、侍祭四個 Tier 1。
- 玩家可以將任一角色改成任何已解鎖職業。
- 可以讓多名角色使用相同職業，例如四人全部選擇戰士。
- 每名主角同時選擇一件可用的飾品遺產。

## 設計支柱

1. **構築先於戰鬥**：戰前的職業、Legacy Trait、飾品遺產與隊伍組合，是戰術深度的主要來源。
2. **小隊伍、深成長**：僅有四名核心角色，但共用職業樹與跨 Run Mastery 提供長期成長。
3. **職業精通是長期進度**：Mastery 以職業為單位由四名主角共同完成，跨 Run 永久保留。
4. **轉職有節奏**：戰鬥負責推進 Mastery 與解鎖；正式轉職只在 Region 之間的固定休整點進行。
5. **損失有後果**：角色在單次遠征中死亡後不會復活；全滅才結束遠征。
6. **每趟遠征都是故事**：成功或失敗都會留下遠征報告、稱號與發現。
7. **每件遺產都有旅程**：遺產不是即時消耗品，而是需要多次遠征逐步修復的長期目標。

## 職業解鎖原則

一般 Tier 3 透過共用職業樹的 Inspiration Links 解鎖：只要所有對應 Tier 2 都完成 Mastery，Tier 3 即永久解鎖。

透過遺產直接取得或啟發的職業稱為「特殊職業」，不出現在一般 Tier 0～Tier 3 同心圓職業樹上。

Relationship／親密度系統已取消，不再參與角色 Build 或 Tier 3 Inspiration。

## 已定案的限制

- 無角色等級、無自由配點。
- 無元素相剋、無元素抗性、無消耗道具。
- 每名角色僅有一個遺產欄位。
- 底層數值可隱藏，但結果必須讓玩家看得懂。

## 名稱與敘事狀態

正式遊戲名稱為《遺產收集者》。四名主角姓名、完整 Tier 3 清單、特殊職業清單、遺產清單、四個 Region 的正式名稱與 Final Boss 名稱尚未全部設定。

# LEGACY COLLECTOR｜遊戲概念

## 定位

LEGACY COLLECTOR 是一款 **隨機遠征式戰術角色扮演遊戲（Roguelike Tactical RPG）**。核心由戰棋戰鬥、跨 Run 職業 Mastery、完整技能繼承、職業轉換、四人隊伍職業系搭配與記憶覺醒構成。

玩家帶領四名固定主角穿越多個 Region，在一次次輪迴中擴張共用職業樹、完成 Mastery、解鎖 Tier 3，最後找回四人各自原本的「XXX 的記憶」，並挑戰 Final Boss。

## 角色與序章

四名主角過去分別代表戰士、敏捷、魔法、支援四大職業系的頂點人物。因某個尚未揭露的事件，他們失去記憶、身份與力量，並以 Tier 0「村民」重新開始。

四人都能自由跨職業系發展；角色原本的職業系歸屬不限制 Tier 1～3，只決定其唯一專屬的最終「XXX 的記憶」。

## 無裝備設計

角色沒有武器、防具、飾品、Relic 或其他裝備欄。

舊版遺產裝備、遺產修復、收藏館、掉落與特殊遺產解鎖機制全部取消。Legacy 仍可存在於世界觀與故事中，但不是玩家可裝備、蒐集或強化的系統資源。

## 設計支柱

1. **職業就是 Build**：角色差異集中在目前職業、技能繼承與轉職歷程。
2. **隊伍搭配就是第二層 Build**：四名角色的當前職業系配置會形成隊伍被動組合；具體效果另由獨立 Prototype 定義。
3. **小隊伍、深成長**：固定四名主角，共用職業樹與跨 Run Mastery。
4. **高 Tier 有明確成長感**：Tier 2、Tier 3 透過完整技能繼承形成更完整的技能組。
5. **Mastery 訓練玩家，也對應角色記憶**：進度屬於職業，跨 Run 保存。
6. **Tier 3 是高階精通**：Mastery 只圍繞自己的 Tier 3 專屬主／被動技能，不使用共通場次、擊殺或 Boss 任務。
7. **轉職有節奏**：每個 Region 固定 1 個中段轉職點。
8. **記憶是角色專屬終點**：四個「XXX 的記憶」不是 Tier 4，也不是任何人都能學的職業。
9. **Region 4 提供可選覺醒路線**：完成對應原始職業系的核心 Tier 3 與所有涵蓋該系的雙系 Tier 3 Mastery 後，可在 Region 4 的記憶神殿首次覺醒。
10. **首次覺醒永久保留**：後續 Run 可直接以已解鎖的角色記憶開始。
11. **Final Boss 是遠征終點**：不要求一定先取得全部記憶，但記憶形態屬最高階後期力量。
12. **最後的 Legacy 是理解，不是物品**：故事最終要回到「享受追逐終點的過程」。

## 職業解鎖與技能繼承

Tier 2 繼承正式連線 Tier 1 的全部主／被動技能；Tier 3 繼承 Inspiration Links 對應 Tier 2 與其祖先技能，同一來源技能不重複。一般攻擊由當前職業自行定義，不繼承。

一般 Tier 3 在所有 Inspiration Links 對應 Tier 2 都完成 Mastery 後永久解鎖。

四個「XXX 的記憶」則依角色綁定：對應原始職業系的核心 Tier 3 與所有涵蓋該系的雙系 Tier 3 Mastery 完成後，首次進入 Region 4 合法記憶神殿即可覺醒；覺醒後永久解鎖。

## Tier 3 資訊揭露

正式遊戲第一次 Tier 3 解鎖以前，職業樹只顯示 Tier 1 與 Tier 2，不顯示 Tier 3 外圈、問號或 Inspiration Links。第一次滿足任一 Tier 3 Inspiration 條件時才揭露外圈。

## 完整通關

一次 Run 維持 4 個主要 Region + Final Region。Tier 3 不是進入 Final Region 的硬性門檻；純 Tier 2 隊伍仍可挑戰完整通關，但屬高難度玩法。

Final Boss 被擊敗後，玩家取得故事意義上的最終 Legacy；它不轉化為裝備或永久戰鬥數值。

## 名稱與敘事狀態

正式遊戲名稱只使用 **LEGACY COLLECTOR**，不另設中文正式名稱。

四名主角姓名、過去稱號、四個「XXX 的記憶」的正式顯示名稱、讓他們失去一切的高位存在、Final Boss 身份與最後一句 Legacy 的正式文字，皆留待後續敘事設計。

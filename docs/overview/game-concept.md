# 遊戲概念

## 定位

《遺產收集者》是一款 **隨機遠征式戰術角色扮演遊戲（Roguelike Tactical RPG）**。核心由戰棋戰鬥、跨 Run 的職業 Mastery、遠征前 Build 構築、完整技能繼承、遺產修復與不可回頭的遠征組成。

玩家帶領四名固定角色，在多次遠征中擴張共用職業樹、完成 Mastery、解鎖高 Tier 與特殊職業，並逐步修復世界的遺產。

## 序章與正式遠征

遊戲最初只有一次序章／教學。四名主角以 Tier 0「村民」身分開始；序章結束後，村民不再作為一般 Run 起始職業。

每次正式 Run 開始前：

- 預設四名主角分別使用戰士、斥候、法師、侍祭。
- 玩家可以改成任何已解鎖職業，也可讓多人使用相同職業。
- 每名主角同時選擇一件可用的飾品遺產。

## 設計支柱

1. **構築先於戰鬥**：戰前職業、繼承技能、飾品遺產與隊伍組合，是戰術深度主要來源。
2. **小隊伍、深成長**：固定四名主角，共用職業樹與跨 Run Mastery。
3. **高 Tier 有明確成長感**：每個職業自身只有 1 主動 + 1 被動；Tier 2、Tier 3 透過完整技能繼承逐步形成更完整 Build。
4. **職業特性只是定位說明**：它不是額外被動技能，也不直接產生戰鬥效果。
5. **Mastery 是長期進度**：每個職業先採 6 項 Checklist，目標約兩個 Run 自然完成。
6. **轉職有節奏**：每個 Region 固定只有一個轉職點，原則上位於路程中段；戰鬥後不直接轉職。
7. **損失有後果**：角色在單次遠征中死亡後不會復活；全滅才結束遠征。
8. **每趟遠征都是故事**：成功或失敗都會留下遠征報告、稱號與發現。
9. **每件遺產都有旅程**：遺產是跨 Run 長期 Meta Progression。

## 職業解鎖與技能繼承

一般 Tier 3 透過共用職業樹的 Inspiration Links 解鎖：所有對應 Tier 2 都完成 Mastery 後即永久解鎖。

Tier 2 繼承正式連線 Tier 1 的全部主／被動技能；Tier 3 繼承 Inspiration Links 對應 Tier 2 與其祖先技能，同一來源技能不重複。

舊版 Legacy Trait／弱化被動繼承已取消。

透過遺產直接取得或啟發的職業稱為「特殊職業」，不出現在一般 Tier 0～Tier 3 同心圓職業樹上。

Relationship／親密度系統已取消。

## 已定案的限制

- 無角色等級、無自由配點。
- 無元素相剋、無元素抗性、無消耗道具。
- 每名角色僅有一個遺產欄位。
- 底層數值可隱藏，但結果必須讓玩家看得懂。

## 名稱與敘事狀態

正式遊戲名稱為《遺產收集者》。四名主角姓名、完整 Tier 3 清單、特殊職業清單、遺產清單、四個 Region 正式名稱與 Final Boss 名稱尚未全部設定。

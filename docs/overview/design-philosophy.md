# 遺產收集者｜遊戲設計理念

## 核心定位

《遺產收集者》是一款結合戰棋 SLG、Roguelike 遠征與角色養成的策略角色扮演遊戲。

核心體驗不是單純培養角色等級，而是在多次遠征中逐步擴張可用職業與遺產，再於每次出發前重新組合 Build，創造不同的戰術旅程。

## 設計原則

### 1. 角色成長來自精通、解鎖與技能累積

角色沒有傳統等級系統。

長期成長來自：

- 四名主角共同完成各職業 Mastery Checklist
- 解鎖新的 Tier 3 與特殊職業
- 高 Tier 完整繼承前置職業技能
- 發現與修復遺產

Relationship／親密度與舊版 Legacy Trait 系統都已取消。

### 2. 少量角色，深度構築

玩家固定擁有四名主角。

每次正式 Run 預設四名角色分別使用戰士、斥候、法師、侍祭；玩家可改成任何已解鎖職業，也可以讓多人使用同一職業。

角色差異來自目前職業、該職業繼承的完整技能組、飾品遺產與戰術配置。

### 3. 村民只負責序章與教學

Tier 0「村民」只作為遊戲最初序章的共同起點，不進入一般 Run 的職業循環，也不需要 Mastery。

### 4. 每個職業自身保持精簡

職業特性只是文字定位，不是技能。

每個正式職業自身只提供 1 個主動技能與 1 個被動技能。Tier 1 保持單純；Tier 2、Tier 3 透過完整技能繼承自然變強，而不是讓基礎職業本身過度膨脹。

### 5. Mastery 是長期理解，不是短期刷取

每個一般職業先採 6 項 Mastery Checklist：3 項共通長期條件 + 3 項依職業玩法、被動技能、主動技能設計的專屬條件。

初步節奏目標約兩個 Run 才自然完成一個職業 Mastery。

### 6. 轉職點控制節奏

戰鬥可以持續推進 Mastery，但戰鬥後不立即轉職。

每個 Region 固定只有一個轉職點，原則上位於路程中段。玩家在該點重新調整職業；完成轉職後，新 Build 的所有主動技能 Charge 補滿。

不另外限制角色轉職次數，真正的頻率限制來自每個 Region 只有一次轉職點。

### 7. 隱藏探索來自職業樹本身

Tier 3 全部為隱藏職業。每個 Tier 3 有自己的 Inspiration Links；共用職業樹完成其全部對應 Tier 2 Mastery 後即永久解鎖。

Inspiration Links 同時是 Tier 3 技能繼承來源，但不是可逆轉職路徑。UI 必須與一般轉職線清楚區分。

透過遺產取得的職業稱為「特殊職業」，不放在一般同心圓職業樹上。

### 8. MVP 開發方向

遊戲先驗證：

- 基礎戰棋戰鬥
- 職業 Mastery Checklist
- 職業主動／被動技能
- 高 Tier 技能繼承
- 共用職業樹與 Tier 3 Inspiration
- 遺產系統
- 遠征準備／Region 中段轉職點／遠征循環

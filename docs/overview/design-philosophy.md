# 遺產收集者｜遊戲設計理念

## 核心定位

《遺產收集者》是一款結合戰棋 SLG、Roguelike 遠征與角色養成的策略角色扮演遊戲。

核心體驗不是單純培養角色等級，而是在多次遠征中逐步擴張可用職業與遺產，再於每次出發前重新組合 Build，創造不同的戰術旅程。

## 設計原則

### 1. 角色成長來自經歷與解鎖

角色沒有傳統等級系統。

長期成長來自：

- 四名主角共同完成各職業 Mastery Checklist
- 解鎖新的 Tier 3 與特殊職業
- 轉職後留下 Legacy Trait
- 發現與修復遺產

Relationship／親密度系統已取消，不再作為長期成長或職業啟發機制。

### 2. 少量角色，深度構築

玩家固定擁有四名主角。

重點不是招募大量角色，而是利用共用職業樹、Legacy Trait 與飾品遺產，讓同一組四人產生大量不同 Build。

每次正式 Run 開始時，預設四名角色分別使用戰士、斥候、法師、侍祭；玩家可改成任何已解鎖職業，也可以讓多人使用同一職業。

### 3. 村民只負責序章與教學

Tier 0「村民」保留作為遊戲最初序章的共同起點。

它的功能是：

- 故事導入
- 基本移動與戰鬥教學
- 呈現四名主角尚未形成職業方向的狀態

序章完成後，村民不進入一般 Run 的職業循環，也不需要 Mastery。

### 4. 構築先於遠征

每次 Run 開始前，玩家先完成遠征準備：

- 為四名角色選擇起始職業
- 為每名角色選擇一件飾品遺產

已解鎖職業可以直接作為新 Run 起始職業，不需要每次重新從低 Tier 練起。

### 5. 轉職必須有節奏

Mastery 可以在戰鬥中持續推進，但戰鬥後不立即轉職。

正式轉職只在 Region 之間的固定休整點進行，讓玩家以一個階段為單位重新思考隊伍構築，而不是每打一場就切換職業。

### 6. 隱藏探索來自職業樹本身

Tier 3 職業全部為隱藏職業。

每個 Tier 3 都有自己的 Inspiration Links。只要共用職業樹完成其所有對應 Tier 2 Mastery，該 Tier 3 即永久解鎖。

不同 Tier 3 可以需要不同數量的 Tier 2 Mastery，因此解鎖難度可以自然產生差異。

透過遺產取得的職業則稱為「特殊職業」，不放在一般同心圓職業樹上。

### 7. MVP 開發方向

遊戲先以最小可驗證系統完成：

- 基礎戰棋戰鬥
- 職業 Mastery Checklist
- 共用職業樹與 Tier 3 Inspiration
- 遺產系統
- 遠征準備／休整點／遠征循環

後續更新再加入新的事件、遺產、Tier 3 與特殊職業。

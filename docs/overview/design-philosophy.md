# 遺產收集者｜遊戲設計理念

## 核心定位

《遺產收集者》是一款結合戰棋 SLG、Roguelike 遠征與角色養成的策略角色扮演遊戲。

核心體驗不是單純培養角色等級，而是在有限的遠征過程中，透過職業選擇、遺產收集、角色關係與隊伍配置，創造每一次獨特的旅程。

## 設計原則

### 1. 角色成長來自經歷

角色沒有傳統等級系統。

角色的成長來自：

- 使用職業累積 Mastery
- 轉職後留下 Legacy Trait
- 與隊友建立長期關係
- 發現與修復遺產

### 2. 少量角色，深度培養

玩家固定擁有四名主角。

重點不是招募大量角色，而是讓同一角色透過不同職業道路產生不同玩法。

### 3. 隱藏探索優先

Tier 3 職業全部為隱藏職業。

玩家透過隊伍配置、角色關係、特殊遺產與遊戲歷程逐漸發現新的可能性。

### 4. MVP 開發方向

遊戲先以最小可驗證系統完成：

- 基礎戰棋戰鬥
- 職業 Mastery
- 遺產系統
- 遠征循環

後續更新再加入新的事件、遺產與 Tier 3 隱藏職業。

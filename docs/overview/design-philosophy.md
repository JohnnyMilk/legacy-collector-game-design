# LEGACY COLLECTOR｜遊戲設計理念

## 核心定位

LEGACY COLLECTOR 是一款結合戰棋、Roguelike 遠征、跨 Run 職業 Mastery 與四人隊伍搭配的 Tactical RPG。

核心體驗不是裝備蒐集，也不是角色等級成長，而是：**在一次次輪迴中重新理解職業、轉換職業、組合隊伍，並逐步找回四名主角原本的身份。**

## 設計原則

### 1. 成長集中在職業

角色沒有傳統等級、自由能力配點與任何裝備欄。

長期成長來自：

- 四名主角共同累積各職業 Mastery。
- 解鎖新的 Tier 2、Tier 3。
- 高 Tier 完整繼承前置職業技能。
- 找回四名角色各自的「XXX 的記憶」。

舊版 Relic／遺產裝備、修復、收藏館與特殊遺產系統已取消。

### 2. 少量角色，深度構築

玩家固定操作四名主角。四人都能跨職業系發展，差異來自目前職業、完整繼承技能組、當前隊伍職業系配置與玩家戰術決策。

四名角色各自原本對應戰士、敏捷、魔法、支援其中一個職業系，但這個歸屬不限制 Tier 1～3 的自由轉職；它只決定該角色最後能找回哪一個專屬「XXX 的記憶」。

### 3. 村民是故事原點

Tier 0「村民」只存在於最初序章。四名主角曾經站在各自職業系的頂點，卻因失去記憶與力量而重新成為普通人。村民因此同時是 Tutorial Class 與故事核心符號。

### 4. 每個職業自身保持精簡

職業特性只是定位說明，不是技能。Tier 1 / Tier 2 自身固定提供 1 個主動技能與 1 個被動技能；Tier 3 專屬能力組合依職業特色彈性設計，高 Tier 再透過完整技能繼承形成複合玩法。

### 5. Mastery 是「想起來」的過程

Mastery 是四名主角共享、以職業為單位、跨 Run 保存的長期進度。遊戲機制上代表玩家理解職業；敘事上則可理解為角色在不同輪迴中逐步找回本能與記憶。

Tier 1 / Tier 2 使用共通 + 職業專屬框架；Tier 3 只驗證自身 Tier 3 專屬主動與被動技能，不使用戰鬥場次、擊殺數或 Elite / Boss 共通任務。

### 6. 轉職點控制 Run 內節奏

戰鬥可以持續推進 Mastery，但不在戰鬥結束後直接轉職。每個 Region 固定只有 1 個轉職點，原則上位於路程中段；完成轉職後，新 Build 的可用主動技能 Charge 補滿。

### 7. 隱藏探索來自職業與記憶

Tier 3 全部屬隱藏職業，透過 Inspiration Links 對應的 Tier 2 Mastery 解鎖。

四個最終角色形態則不是 Tier 4，而是四名主角各自專屬的「XXX 的記憶」。首次覺醒需要：對應職業系全部 Tier 3 Mastery + Region 4 可選記憶神殿。首次覺醒後永久解鎖。

### 8. 隊伍搭配取代裝備 Build

四名角色當前職業的 sectors 會形成隊伍職業組合。單系職業貢獻 1 count；雙系 Tier 3 對兩系各貢獻 1，因此四人隊伍總 count 可由 4 變化至 8。各系 2 / 3 / 4 Count 分別提供 +10% / +20% / +30% 的全隊被動：戰士強化物理傷害、敏捷強化 AGI、魔法強化魔法傷害、支援強化 DEF/MDEF；四系恰為 1 / 1 / 1 / 1 時則五項數值各 +5%。其他排列不另設組合 Bonus。

### 9. Final Boss 是 Run 的終點，不是設計的全部

一次完整遠征維持 Region 1～4 + Final Region。最終遊戲目標是擊敗 Final Boss、解開輪迴與四名主角過去的謎團。

故事最後的 Legacy 不是裝備，而是一句話／一個理解：**不要只追逐結果，也要享受抵達之前的過程。**

## MVP 開發方向

優先驗證：職業 Mastery、技能繼承、Tier 3、隊伍職業組合、記憶覺醒、Region 轉職節奏、戰棋核心與 Final Boss 遠征循環。
